- Verify: sandbox — an instrument change with no live-GIS dependency of its own. Its own network calls all go to `*.arcgis.com`, which this sandbox reaches, and it never runs in CI (`npm run probe:parcels`, on demand).
- **THE BLIND SPOT, stated as a property rather than an anecdote:** the probe resolved every state's candidate from that STATE'S OWN `.gov` GIS host plus a web-search research pass. This sandbox reaches `*.arcgis.com` and cannot reach most state `.gov` domains — so any state that publishes the SAME dataset to its own ArcGIS Online **organizational account** was reachable the entire time and was never looked for. **New York had already been rescued by exactly this route** (`ny_statewide` in `counties.js` says so in its own comment) **and it was recorded as a one-off workaround for one state instead of as the default second pass for all fifty.** The tell was in the doc the whole time.
- **THE FIX — `ui-audit/lib/agolParcelSearch.mjs` + a second pass in `probe-statewide-parcels.mjs`.** For every state: query the ArcGIS Online search API for public parcel-shaped Feature/Map Services, triage by title, resolve each survivor's ORGANIZATION, classify the publisher, then MEASURE what survives (geometry type, field list, feature count). Runs by default; `--no-agol` skips it, `--agol-only` runs pass 2 alone (and never writes the doc, since pass 1's cells would be hollow).
- **⛔ THREE TIERS, NEVER TWO, AND THE MIDDLE ONE IS THE POINT.** `official` (a verified state org, or an org whose name both names the state and names a government body) · `review` (parcel-shaped, publisher not positively classifiable — SURFACED for a human) · `excluded` (a commercial vendor, or a positively-identified county/city/school/university). **The measured finding that forced this shape: an organization's display NAME is not a reliable signal of whether it is a state agency.** Resolved live from `sharing/rest/portals/<orgId>`, California's publisher is called **"CAL FIRE"**, New York's **"ShareGIS NY"** and Rhode Island's **"RIDEM - Map Room"** — none of the three names its own state or any government body. A two-way filter therefore DISCARDS the publishers of three states this repo has already wired, and every discard reads downstream as an authoritative `no-free-source`, which is precisely the failure this item exists to correct. `excluded` only ever fires on a POSITIVE marker, never on an absence.
- **⛔ COMMERCIAL CATALOGUE ITEMS ARE EXCLUDED IN EVERY STATE, by publisher.** Regrid's "USA Nationwide Parcel Boundaries" ranks first in nearly every state search (confirmed live); the owner has declined paid data, so Regrid/LandGrid/CoreLogic/ATTOM and siblings are filtered in all 51 rows rather than state by state.
- **⛔ THE VACUITY GUARD IS PART OF THE PASS, NOT AN EXTRA (DRIVER-SCROLL-IS-NOT-APP-SCROLL §6).** A search-and-filter pipeline tightened one notch too far returns a clean, confident ZERO for every state, and nothing downstream can tell that apart from a world with nothing in it. So the pass carries known arms whose answers are known independently of it, checked BEFORE any network call, and it REFUSES to print a score when they fail. It checks three properties: every known-good publisher classifies `official`; every known-good publisher still reaches at least `review` with the registry EMPTIED (the filter can fail to promote a real state source, but must never be able to DISCARD one); and every known-bad classifies `excluded`.
- **⛔ THE ARM EARNED ITS PLACE TWICE ON ITS OWN FIRST TWO RUNS, which is the whole argument for the rule that requires one.** Draft 1 classified purely on organization name and wrote its New York arm from an ASSUMED name; resolved, NY's org is "ShareGIS NY". Corrected, the CALIFORNIA arm was STILL assumed ("California Department of Forestry and Fire Protection") and is really "CAL FIRE", which fails the same heuristic. A name-only filter would have reported a confident clean zero for both states — one of them the state this pass was written to find. Every `orgName` in the file is now a resolved value, and `heuristicOnly` pins each arm's registry-emptied behaviour permanently.
- **⛔ AND THE FIRST FULL 51-STATE RUN REPORTED TWO DEFECTS IN THE PASS ITSELF, both fixed before shipping and both kept as regression tests.** (a) **A registry hit promoted another state's organization:** ArcGIS Online ranks by relevance, not geography, so a search for "Washington statewide parcels" returned FLORIDA's statewide cadastral layer and Utah's county parcels, and a bare registry lookup stamped them `official` under WA. A verified org now promotes ONLY for its own state and is `excluded` elsewhere, naming the state it really belongs to. (b) **County-level layers ranked as statewide:** Utah AGRC publishes per-county LIR layers from the very organization that publishes its statewide one, so no publisher check can separate them — the title is the only signal, and a title naming one local jurisdiction is now excluded unless it also claims statewide scope.
- **⛔ CROSS-STATE SEARCH NOISE IS BUCKETED, NEVER DROPPED, AND NEVER COUNTED.** Every candidate records whether it is linked to the state at all (verified org / org names the state / title names the state / none). Unlinked rows are listed in their own labelled section and left out of the headline count — Canada's cadastre answered searches for Maine and DC. They are not discarded, because the link test is unsound in one direction: **Rhode Island's own statewide layer is titled `Tax_Parcels` by "RIDEM - Map Room" and links to its state through neither.** Dropping it is how a state gets recorded as `Candidate: none found`.
- **THE RESULT OF THE FULL RE-RUN ACROSS ALL 51 (the count this item was asked for): exactly TWO rows changed — California and Rhode Island — and no additional state turned up.** Verdict counts moved from `no-free-source` 20 → 18, `measured-reachable` 15 → 16, `blocked-in-sandbox` 11 → 12. The single new `official + measured-plausible` hit in an unwired state is **Washington** (WA Geospatial Portal's "Current Parcels", 3,321,859 parcels), which is **already on record as declined on LEGAL grounds** — its licence restricts some counties' parcels to "State of Washington business only" — and the brief confirms it stays out pending an owner decision. **Nothing new to file for wiring.**
- **THE SEVEN STATES THE BRIEF ASKED BE RE-CHECKED BY THIS METHOD — Michigan, Iowa, Idaho, Oklahoma, Oregon, Missouri, Georgia — were all re-checked, and every decline STANDS.** A null is a finding, so it is now recorded in the doc as its own table (prior reason for the decline · what pass 2 returned) rather than left to be re-derived by the next session — and it becomes visible if a later run turns one of them green. Iowa's only pass-2 candidate is the same deprecated `Iowa_Parcels_2017` layer already on record; Georgia's is a single county's layer.
- **`FIELD_PATTERNS` correction, found by this run:** `PARCEL_APN` (California) and `PlatLot` (Rhode Island) both reported `parcelId=absent` in the doc while plainly BEING the parcel identifier — `\bapn\b` cannot match inside `PARCEL_APN` because an underscore is a word character, so there is no word boundary before "APN". A doc that reports a real id column as absent understates a source. The app's own live field auto-detect was never affected (these are reporting hints, not authority).
- Proof: 25 unit tests in `test/agolParcelSearch.test.js` covering the pure half with no network — including the vacuity guard mutated BOTH ways (a classifier that rejects everything and one that admits everything each turn it red), the cross-state registry case, and the local-scope title case.
