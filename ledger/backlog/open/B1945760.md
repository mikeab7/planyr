`[x]` **Layout decision, stated and applied, not left implicit.** These are narrow dashboard cards and the labels roughly double in length. Chose: keep the existing single-line ellipsis truncation (the row's flex layout — name `flex:1, minWidth:0` beside a fixed-width count — already holds at any card width with no reflow) and add a native `title=` tooltip carrying the full label, so a truncated name stays reachable on hover/long-press. Applied to `DashboardCards.jsx`'s `ScheduleHealthCard` row, `NeedsAttentionCard.jsx`'s per-row subline AND its footer totals line, and (for consistency, same trade-off) `SinceLastHereCard.jsx`'s subline.
