`[ ]` **Open — NOT built in the Spreadsheet PR, on purpose.**
- **Schedule grid (`public/sequence/index.html` `GridView`).** Does not share `SheetView`'s selection code (its mechanism was lifted from here once, then diverged). Same drag defect: `cellMouseEnter` extends a range only for cells the pointer crosses, and nothing scrolls the grid while the button is held at an edge. A fix is a port of `lib/dragSelect.js`'s idea (pointer → row via the row positions, a rAF loop while at/past the scroll container's edge), not a share of the code. **Ctrl+click** is currently a plain click. Multi-select there is only meaningful for ROWS and every row command (indent / outdent / move / delete, parent–child reparenting, cut/copy) assumes one contiguous block — the file's own header comment (`indentSelection`) states a discontiguous selection "cannot occur" and the code relies on it. Building it means re-auditing every one of those paths, which is its own item.
- **Notes tables.** ProseMirror `CellSelection` is one rectangle by construction, so Ctrl+click cannot add a second range without replacing the selection model of the editor; drag-select past the edge is the browser's own text-selection autoscroll.
- Stopping rule: closes when the owner asks for either behaviour on these surfaces (then build it as its own item), or is superseded by a decision to share one selection engine across grids.
