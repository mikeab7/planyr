`[ ]` **Implemented — see the V# below for the live checks (Verify: live — PDF/export parity + persistence of new model fields).**
- **What shipped.** The inspector for every neutral markup (line · polyline · rectangle · ellipse · polygon · cloud) and for text boxes / callouts is now three sections with the same names on every kind: **TEXT** (text box + callout only; a plain full-width ✎ Edit text button sits above it at the very top) · **APPEARANCE** (closed shapes, cloud, text box, callout = the Outline | Fill table with Colour · Opacity % · Weight · Pattern and a Hatch colour row only while a hatch is chosen; line / polyline = one column) · **SIZE & POSITION** (Area / Perimeter, Width / Height, Margin (renamed from Padding), Arc size, Rotation, Length + Inline label). Easement / deed / measurement / multi-select panels untouched.
- **Owner rulings applied:** line weight shows NO unit (stays an up/down stepper); pattern selects right-aligned (`text-align-last: right`); opacity is a typed % box on every kind (the cloud's two sliders are gone); every Appearance / Size number box fills its column (`NumInput fill`, `PercentField boxed`) so right edges line up. Rotation keeps the shared `RotationStepper` and gains an angle glyph (needle at the current angle), two icon quarter-turn buttons and a **Level** button that exists only while the angle is not 0.
- **Model (additive, absent = today byte-for-byte):** `strike` · `caps` · `valign` ("top" | "middle" | "bottom") on a text box / callout via `lib/calloutStyle.js`, and a fixed height `boxH` (feet) set by dragging the new top / bottom grips and cleared by Fit to text / Alt+Z (same as `boxW`). **valign default is "top"** — a box only ever grows taller than its text when `boxH` is set, so every existing callout is pixel-identical whichever default is chosen; "top" is the Word / Bluebeam convention. All caps is a DISPLAY transform in `calloutLayout` (stored text never rewritten). Line / polyline now carry and render `strokeOpacity`; the cloud now honours a fill pattern.
- **PDF-PARITY:** the export clones the live SVG, so the flattened picture follows. Editable-PDF path (`annotationExtract` / `pdfAnnotations`): strikethrough is drawn in the appearance stream; a FreeText cannot store strikethrough or vertical alignment, so a viewer that REGENERATES the annotation drops them — said out loud as a `degraded` note naming the text box. Caps arrive as the drawn (uppercase) text.
- **Also fixed while here:** the two new grips would have eaten a double-click on the border's centre (CHROME-NEVER-EATS-A-PRESS) — both grip starters now forward the press to the box's own double-tap pairing. The Ctrl+Z slider contract test (`e2e/ctrlz-undo`, B746/V258) lost its slider (the cloud's) by the owner's "never a slider" rule and is retargeted to the one remaining slider (a deed's Fill opacity).
- **Sandbox-verified:** repo-root `test/` **calloutPanelLayoutA** (20: defaults/back-compat, caps display-only, decoration compose, valign math, boxH layout, PDF strike + degraded notes, wiring guards); full unit suite green; e2e **markup-panel-layout-a** (6): every kind × both themes × default and minimum panel width — sections in order, Edit text on top and plain, no "pt" beside weight, pattern selects right-aligned, shared right edge per column, Level only when rotated, quarter turns, no horizontal overflow; a line's opacity writes `strokeOpacity` and the canvas honours it; a text box's strike + caps + bottom alignment persist across reload and render. Ten other callout / markup e2e specs fail identically on untouched main in this sandbox (measured against a clean build of main) — not caused by this change.
