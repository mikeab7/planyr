- **What it is, measured.** With the aerial (or any composited map layer) under the drawing, a slow docked-panel drag changes the anti-aliased FRINGE pixels of the plan's outlines by up to ~29/255 (≈ 4,700–10,000 px of the measured patch), and the change persists at a given panel width. **Nothing moves:** a fringe line's centroid holds to ±0.03 px and the sub-pixel shift estimate is 0.00 device px on every frame. Each layer ALONE is exact (aerial 0 px, FEMA 0 px, drawing 0.00 displacement). It was present at the same magnitude before the B2154768 ×2 fix.
- **Ruled out (measured, do not re-chase):** the drawing's scale (screen CTM exactly 1, viewBox = box); the registration translate (removing it changes nothing); `will-change`/`isolation` on the canvas or the map; GPU raster (`--disable-gpu`, `--disable-gpu-rasterization` give identical numbers); the docked panel's own paint (hiding it changes nothing). It needs a visible map layer UNDER the drawing — with the whole Leaflet container hidden it vanishes.
- **Next instrument:** a CDP `LayerTree` snapshot at two panel widths (the first attempt hung on `layerTreeDidChange`) to see whether the drawing's composited layer changes bounds/raster scale as the canvas narrows.
