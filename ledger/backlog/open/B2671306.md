### B2671306 — Lazy per-state map tables: design + measured sizes (audit batch K) [perf] (task)
- Verify: live
- #perf
Measured 2026-11-23 on main 5f54758: Site route = 2,710 KB across 32 chunks (target 1,563). Minified self-sizes of the per-state pieces: 14 state `*Layers.js` ≈ 330 KB, 19 `*Parcels.js` ≈ 175 KB, `sources.js` + 9 `sources*.js` ≈ 120 KB + ~85 KB, `counties.js` ≈ 123 KB.
WHY NOT A QUICK CUT: every one of these is read SYNCHRONOUSLY at module load. `ALL_LAYERS` (layers.js:1338) is spread from every state layer file and read by LayerPanel, SitePlanner, MapFinder, exportSheet, layerPrefs, layerOpacity, placeNamesSuppress, useDrawnOverlays, useLayerHiddenToast. `GIS_SOURCES` is read at import time by jurisdiction.js (~96 refs), 5 `*Layers.js` files, harrisTaxRates, siteChecksRun, rutherfordJurisdiction. `COUNTIES`/`COUNTIES_MAP` have ~263 refs inside counties.js. DATA-LOSS HAZARD: layerPrefs.js:42 and layerOpacity.js:31,81 DROP any saved key not in `ALL_LAYERS`, so a not-yet-loaded state's saved layer prefs would be erased on first save.
Plan (stage 1 = layers): slim eager index per state layer file (ids, group, states, mergeGroup); `ensureStateLayers(state)` dynamic-imports and `Object.assign`s into ALL_LAYERS/MERGE_GROUPS/LAYER_VINTAGE and bumps a store; prefs sanitisers keep keys whose id is in the eager index; syncOverlayLayers/export await `ensureStateLayers` for every state a saved overlay id belongs to; LayerPanel subscribes. Stage 2 = `*Parcels.js` via countyPolygons.resolveCounty → async resolver with a LOUD "not loaded" state. Stage 3 = sources.js split. Each stage needs a signed-in live GIS check (V#) on a throwaway duplicate plan.
