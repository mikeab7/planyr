### B2671314 — gis-cache relay served upstream HTML/SVG same-origin: one-click session theft [security] (bug)
[x] Pen-test 2026-11-24. `/api/gis-cache/svc/<b64 url>` relays any host matching `ALLOWED_GIS_HOST_RE` (includes whole publishable families: *.arcgis.com, *.usgs.gov, *.epa.gov…) and echoed the upstream Content-Type on planyr.io's own origin, so a link to an attacker-hosted text/html or image/svg+xml item ran script beside the signed-in session. Also followed redirects off the allow-list. Fix: content type rebuilt from an allow-list (json/geojson/raster/protobuf; else octet-stream + attachment), nosniff + `sandbox` CSP + CORP on every response, `redirect: "error"` upstream. Test in test/gisCacheHandler.test.js. Verify: sandbox. Tags: #security #gis-proxy
