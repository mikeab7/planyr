### B2366657 — FetchGIS (Amalgam LLC) runs ~25 Michigan counties' official parcel viewers, and its data server refuses non-browser requests: get an agreed way in `[Site Planner / GIS]` (feature) #site-planner #gis #parcel  *(found by B2366656, 2026-10-20)*
`[ ]` **Open — owner decision.** FetchGIS viewers (`app.fetchgis.com/?currentMap=<county>`) are the official map of Barry, Bay, Calhoun, Clare, Clinton, Delta, Genesee, Gladwin, Hillsdale, Huron, Isabella, Lapeer, Mackinac, Marquette, Mecosta, Midland, Otsego, Saginaw, Sanilac, Shiawassee, St. Joseph, Tuscola and others. Its ArcGIS Server (`app.fetchgis.com/geoservices/fgis/<xxx>Parcels/FeatureServer/0`, named in the viewer's own `main.js`) answers a plain request through the relay with an HTTP 520 reset while the viewer page loads. Reaching it means replaying the viewer's browser identity, which Planyr does not do (same ruling as the Missouri Integrity-token counties). Calhoun, Delta and Otsego have no other source; ~15 wired counties rest on third-party copies a first-party feed would replace.
- **Options:** a data-access request to Amalgam LLC (a signed key or allow-listed relay), or leave as is. Stopping rule: closes when the owner decides; if yes, the first deliverable is one measured county, then the rest in one table.
- Verify: sandbox (once access exists, measured like every other row).

- **Update 2026-10-29 (B2507104, Michigan second pass):** the county sites themselves link FetchGIS for five more counties the first pass had filed "BS&A only" — Chippewa (Eastern UP GIS), Clare, Iosco, Ogemaw (the county also sells the shapefile, $0.15/parcel) and Schoolcraft (the CUPPAD map). They are filed `locked` with the Calhoun / Delta / Otsego wording; an agreement with Amalgam would now unlock eight Michigan counties outright.
