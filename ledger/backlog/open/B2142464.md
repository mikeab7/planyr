- **Fix:** `lib/notesTablePaste.js` (new, pure) + `notesPastePlain.js` + `notesImageNode.js`/`notesAttachNode.js` (stand down for a table) + `notesExtensions.js` (`keep` table attr) + `NoteEditor.jsx` (armed-paste and nothing-focused/box-selected paste now go through the editor's own paste pipeline; a box made for a table is widened; caret is kept inside the box after a table lands). "Keep text only" on a table = TAB-SEPARATED rows (stated choice); Ctrl+Shift+V of spreadsheet text stays text; plain TSV on Ctrl+V becomes a table.
