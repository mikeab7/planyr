### B2270993 — Admin coverage map: clicking a county showed nothing; hover was one hidden line above the map `[Platform / Admin]` (bug) #admin #ui  *(owner chat block 2026-10-15, NEW-2 of three. Minted B2270993 from this branch's block.)*
`[~]` **⏳ Verify — implemented and sandbox-proven; the deployed-build check is V1696128.**
- Verify: live → **V1696128** (no `Blocker:`).
- **Root cause (measured):** the pan handler took pointer capture on pointer-down, so the click's target was the `<svg>` (not the county `<path>`), and the only thing a pick ever changed was the one-line readout above the map — hover overwrote even that, and with the map filling the screen the line was off-screen.
- **Fix (`ParcelCoverageSection.jsx`, `lib/parcelCoverage.js` `countyDetail` / `openRequestsFor`):** pointer capture is now taken only once a press turns into a drag, so a plain click keeps its own target; a press that travels no further than the tap slop is a click and opens a **details card** next to the click (stays until ✕ / Esc / another county; placed and clamped inside the map, `placeNear`). The card shows county + state, the coverage kind in plain words, source name, host, registry key, the layer URL with a Copy button (a failed copy is said), last-verified date, the parcel-ID / address / lot-number field mapping, a collapsed verification note, the "City of X parcels available" block (B2270994), and — for a county with an open County-requests row — the request with a link to `#/admin/criteria`. Not-wired counties say "No parcel source is wired for this county." A real drag still pans and never opens the card; a touch tap opens it (and a browser-claimed touch scroll — `pointercancel` — is never a tap). Hover now shows a small **tooltip at the cursor** (county, state, coverage kind); the readout line above the map is gone. The selected county is outlined.
- **Sandbox proof:** `test/parcelCoverage.test.js` (`countyDetail` for Harris, a city-only county and an unwired county; `openRequestsFor` matching by state + name, wired rows excluded); `ui-audit/verify-admin-parcel-coverage.mjs` (real Chromium, desktop real mouse click with zero movement, and phone-width touch tap): tooltip names county + coverage and sits at the cursor; the card opens with the county's name, states the kind, carries the layer URL / registry key / host for Harris (known-good arm: Harris must read "County's own server" or the run is VOID); Autauga AL says not wired; Esc and ✕ close it; a drag pans and does NOT open it. Red against the pre-fix component.
