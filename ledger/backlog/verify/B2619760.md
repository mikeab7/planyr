- **The gate (`src/shared/turnstile/captchaGate.js`, pure, timers injected, `useCaptchaGate.js` binds it):** a press with a token sends at once; a press with NO token is never blocked — the button reads "Verifying…" and the submit goes by itself when the token lands (Keychain / password-manager fill + immediate tap; Enter does the same); a second tap/Enter while waiting or sending is ignored; the token is dropped and the widget `reset()` after EVERY attempt, pass or fail (a wrong password burns it, so typo-then-right works); expired tokens are refreshed by Turnstile (`refresh-expired: auto`) and a press in the gap waits for the new one; a blocked script (10 s), an error callback, or no token within 15 s ends in plain words ("We couldn't run the browser check. Check your connection, then try again.") with a working **Try again** that re-renders the widget — never an endless "Verifying…" (a visible challenge stops the clock; Cloudflare's own `timeout-callback` ends it).
