### B2146546 — Undo of a Delete made before the delete reaches the cloud is lost: screen shows restored + "Synced", cloud keeps it deleted, reload drops the elements `[Site Planner / sync]` (bug, HIGH — silent data loss) #site-planner #sync #persistence  *(AUTH-SWEEP 2, V182 step 1, build 1142833, reproduced 4×)*

**Repro:** signed in on planyr.io, a plan with 1–3 synced buildings. Select (click, or Select-multiple marquee), press Delete, then Ctrl+Z within ~0.3–6 s (before `site_elements` shows `deleted_at`). **Observed:** elements reappear, badge reads Synced; `site_elements` rows stay `deleted_at` set (`op_kind` delete), no restore write follows (waited 44 s); after reload the elements are gone. **Control:** wait until the row shows deleted, then Ctrl+Z — the restore persists (rev bumped). **Suspect (unconfirmed):** `docs/DATA.md` invariant 4 (undo drops buffered upserts, keeps buffered removes) applied to the user's OWN just-buffered delete — the undo cancels the local op but the buffered remove is still flushed. **Stopping rule:** closes when Delete→Ctrl+Z at 0.25/1.2/6 s persists across reload on the test account (add e2e). Owner-facing: data loss — fix this session if tractable (see status below).
- Verify: live — drive the repro above signed in on the deploy.

`[x]` **Root cause (confirmed by a red unit test on untouched code):** the delete is flushed immediately, so the real window is "delete IN FLIGHT". `reconcile()`'s diff saw shadow json === canvas json after the undo and produced nothing; the delete then landed and nothing followed it, while the canvas (and badge) said restored/Synced. Not the remote-tombstone rule of DATA.md invariant 4 — that is untouched.
`[x]` **Fix (`elementSync.js` reconcile, seen-branch):** an undo of a delete WE queued cancels the queued delete; one already on the wire is followed by an explicit `restore` op (the serializer orders it after the delete). Tests: `test/elementSyncUndoDelete.test.js` (in-flight case RED on the pre-fix engine, green now); 152 sync/multiwriter/undo tests green.
