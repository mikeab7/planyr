- **Report.** Owner-set defaults for all new users: parcel OUTLINE indigo, SETBACK band indigo, and the setback chip — currently orange border and orange text sitting on an orange band — **black border and black text** (he considered purple and corrected himself to black). Existing per-site colour overrides must be respected, not stomped.
- **The fix.** `--canvas-parcel` and `--canvas-setback` now resolve to a new `--indigo` alias, and the alias is **not a new hue**: it is the value the design system already carries for its indigo text tokens (`#534AB7` light, `#AFA9EC` dark — the light-on-dark variant so it stays legible on the dark canvas and a dark aerial). It gets a neutral name because it is now a DRAWING colour, not a module accent, so the two can never be coupled by accident. The JS palette mirror (which SVG attributes must read, since `var()` does not resolve there and would not survive export rasterization) is updated in the same commit.
- **The chip.** Border and numerals default to a new `--canvas-chip-ink` near-black; the plate is white in BOTH themes, so the ink is deliberately fixed rather than theme-swapped. **B1100's override survives untouched:** a parcel whose setback line has been explicitly recoloured still takes its chip with it — the black is the DEFAULT, not a hardcode, and the "recolouring the line takes its numbers with it" behaviour is exactly what an explicit override is for.
- **Nothing existing is stomped.** These are render FALLBACKS: a parcel carrying its own `stroke` / `sbStroke` keeps it, `parcelDefaultStyle` still stamps only what the user actually customised, and the colour stays overridable everywhere it already was (per parcel and in Standards → Parcels).
- **Verified here.** The theme contrast audit (which parses the real `index.css`, resolves `var()` aliases and checks every defined token pair in BOTH themes) passes; the e2e setback-style spec and the parcel-selector harnesses were repointed off the retired hexes onto stable `data-testid` selectors, so a future palette change cannot silently break them again. Harness reads the live DOM: outline `#534ab7`, setback ring `#534ab7`, chip border and numerals `#15171c`. lint 0 · full suite green · build green.
- **What the sandbox cannot prove (→ V547):** that indigo stays legible over the real Esri aerial AND the USGS topo basemaps at working zoom, in both themes. A dark-grey headless canvas is not an aerial photograph.
