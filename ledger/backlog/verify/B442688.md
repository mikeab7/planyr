**WHAT THE HARNESS FOUND, which is the part worth reading.**
1. **A real bug in this very work: hiding Parcels left every acreage badge on screen.** The badges are built from `parcels`, not `drawParcels`, so the draw-seam filter never reached them — and the badge carries `data-feature="parcel:<id>"`, so by every reading the parcel was still on the plan. A group that hides an object must hide its chrome, or "hidden" means "mostly hidden". Fixed at the chip list.
2. **The harness's own first cut was measuring the wrong thing, and it failed LOUDLY rather than passing.** `panelText` scoped to `[data-surface="planner"]`'s nearest `div`, which resolved to most of the page — so the "numbers" being compared included canvas element labels, the acreage badges and the View menu's own chrome. Six checks went red on a working implementation. The metrics region is now `data-testid="yield-metrics"` and the read returns **null** when it is not on screen, so "the panel was not open" can never masquerade as "the numbers did not move" (two nulls compare equal — that trap is closed by an explicit setup check, which then caught the *next* one: the left dock starts CLOSED on every load, so 25 checks had been comparing `null === null`).
3. **The mutation proof.** Move the filter one seam earlier — filter `els` before the metrics pass instead of at the draw set — and the canvas is **pixel-identical** while `Buildings 62.13 ac · 24%` becomes `Buildings 0.00 ac · 0%` and open space silently gains 62 acres. The harness goes 33/33 → 28/33 and names the moved number. No visual test in this repo could see it.

**Also closed:** hiding a group now clears any selection into it (the handle layer renders from `sel`/`multi`, not the draw sets, so grips would otherwise float over ground with nothing under them), and a MARQUEE cannot catch what he cannot see (the three box-select passes read the raw model, so a box over a plan with markups hidden would have handed back invisible objects — and the next Delete would have taken them).

**Persistence:** `settings.hidden`, a SPARSE map naming only what is hidden, so a plan saved before this gains no keys and renders byte-identically, "show everything" is a DELETE of keys rather than eight `false`s, and an unrecognised key from a newer build degrades to visible.

**Glanceable, as he required** ("a plan that silently hides half its content is worse than one that never hid anything"): the collapsed View header turns amber with a struck-through eye and NAMES what is hidden — `Buildings, Markups hidden`, degrading to `4 groups` past three — and the open card repeats it with a one-click **Show all**.
