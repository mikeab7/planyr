- **FIX (one rule, two seams):** `parcelQueryWire.ensureFeatureIds` (B2416496 / #2490 landed the SAME root-cause fix independently, in the outline worker, which every answer passes through) gives a feature with no id its OBJECTID-like property, else a stable geometry key — never a shared `undefined`; a server that DOES send `id` is untouched. This item's display-layer call in `parcelDisplay.js`'s `_addFeatures` is the second seam for an answer that reached the layer WITHOUT the worker; its own duplicate implementation was deleted so there is ONE function. This item's e2e proves it end to end at the layer. Fixes every FeatureServer county with the same shape (the pass-2 Tennessee counties among them).
- **RED-PROOF:** e2e `e2e/parcel-display-no-feature-id.spec.js` — a mock that answers exactly like the real server (no `id`): **on `ff7be38` built locally: "held 1 lots of 144 served over 15 queries" (red); on the branch green** (`held` = every lot, `drawn` = held).
