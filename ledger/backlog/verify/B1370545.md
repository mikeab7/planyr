`[x]` **FIXED THIS SESSION, and it needed no coordinate migration.** The stored origin is unchanged — it is still the body's own top-left, so every existing note keeps its numbers — and what changed is that a NEGATIVE `y` is now legal and the SHEET grows upward to hold it (`anchorExtentTop`). An anchor above the body's origin renders into the title band, which is where the title is, so "level with the title" is simply a negative `y` and needs no new frame of reference. Moving the stored origin to the sheet instead would have meant rewriting every anchor's `y` by a chrome height that changes with the window, the phone breakpoint, and whether a page has a project badge — a migration whose input is a rendered measurement, which is the shape of bug this module keeps hitting.
- ⛔ **CORRECTED BY B1433856 (2026-09-09) — the next two bullets described the ORIGINAL mechanism, and the owner's own account proved it a dead zone, not a saving.** "An anchor above the body's origin renders into the title band, which is where the title is" was true literally: `note-title`'s `<input>` is `width: 100%` always, so a box landing there rendered BEHIND the title's own input, and a real click on the shared pixels focused neither element (`document.activeElement` stayed `BODY`) — a permanent, reload-surviving dead zone, not a working placement. **B1433856 replaced the mechanism**: the GAP after the band (`TITLE_BAND_GAP`) grows instead of the sheet's padding-top, so a box that would have landed in the band now renders in the fresh space that opens up below it — still no coordinate migration, still the same stored `y`, but never sharing a pixel with the title again. See that item for the full correction; the two bullets immediately below are KEPT for the historical record of what this item originally shipped, not as a description of current behavior.
- **THE GROWTH BUDGET IS MEASURED, NOT ASSUMED, AND IT IS OUTSIDE THE FEEDBACK LOOP** *(superseded — see the correction above; `growTop` no longer credits the band's height at all, and the band's own ref is no longer read by this measurement)*. A box only escapes the sheet once it reaches above the sheet's own top padding PLUS the title band's height, so `growTop` subtracts both.
