- Origin: filed 2026-08-09 from chat; shipped the same session.
- **THE SYMPTOM READS AS A BROKEN UNDO, WHICH IS WHY IT IS ITS OWN ITEM.** `startMoveEl` called `pushHistory()` on pointer DOWN, before a pixel of movement, so a run of ordinary clicks left a run of identical snapshots on the stack: press Ctrl+Z after a few clicks and the first several presses restore state that is already on screen. Nothing looks like it happened.
- **THE SWEEP the owner asked for.** Every drag start that pushed on the press now defers to the gate's arming frame (`histOnArm` → `pushHistory()` once, on the frame the drag begins): 26 of them, from the element move down to the sheet-overlay rotate. The remaining ~180 `pushHistory()` call sites were audited and are correct as they stand — they fire on a COMMITTED change (a menu action, a property commit, a paste, a finished draw), not on a press. B1327/NEW-4's private latch on the acreage chip is **deleted**, not duplicated: the shared gate now owns it for every drag and defers past a travel test rather than firing on move #1.
- **AND THE FRAME THAT MUST NOT BE DROPPED.** `cancelActiveMove` (B315's Esc/abort revert) called `histRef.current.drop()` unconditionally. With the frame no longer pushed on the press, an aborted gesture that never armed would have dropped the PREVIOUS, unrelated command off the stack — the same pollution in the opposite direction. It now returns early for an unarmed gesture.
- **THE WRITE PATH, his second clause.** Because the gate returns before any branch, a plain click produces no `setEls` at all — so nothing bumps the element's `rev` / `updated_at`, and a click can no longer read as a foreign edit to another tab or device. Proven locally (the persisted record is byte-identical across a tremor click); the signed-in row-level half is V93568's remaining step.
- **PROOF.** `test/dragGate.test.js`'s NEW-2 wiring guard fails if any gated drag start pushes history in its pointerdown handler (mutation-proven), and `e2e/click-never-moves.spec.js` drives the owner's exact sequence: draw → one real drag → five plain clicks → **one** Ctrl+Z returns the building to its pre-drag position.
