- **The real rule (found in code, not assumed).** The funnel button was drawn only when `task.hasChildren && task.isExpanded && task.hideableCount > 0` (`public/sequence/index.html`, the Task cell). `hideableCount` = how many DIRECT children have a whole subtree that is all done / paused / not-started. So a row lost its button whenever (a) it was COLLAPSED (Alternates), or (b) NONE of its children was hideable — every child in progress / needs-attention / blank-status (Testing Consultants: Concrete, CMT, Roofing all active; CMT: its one child active). The three rows that "had it" (Construction, Contract, Bidding, Debt Placement, Closeout, Chambers County) happened to have a finished or not-started child. The owner's guess about the status-count pill was a red herring: that pill is the button's own focused-state breakdown, so it is a *consequence* of the button, never the condition. A side effect of the old rule: a group left Focused whose children all became active lost its button while Focus stayed ON — no way to turn it off except Alt+F.
- **The fix — one definition.** `focusGroupIds(tasks)` = the ids that have at least one child. It now feeds `hasChildren` on BOTH grid lists (the Focus-aware list and the review list) and Alt+F's `focusToggleTarget`; `rowCanFocus(row)` = `hasChildren` on the Focus-aware list is the one test the chip is drawn on. Whether anything is currently hideable decides only the tooltip (`focusChipTitle`: "Focus: hide completed / paused / not-started tasks here — none right now (Alt+F)", every variant keeps the established "Focus: hide" / "Show all tasks" prefix other harnesses key on) and Alt+F's existing "nothing to hide in it yet" toast — never whether the control exists. The review list ignores Focus entirely, so it still draws none. There is no Focus entry in any right-click menu (checked), so nothing else needed the rule. Alt+F already worked on any row with children; it still does, and now agrees with the button by construction. Clicking the button on a group with nothing to hide flips the same `focused` flag through the same `updateTask` (one undo step), hides nothing, and will hide rows the moment one finishes.
