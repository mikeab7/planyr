- **WHY A RAW SIMILARITY SCORE CANNOT FIX THIS — measured directly against production before choosing a design.** The Cowboy query's own top candidate ("Kansha Japanese Sushi Bistro") scores word_similarity 0.615 — no single cutoff separates that from a genuine match: a real typo'd match scores LOWER in a real case ("chiptle" → "Chipotle" scores 0.545) while OTHER garbage scores HIGHER ("chilis restaurant" → "El Viejo Solis Restaurant Corporation" scores 0.777, because 3,225 of the snapshot's 82,310 names contain the single word "restaurant"). word_similarity() rewards the best-matching SPAN of the query, so a query with one missing distinguishing word can still score high against a name sharing only its generic descriptor.
- **THE FIX — "strong match" is WORD COVERAGE, a named, tested, documented rule (`src/workspaces/food/lib/searchQuality.js`), not a magic number.** `isStrongMatch(query, name, address)`: strip generic restaurant-domain words (`GENERIC_NAME_WORDS` — measured: "restaurant" in 3,225 names, "grill" 3,533, "bar" 3,802, "kitchen" 1,847, "cafe" 3,131, "house" 1,452, "drive" 578), then require every (or, past 3 words, 75% of) remaining distinguishing word to appear — typo-tolerant (`EDIT_DISTANCE_TOLERANCE`, length-scaled Levenshtein) and prefix-tolerant ("mcdon" → "mcdonald's") — somewhere in the candidate's name OR address (so a location-qualified query like "fadis westheimer" still resolves against the street). Verified against every production case gathered this session: the Cowboy garbage (0 of 4 sampled candidates pass), "chilis restaurant"/"wendys drive thru"/"taco bell mexican" garbage (all correctly rejected, unlike a raw-sim cutoff would), and every genuine typo'd match this session found ("chiptle"→Chipotle, "mcdon"→Mcdonald's, "olive gardn"→Olive Garden, "whataburgr"→Whataburger, "bandito taco"→Bandito's Taco Grill, "panda expres"→Panda Express) all correctly pass.
