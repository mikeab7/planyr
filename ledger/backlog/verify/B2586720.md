- **Flags.** A `SheetInterceptorService` CELL_CONTENT interceptor (the route indent uses) puts Univer's own corner marker (top-left triangle) on each flagged cell; the same `InconsistencyPanel` as the old grid lists them, a row jumps the selection, Dismiss is a Planyr mutation with its inverse on Univer's undo stack (one Ctrl+Z brings the flag back; the dismissal is saved through the sidecar).
- **Trace.** Toolbar buttons (Formulas tab, first in the strip) start / step Trace Precedents / Dependents for the active cell (a second click goes one level further, as in Excel); arrows are drawn on the canvas by a `SheetExtension` registered on the sheet component (dot at the precedent, dashed box for a range, arrowhead at the dependent's edge, labels for links that leave the sheet), so they scroll and zoom with the cells; Escape or any edit that can change dependencies clears them.
- **Palette.** Ctrl+K (stays THE palette) opens the SAME `CommandPalette` component fed the registry's commands routed through `ICommandService`: tool commands → the Excel-keys plugin's `planyr.excel.<id>` → Univer-native ids (undo/redo, find, replace, zoom, add/remove sheet) + a few Univer extras; "Number Format: …" rows and merge-toggle have their own routes. Every registry command is routed or NAMED as a gap with its reason (`PALETTE_UNAVAILABLE`; a unit test fails otherwise).
- **Name Manager.** The same `NameManager` component; define / retarget / delete are Univer's `SetDefinedNameCommand` / `RemoveDefinedNameCommand` (local to the sheet, same id shape the bridge loads), a rename's formula rewrites (the old grid's `renameName` rule) ride in the SAME undo group, so one Ctrl+Z reverts name and formulas.
- **Colours.** Typed input blue, cross-sheet link green, ordinary formula keeps the text colour; a colour the person set always wins; ON by default per the old grid, toggle on the Formulas tab (same per-project preference key as the old grid), drawn at render time — nothing is written into cells.
