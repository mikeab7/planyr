- **⛔ THE BLOCKER, stated first because it is the one thing a reader must not miss.** The dispatch required the WQCV and EURV equations to be read **from the source manuals with section numbers cited**, and explicitly forbade reconstructing them from memory. **They could not be read.** Every primary host — `mhfd.org`, `mhfd.specialdistrict.org`, `old.mhfd.org`, `fcgov.com`, `denvergov.org` — answers **403 to CONNECT at the egress gateway**, and the fetch tooling 403s on *every* host including unrelated ones (Wikipedia), so this is an environment limit, not a bad URL. Web search reaches the open web but returns a **model summary** of a page rather than its text, and **two independent search reads of the SAME UDFCD EURV memorandum returned two DIFFERENT coefficient sets** (`0.140 / 0.113 / 0.100` vs `1.68 / 1.36 / 1.20`). That disagreement is the proof the numbers cannot be transcribed at second hand. Per the dispatch's own instruction — *"if a needed equation cannot be read from an accessible source, say so loudly and ship that part as unavailable rather than approximating"* — **no coefficient was invented.** The `OWNER-TODO.md` entry is the unblock: four PDFs, downloadable from any ordinary browser.
- **WHAT DID SHIP, and why it is an engine rather than a stub.** New `ruleType: "volume-curve"` + `lib/mhfdDetention.js` (lazy, joins the Colorado `coTier` chunk — a Texas user downloads none of it):
  - **WQCV and EURV are DISTINCT components**, never collapsed: each carries its own `role` (`water-quality` vs `flood-volume`), its own `depends` list, its own evidence state and **its own citation** (they come from different documents), plus the routed 100-yr as a third component with `method:"routing"` — because a routed volume is not a coefficient anyone could look up, and saying so is the honest answer rather than a gap.
  - **The MATH IS REAL and tested.** `wqcvDepthIn` / `eurvDepthIn` / `depthInToAcFt` / the combiner are exercised against **synthetic** curves with hand-computed expectations (the full cubic, the soil-group area weighting, C/D folding, clamping, monotonic drain time). So the code is verified independently of MHFD's real numbers, and **transcribing them later is a DATA edit** — one object literal per component, no code change, no new dispatch.
  - **Per-component evidence states, with different cures.** `unavailable` (`source-unreachable` for WQCV; **`source-conflict` for EURV**, because it is worse off than merely unreachable; `requires-routing` for the 100-yr) vs `needs-input` (curve present, imperviousness / soil group / drain-time election missing). Conflating a missing CRITERION with a missing USER INPUT is how a data gap gets mistaken for something the reader can fix.
  - **`rateAcFtPerAc` is ALWAYS null.** A full-spectrum volume has no per-acre rate; back-computing one to fill the Texas badge would invent a criterion MHFD does not publish. `ruleBadge` names the METHOD in that slot instead ("full spectrum (WQCV + EURV)").
  - **Release rates and outlet configuration** are declared present-but-NOT-transcribed, so Planyr's Texas outlet model is never quietly applied to a full-spectrum basin.
- **THE C.R.S. 37-92-602(8) RECONCILIATION — the two features AGREE rather than contradict.** MHFD asks you to hold water; Colorado water law asks you to let it go, so a site can satisfy its drainage criteria and still be an out-of-priority diversion. `reconcileMhfdDrawdown` reads the 72-hour limit **out of the statute record** (never a hardcoded 72) and **borrows the statute module's vocabulary** — `fail` / `not-ruled-out` / `unknown`, never "pass" or "complies", asserted in the suite, because `drawdownStatute.js` deliberately refuses to say "pass" and a second module claiming compliance about the same statute would contradict it on screen. With no drain time elected it answers for **all three options at once** ("all 3 options (12, 24, 40 hours) sit inside the 72-hour limit") rather than assuming one — a silently defaulted drain time would drive a statutory verdict off a number nobody chose. And it names the honest half: **the EURV release above the water-quality zone is the term that could actually collide with the statute, and it is the one Planyr cannot size.**
