- **THE BUG, exactly as diagnosed.** `resolveCountyLayer` resolved the site's parcel-identify layer URL ONCE, on first use (`if (idLayerRef.current) return idLayerRef.current;`), keyed on `siteCounty` — the county recorded when the site was CREATED — with a `COUNTIES_MAP[siteCounty] || COUNTIES_MAP.harris` fallback. Three compounding defects: it never re-asked as the view panned across a county line; it cached the answer for the whole planner session even after crossing one; and an unconfigured/unresolved county silently fell back to querying **Harris County, Texas** forever — the identical wrong-but-plausible default `candidateCountiesForPoint` was already fixed against, surviving here in the ONE place the Map view's fix never reached. Because the SAME URL backed both the lit outlines and the click query (the B137 rule, deliberately preserved), the outlines went dark too — exactly the owner's "the parcels didn't show up," not merely "the click failed."
- **THE FIX (`SitePlanner.jsx`).** Replaced the single frozen `idLayerRef`/`resolveCountyLayer` with a per-county URL cache (`countyLayerUrlsRef`, `resolveOneCountyLayer`) shared by both consumers, and a `candidatesAtPoint(lat, lng)` helper that routes every click through the SAME `candidateCountiesForPoint` + `filterHealthyCandidates` the Map view already uses — re-asked fresh for every point, never pinned to the site's recorded county, and with **no county fallback of any kind**: an unconfigured area returns no candidates rather than a wrong-but-plausible one. The lit outline effect now lights up every configured county's outlines (mirroring exactly what `MapFinder` already does — resolve every county, add every one's display layer) instead of only the site's recorded one, so panning across a county line shows that county's lots instead of nothing, and the click routes to whatever the point is actually in.
- **B137 kept intact, deliberately.** Outlines and the click query still share one routing decision (`candidateCountiesForPoint`) and one URL cache — they cannot drift into "I can see it but I can't add it" by construction, the same guarantee the original comment described, just no longer pinned to one county.
