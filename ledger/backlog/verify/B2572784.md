`[ ]` **⏳ merged — V2028480 PENDING (live check on planyr.io, test account).** Univer 1.x has no indent field and no indent command (spike finding), **but** its cell style has a padding field `pd` that the renderer honours for plain text, spill and shrink-to-fit — and `pd` is on the short list of style keys Univer's commands keep (a custom `ind` style field was tried first and is silently stripped by `SetRangeValues`; measured). So:
- **Stored** as the cell's own `pd.l = 2 + 14·N` (N = 1..15), one number on the cell's Univer style, which travels with its cell through insert/delete, sort, drag, fill, copy/paste and the format painter — so it is NOT in the bridge sidecar any more (the old sidecar `indent` map is removed: one source of truth). `lib/univerBridge.js` maps it ⇄ Planyr's `styles[key].indent` (MAPPED key; `indentOfStyle` / `storedIndentStyle`).
- **Drawn** by a render-time interceptor (`SheetInterceptorService`, `CELL_CONTENT`, Style effect) in the new `lib/univerIndent.js` that projects the stored number onto the READING side only (left for left-aligned / general, right for right-aligned, none for centred), clamped so it can never exceed the column — the old grid's numbers (`cellTextLayout.INDENT_STEP_PX`, cap 15), so a sheet indented in either grid shows the same in both. Nothing derived is ever saved: an alignment change or a column resize cannot leave a stale padding.
- **Controls:** Decrease / Increase Indent buttons on the Univer Start tab beside alignment, with the old Ribbon's icons, and two command ids the Excel-keys plugin can bind (Alt H 5 / Alt H 6): `planyr.sheet.command.decrease-indent` / `planyr.sheet.command.increase-indent` (`INDENT_COMMAND_IDS`). Each click is ONE `SetRangeValues` = one undo step; every selected cell steps from its OWN level (old grid's `adjustIndent`). Registration in `UniverSheet.jsx` is one `installUniverIndent({...})` call after the first workbook loads (the sheets services exist only then).
- **Verified in the sandbox:** `test/modelUniverIndent.test.js` (the pure rules; step/cap/side/clamp agree with the old grid's `cellPadding`; the Goose Creek shape round-trips; old-grid Increase Indent ×N ⇄ Univer at every level) and `test/modelUniverBridge.test.js` (indent on the style, follows its cell when Univer shifts rows, a change made inside Univer comes back, junk padding never becomes an indent) — red on main's bridge; `ui-audit/verify-univer-parity.mjs` check `indent` with real mouse + keystrokes and pixel sampling: left edge +14 / +28 per click and back, saved workbook indent 2, one Ctrl+Z per click, right-aligned inset on the right (−28), centred unchanged, a long label still spills into its empty neighbour, a deep indent in a narrow column never paints into the next column, indent follows its cell through a column insert, survives editing its text and real Ctrl+C / Ctrl+V — and FAILS on main ("no visible toolbar button"); also fails (right / centred) with the interceptor removed.
