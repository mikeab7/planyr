- **The paste box is SHARED, not rebuilt** — `CompEntryGrid.jsx`'s existing textarea + commit-summary block was factored into one `pasteBoxNode`, rendered identically by both the desktop table and the new mobile sheet, so a paste behaves byte-identically regardless of which layout is showing (mobile has no separate create surface — a phone session gets comps the same two ways a desktop one does: paste, or a map pick).
- **The "arm a row, then tap the map" flow needed a real fix, not a copy of the desktop's docked-panel trick.** The desktop sheet leaves the map visible by docking to the bottom edge; a transposed one-field-per-row sheet needs the whole screen, so it renders full-viewport (`position:fixed; inset:0`) — which would make the map completely unreachable the moment a user taps an unset Location row. Fixed with a local `minimized` state in `CompEntryMobileSheet.jsx`: the instant the CURRENT row becomes armed (`armedRowId` prop matches it), the full sheet collapses to a slim bottom banner ("Tap the map to drop the pin… Cancel"), leaving the map fully visible and clickable above it; the sheet restores automatically the moment the pick lands (`armedRowId` clears) or Cancel is tapped. Purely local to the new component — `CompsPanel.jsx`'s own `armedRowId`/view state is untouched.
- **`compMobileLayout.js`** (new pure lib) is the one place deciding which fields show in which section per comp type — reads `SHEET_COLUMNS` from `compSheetColumns.js` (the same model the desktop sheet uses) so a mobile field can never mean something different from its desktop counterpart, and a future column addition is picked up by both layouts automatically. Unit-tested (`test/compMobileLayout.test.js`, 14 tests): section membership per type, the pinned-section order/count, and the jump sheet's status-text wording.
- Every edit on mobile still commits through `CompEntryGrid.jsx`'s existing `commitRows`/undo stack (`commitFieldEdit` — new, mirrors `finishEdit`'s own commit branch; `setRowToday`/`resolvePeriod` reused verbatim), so the two layouts can never disagree about what a comp is.
