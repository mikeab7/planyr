`[x]` **Defects fixed (all six the owner confirmed from a screenshot).** (1) **Pinned flash** — pinned ids arrived from an async account-prefs load, so the list painted in plain recency order and jumped a beat later. They are now read SYNCHRONOUSLY from the on-device mirror of the SAME store (`planyr:userPrefs:v1` → `sitesPanel.pinned`, `projectSwitcherModel.readPinnedFromMirror`) at mount AND in the same batch that opens the dropdown; the async `refreshPins` still reconciles with the account row but is a no-op unless the cloud genuinely disagrees. The mount effect also warms it so the mirror is fresh before the first open. (2) **Calendar icon drift** — every row's right cluster is now four fixed-width slots (pin · calendar · time · menu), the calendar slot always reserved. (3) **Sort** — both groups sort by ONE field, `lastOpenedAt(p, opened) = max(when this device last opened it, its last-saved time)`, and the time on each row is derived from that same function, so sort key and label cannot disagree. "Opened" is recorded on a row click and whenever the routed project changes (`noteProjectOpened`, `planyr:projectOpened:v1`, capped at 500 entries, device-local). (4) **Two scrollbars** — `AnchoredMenu`'s own `overflowY:auto` is overridden; the panel is a flex column with ONE scrolling list. (5) **Footer** — `+ New project` and `Recently deleted (N)` are a flex-none footer, always in view; the link opens the existing restore view IN PLACE of the list (back button returns), so the footer never leaves. (6) Pin icon on the left of the name and the loud `current` word are gone.
