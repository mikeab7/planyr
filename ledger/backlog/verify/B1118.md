- **Repro.** A real tear of ALL eleven children 236 ft west / 180 ft north of an **882 × 510** host **survived a full reload** on the B1114 build.
- **Root cause — TWO holes, both found by the owner.** **(a)** `strandedFromHost`'s reach is `halfDiag(host) + halfDiag(child) + extraReach + slack`, and `halfDiag(882×510)` is **509 ft on its own** — so the bigger the building, the bigger the tear it tolerates, which is backwards. **(b)** `normalizeStrandedZones` only walked the `prevZone` / `forCourt` / `forTrailer` chain from a `truckCourt`-tagged head, so a stack member on no recognised chain was skipped entirely and never reached `offAnchor` at all.
- **Fix.** The per-kind **computed anchor** is now the primary test for every stack-like bonded child: the head set is every bonded, stack-like, non-dog-ear child that nothing else is stacked behind (by either bond), each walked as a chain — of one, if that is all it is — rooted at its own side. The anchor does not scale with host size, so an 882 ft building tolerates exactly the same few feet of slop as a 200 ft one.
- **Third hole, found while fixing this and reported here rather than quietly patched: MY TWO FIXES WERE FIGHTING.** The load-time heal repairs the canvas, and then B1113's rows-canonical-on-seed adopted the **torn rows straight back over the repair** — the broken copy winning by design. `reconcile` now takes an `exempt` set and `refetchReplace` passes the healed ids, so a repair diffs and **commits** instead of being reverted. This is very likely why the owner saw the tear survive a reload even though the healer's own unit tests were green.
- **Tests.** The owner's exact case — an 882 × 510 host with every child translated 236 ft — all re-fit on load and all are reported; the same large plan untorn returns **byte-identical** (no churn on a big building); a stack member on NO chain is anchored (it used to be skipped) yet left untouched when correct; and a healed element is exempt from rows-canonical while a non-exempt stale divergence is still overruled.
- **What is still owed (V516).** A reload of a deliberately torn real plan on a large building, confirming the repair now sticks — and that a healthy plan still reports no heals.
