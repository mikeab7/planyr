The top-level `computeTimeOfConcentration({ areaAcres, impPct, lengthFt, slopePct, criteria })` resolves L/S from real inputs when supplied, falling back to the area estimate / a configurable default slope (1.0%, a flat-industrial-site screening convention) otherwise — each fallback explicitly flagged (`lengthEstimated`/`slopeEstimated`), never silently substituted.
- **Every coefficient is CRITERIA-CONFIGURABLE, not an inline constant** — four new fields (`tcFloorMin`, `tcDefaultSlopePct`, `tcUrbanAdjustment`, `tcFlowPathKFactor`) added to every jurisdiction row in `detentionCriteria.js` (`waller`/`bkdd`/`fortbend`/`harris`/`coh`/`montgomery`/`chambers`/`generic`), threaded through `criteriaFor()`, overridable exactly like every other criterion.
