- **The trust rule is a DECLARED REGISTRY, not a convention** (`lib/siteChecks.js` `TRUSTED_CHECKS`): FEMA 100-/500-year + NWI wetlands = all regions; RRC wells + RRC pipelines = Texas only. `test/siteChecks.test.js` asserts each row's regions equal the GIS registry's own `SOURCE_STATE_SCOPE`, so the two cannot drift. Outside its regions a check drops to a layer pill; **Colorado wells get no verdict** (ECMC unwired — and no wells pill either, because no non-Texas wells layer exists yet).
- **Severity is by LOCATION, not presence.** Red = ON the site (1% floodplain area inside the ring · mapped wetland inside · pipeline crosses/touches the ring · a well on the site). Amber = near or a lesser on-site trigger (0.2% floodplain on the site · pipeline within ¼ mi not crossing · well within ¼ mi). Green `None` = checked, nothing within the radius (`None within a quarter mile`).
- **RADII / TOLERANCES — all in one place (`CHECK_THRESHOLDS`, siteChecks.js), stated for the PR:** near radius **¼ mile** (the existing `ANALYSIS_SOURCES.oilgas.bufferMi`, now read from the boot-safe leaf `siteCheckRadius.js`; pipelines had none and adopt it) · "on the site" = within **1 ft** of the ring (both sides project through the same grid, so a pipeline that truly touches agrees to well under a foot, while a schematic RRC route a few feet off still reads "near") · overlap dust **25 sq ft** (a 0.01-acre wetland is 435 sq ft and still counts) · FEMA coverage floor **98%** (see below) · server buffer padded **150 ft** past the radius, exact cut made client-side · proximity cap **200** features before the unbuffered on-site pass · **6** result pages.
- **Measurements built (the core of the item):** flood % of site = AREA fraction through clipper on the real rings (never vertex sampling); the SITE's save-and-except holes are subtracted from numerator AND denominator; a FEMA polygon's own interior rings stay holes; shaded-X is netted against the 100-year first so an AE area a 0.2% polygon also covers is counted once. Wetlands = acres of the union ON the site + count of wetlands that put real ground on it. Pipelines = nearest distance from the site LINE, prefixed `~` (T-4 routes are schematic), operator names title-cased, direction from the nearest POINT on the line (not the nearest vertex). Wells = on-site count, then within-¼-mi count, with a status mix. A crowded answer triggers a second unbuffered ON-SITE query so a crossing cannot hide behind 200 near-misses.
- **Failure is a first-class state, never silent, never green.** Timeout / HTTP 5xx / network / ArcGIS `{error}` body / a 200 with no `features` array (a bad query answered politely) / polygons with no geometry / results still truncated after the page cap → the row reads `Couldn't check` with a Retry (re-asks ONLY that check, bypassing its stored answer). Even a failure with an OLDER stored copy behind it is a failure, never a stale verdict. One source's outage never takes the others down.
- **Judgement call worth the owner's eye — FEMA publishes the ALL-CLEAR (unshaded Zone X) as polygons, so ground with NO polygon is ground FEMA has not mapped.** A site with under 98% mapped coverage (or any Zone D) therefore reads amber `Not fully mapped`, never `None`. The old screen read an empty answer as "No mapped SFHA".
- **Region gate leak found and closed while building it:** `siteState()`'s "TX" is a generous BOX — it contains Shreveport, Roswell NM and Lawton OK, where the RRC knows nothing, so a green "None" would have been a false clean. The RRC checks additionally require the point to sit inside a hand-simplified `TEXAS_OUTLINE` (a hair INSIDE the borders: a border-town site only ever loses a verdict, never gains a false one). Strictest reading on a straddle: every sampled point of every ring must be in the check's regions.
- **Hover/open a row highlights its layer, transiently (`lib/layerFocus.js`):** the planner draws from a DERIVED overlay copy (`syncOverlays`), so a hover is never persisted, never pushes an undo frame and never leaves a layer on; the focused layer shows at full strength (even if off) and the others dim.
- **Pills share the Layers panel's keys** (`lib/siteLayerPills.js`): power, rail, traffic counts, contamination (LPST + EPA, two keys behind one pill), faults — each only if the layer can draw where the site is; FL/GA pipelines come back as the approximate EIA layers.
