### B2016112 — Pinch zoom stops where the fingers stop, not at the next whole zoom level `[Map Finder / Dashboard / Food]` (feature) #ui #site-planner #food #dashboard  *(Owner request 2026-10-03 (NEW-1): pinching only settled at fixed steps — scale bar jumping 100 → 200 → 500 mi; same for trackpad pinch on desktop.)*

`[x]` **Cause (matches the brief):** all three browse maps made Leaflet with the default `zoomSnap: 1`, so every gesture rounded to a whole level on release.
`[x]` **Fix:** new `src/shared/map/freePinchZoom.js` — `FREE_ZOOM_OPTIONS` (`zoomSnap: 0`, `zoomDelta: 1`, built-in wheel handler off) spread into the `L.map(...)` of `MapFinder.jsx`, `LocationsMapCard.jsx` and `FoodMap.jsx`, plus `attachFreeWheelZoom` (public Leaflet API only): a touch pinch is Leaflet's own touchZoom, now unsnapped; a trackpad pinch (ctrl+wheel with a small delta) zooms continuously, anchored under the cursor, one update per frame; a mouse-wheel notch is exactly ±1 level. +/− and double-click zoom stay one full level (`zoomDelta` 1). The site-plan backdrop map (`SitePlanner.jsx`, already `zoomSnap: 0`) is untouched. Read-only E2E-gated handles `window.__mapFinderMap` / `__locationsMap` / `__foodMap`.
`[x]` **Why a custom wheel handler:** measured on stock Leaflet with snap 0, one notch gave Δ=1.63 from a fractional start — and even with snap 1 stock Leaflet gave Δ=2 for one notch in this Chromium. The new handler is exactly 1.0 from integer and fractional starts.
`[x]` **Whole-number-zoom audit (re-confirmed across the three files + helpers):** no `Math.round/floor` of `getZoom`, no zoom-keyed cache; every gate is a `>=`/`<` threshold (place names, parcels, site-plan overlays, wide/city labels, Food `MIN_PIN_ZOOM`); `useGroundElevation`/`terrainLayers` already round to a band themselves; `tileLifecycle.js` is written for fractional zoom. Layer gates therefore turn on at the same zoom value as before (Food pin gate re-measured at 14.7 / 15.2).
`[x]` **Landmine handled deliberately:** `test/foodModule.test.js` (B651872 ×3) asserted FoodMap had no `zoomSnap:`/`zoomDelta:`; updated with a comment (it encoded "integer zoom wasn't the grey-tile cause", not a requirement). B651872 fixes still hold: fixed flyTo duration and long-jump `setView` unchanged; Houston → Maui from a fractional start paints all tiles (20/20 decoded).
- Guard: `test/freePinchZoom.test.js` (pure rules + wiring on all three maps, site-plan map excluded) and `ui-audit/verify-free-pinch-zoom.mjs` — real two-finger CDP touch pinch + wheel + ctrl-wheel + buttons + double-click on each of the three maps, with a known-good arm (double-click/± = exactly 1.0). **Red-proofed:** with the helper neutralised to stock behaviour the harness fails 20 checks (pinch snaps to 11/10, notch Δ=2 / 1.63, ctrl-wheel snaps to 16); green with the fix (all maps, all checks).
- Accepted trade-off (owner-approved): imagery is slightly soft between whole levels.
