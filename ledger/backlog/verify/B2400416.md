`[ ]` **Implemented — see V1826720 for the live signed-in check (Verify: live — a real pointer drag on a real canvas; sandbox arms below all passed).**
- **What shipped.** The Placement section's Rotation row is now: top line = the "Rotation" label · a round **dial** · the number box; under it two equal-width buttons that spell out what they do — **Turn 90° counterclockwise** and **Turn 90° clockwise** (test ids `overlay-rot-ccw90` / `overlay-rot-cw90` kept; no "left"/"right" anywhere).
- **Dial** (`OverlaysPanel.jsx` `RotationDial`; pure maths in `lib/rotationDial.js`): a circle with four tick dots at 0/90/180/270 and a needle in the Site green at the current rotation (0° = up, clockwise positive — the same sense the overlay turns on the map). Press anywhere on it and drag: the rotation is written live (rounded to 0.1°); **Shift snaps to 15° steps**; a drag across 0/360 wraps (359.96° is 0°, never 360). **One drag = ONE undo step** (`createDialDrag` pushes history once, on the first move that actually changes the angle; a press that lands on the current angle writes nothing). Keyboard: focusable `role="slider"` (`aria-valuemin 0`, `aria-valuemax 360`, `aria-valuenow`, `aria-label "Rotation dial"`); ←/↓ −1°, →/↑ +1°, Shift ±15°; a held key is one undo step.
- **Number box** keeps today's typed behaviour (parse, Enter commits, ° suffix, ↑/↓ step) and swaps the − / + buttons for a stacked **▲ (+1°, clockwise) / ▼ (−1°)** at its right edge (the shared `NumberBox`, which gained optional `upGlyph`/`downGlyph`/`upTestid`/`downTestid`; the arrows are drawn as SVG because this panel allows exactly two text sizes — the layout sweep caught the default 10px glyphs). Aria: "Increase rotation 1 degree" / "Decrease rotation 1 degree". Test ids `overlay-rot-plus` / `overlay-rot-minus` kept on them.
- **Narrow panel.** The two 90° buttons use the same measured row-or-column rule as the scale group (`useRowOrStack`, now shared): one row of two equal buttons when both labels fit unwrapped, else two full-width buttons stacked — never clipped, never a mid-label wrap.
- **Found and fixed while verifying:** in the typed rotation box, **Esc did not revert** — the blur Esc triggered committed the stale half-typed draft (the old stepper had the same defect). Now Esc cancels (`cancelled` ref), proven in the browser spec.
- **Everything works on a LOCKED overlay** (owner constraint #24): nothing in the rotation block reads `locked`; the e2e arms run for both. Same (non-)disabled reasons as before — the row simply isn't shown for the map capture.
