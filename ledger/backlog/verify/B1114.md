- **Repro.** A truck-court apron 218 ft off its host's centreline, and its trailer strip 218 ft west / 223 ft north, both **loaded and rendered without being healed**. The V508 case that passed used 2,086 ft, so the threshold sat somewhere in between — which is the tell that **magnitude was the wrong question.**
- **Root cause.** `strandedFromHost` compared an ABSOLUTE distance against `host half-diagonal + chain depth + child half-diagonal + slack`. On a 600×300 building with a full dock stack that reach is comfortably past 300 ft, so a 311 ft tear sat inside it and looked legal.
- **Fix — compare against the COMPUTED ANCHOR per kind, so magnitude stops mattering.** A bond's legal position is derivable: **ACROSS** the wall a stack member's offset is fully determined (`host_depth/2` + everything inboard of it + its own depth/2 — there is no user freedom on that axis at all), and **ALONG** the wall there IS freedom (the owner slides a field to line up a curb return — the B1039 rule) but it is bounded: the member must still OVERLAP the wall it is bonded to. New pure `offAnchor({acrossHave, acrossWant, alongHave, alongLimit, tol})`; tolerance 10 ft, generous enough for stored rounding and legacy sub-foot drift, far tighter than any real displacement. The wall-kid along-axis reset uses the same computed overlap bound instead of a distance.
- **Tests.** Cases at **50 / 200 / 2000 ft** all heal; the **exact reported 218/223** heals; a correct stack returns byte-identical; a **resized court depth is respected, not reset** (the depth is read off the member's own box, so a re-anchor is never a re-design); a legitimately slid side-parking row keeps its slide while one slid clean off the wall re-centres; `offAnchor` never claims a tear it cannot measure. **The 50 / 200 / 218 cases FAIL against the old absolute-distance test** (verified by reverting it), so these are guards, not decorations.
