### B2160242 — Trailer parking: stall depth is not editable per row, and a 50′-deep row holds NO stalls at the 53′ standard `[Site Planner / trailer]` (bug) #site-planner #ui  *(owner chat block 2026-10-06, NEW-3: "tried to draw 50-foot-deep trailer parking and the tool would not let him; it only worked once he got to 53 ft." `[ ]` **⏳ merged — V1575488 PENDING (Verify: live — real drawn geometry on a signed-in plan).**
- **Cause, found by reading the code and confirmed by the count (AUDIT-FIRST):** there is **no 53′ floor anywhere** — no clamp, no minimum on the draw. The Trailer tool is a free rectangle; the stall count comes from `trailerStalls(w, h, cfg)`, which lays a double-loaded module of `2 × stall depth + drive lane` and needs `h ≥ stall depth` for even one band. The standard stall depth is 53′ (`settings.trailerL`), the row had no way to carry its own, so a 50′ row computed **zero bands and zero stalls** — drawn, striped nothing, counted 0. That is the "it only worked at 53". (`trailerStalls(600, 50, {trailerL: 53}).count === 0`; at 50 it is 50.)
- **Fix:** (1) **Properties → Stalls** — Stall depth / Stall width / Drive lane are per-row overrides in the row's `cfg` (they beat Standards, `std ↺` returns one to the plan value, geometry, count and label all follow); Standards stays the default for new rows. (2) A row **drawn** shallower than the standard stall adopts the drawn depth as its stall depth (`drawnTrailerCfg`), so the first thing the owner sees is a counted 50′ row, not an empty one. (3) Sanity floor **8′ depth / 6′ width / 0 lane** — far below any real stall, only there to stop a typo making a thousand stalls; typing under it is answered "Using 8" by the shared field, never silently clamped. A dock-zone member (`noFit`) keeps its depth under the stack's own Depth control (it is rebuilt from it), so only its width and label switch show there.
- **Same-floor check on width / lane:** none found — Standards' Trailer W/L accept 1+ and the lane 0+ (unchanged, asserted); the per-row fields add the sanity floors above. Polygon (click-drawn) rows' estimate now reads the row's own spec, as does the yield total (`siteMetrics`).
- **Sandbox-verified:** `test/trailerRows.test.js` (50′ at 53′ = 0; at 50′ = 600/12 = 50; 45 / 50 / 53 / 60 all count; a source guard that no 53 floor exists in the geometry or the new module); `e2e/trailer-row-labels.spec.js` NEW-3 draws ~50′ with the real tool, edits the field to 50 / 53 / 45 and reads the model, the readout and the label — red on main (no field). **Live-verify:** V1575488.
