- **THE ANSWER: rasterizing is the expensive step; compressing it is not, so the codec question and the resolution question are NOT the same lever.** Measured on the real page: render (pdf.js → pixels) **~700–1300ms**; ENCODE, either codec, is tens of ms to a couple hundred — PNG encode **19ms**, JPEG q0.85 encode at the SAME resolution **102ms**. Switching PNG→JPEG at unchanged resolution: **321 KB → 202 KB, a 37% reduction, for ~80ms of extra encode time on a render that already took 700ms+.** That confirms his own instinct exactly: compression is milliseconds; it was never the tradeoff to worry about.
- **THE REAL LEVER IS RESOLUTION — but only for a page BIGGER than a normal flyer sheet, which his own file is not.** His site-plan page is a plain 8.5×11" letter sheet (612×792 pt); at the app's existing 150 DPI base that's **1275×1650px**, comfortably under any sane cap — so for THIS file, a long-edge cap changes nothing (confirmed by the shipped math itself: `effectiveRasterDpi` never RAISES the DPI, only caps it down, and it doesn't trigger here). The cap is insurance for a full civil site-plan sheet: at the SAME 150 DPI, a 24×36" ARCH D sheet would rasterize to **3600×5400px** — far more detail than a map view spanning a few thousand screen pixels at his working zoom can use, and needlessly large to store/download. Capped at a 4000px long edge, that same sheet renders at a lower effective DPI instead, landing at **2667×4000px**. The cap is a CEILING, not a target — it only ever engages when the source page is genuinely oversized.
- **SHIPPED: `shared/sitePlans/lib/overlayRasterSize.js` (new, pure, unit-tested) — `effectiveRasterDpi`/`cappedRasterDims`.** `pdfRaster.js`'s `renderPdfPageToImageData` gained an additive, opt-in `maxLongEdgePx` option (the existing OCR caller, `deedOcr.js`, is completely untouched — its own 300 DPI default and behavior are unchanged byte-for-byte) that caps the render DPI down before rendering, so an oversized sheet is never rasterized big and then thrown away — it's rendered right-sized the first time.
