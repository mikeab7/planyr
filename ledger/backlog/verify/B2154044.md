### B2154044 — On a freshly created sibling plan the FIRST markup is never written to the cloud if you switch plans within ~0.3 s (local copy shows it; `site_elements` has 0 rows; a fresh sign-in shows it empty) `[Site Planner / sync]` (bug, medium — silent data loss, LOUD-FAILURE) #site-planner #sync #persistence  *(AUTH-SWEEP 2, V27088 side finding, reproduced 3 of 3: Concepts C, E, F; a 6 s dwell saved)*
Repro: signed in, Plan menu → New plan, press L and draw a line, wait 0.3 s, switch back to Concept A, wait 12 s. The same race probably lost all of Concept B's content in a first fast run. Investigation dispatched; **Stopping rule:** a fast plan switch after the first draw leaves the row in the cloud (test).

`[x]` **Root cause (reproduced live 2× on planyr.io build 80683f6, then fixed and re-run against the production backend from a local build):** not a debounce drop. A freshly created plan's element engine seeds only when the realtime join answers (or a 4 s fallback); until then `reconcile()` is a deliberate no-op, so the first markup was never queued or journaled, and the planner (keyed by plan id) unmounting on a plan switch hard-`stop()`ped the engine — also dropping a debounced update and a retry waiting on backoff.
`[x]` **Fix:** `elementSync.stop({ drain: true })` + `drainSeed(rows, collections)`; `SitePlanner.jsx` teardown now `drainElementsOnTeardown` (seeded: diff the final canvas and commit; never-seeded: push the plan header, fetch rows, run the same rows ∪ never-synced fold as `refetchReplace`; plain stop when signed out / different account / read-only / deleted / header conflict). Rows stay canonical (DATA.md inv. 3), tombstones stay deleted. `docs/DATA.md` §5 records it. Tests: `test/elementSyncDrainOnStop.test.js` (11; 9 RED on the pre-fix code). Known open edges: drain overlapping a quick return (absorbed by the "live row already holds our data" path); the pending-edit journal is not cleared after a drain (harmless on next fold); the tab-close flush on an unseeded engine is still covered only by the local mirror + next open's fold.
