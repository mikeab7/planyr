`[x]` **FIXED THIS SESSION — determined exactly which of the three possible causes it was, per the brief's own question.** The write works (`toggleLocked` → `patchAndReload` → a real Supabase `UPDATE`) and the visual state works (`LockIcon locked={o.locked}` reads the live row, survives reload). **The map layer's gesture-guard is what was broken**: `locked` was checked in exactly one place in the whole stack — `useSitePlanOverlayLayers.js`'s per-overlay `setClickable`, which only gates whether CLICKING THE IMAGE arms editing.
