- **Built:** Ctrl+B/I/U/5, Ctrl+1 (dialog), Ctrl+Shift+$ % ! ~ # & _, Ctrl+R, Ctrl+Enter (fill selection), Alt+Enter (new line in a cell → wrap turns on, row grows), Ctrl+; and Ctrl+Shift+; , Ctrl+' / Ctrl+Shift+" , Alt+= AutoSum (number run above/left; a total under each column of a block), F4 (repeat last action; in an open formula cycles $A$1 / A$1 / $A1 / A1), Ctrl+A (region, then whole sheet), Shift+Space, Ctrl+Space (row then Ctrl+Space = whole sheet, as in Excel), Ctrl+Shift+Arrow/Home/End, Shift+Home, Home, PgUp/PgDn, Alt+PgUp/PgDn, Ctrl+Shift+= / Ctrl+- (rows/columns when whole lines are selected, else an Entire row / Entire column prompt), Ctrl+9 / Ctrl+Shift+9 / Ctrl+0 / Ctrl+Shift+0 (hide / unhide — NEW model fields `sheet.hiddenRows`, `column.hidden`, round-tripped through .xlsx), Shift+F11, Ctrl+PgUp/PgDn, Ctrl+S (flushes the cloud push now and says what was saved; the browser save dialog never opens). Alt sequences: H O I/A/W/H, H B A/N/T/O, H H, H F C, H F P, H A L/C/R/T/M/B, H W, H M M/C/U, H I R/C, H D R/C, H E A/F/C, H S S/O/F, H 0/9/1/2/3/5/6/K/P/N, W F F/R/C. Ctrl+C/X/V: see B2455075.
- **Undo:** each shortcut is one `commit`, so one Ctrl+Z (harness S1 proves a multi-cell Ctrl+B reverts in one step).
- **Decisions to know:** (1) **Ctrl+K stays the command palette** (cells have no hyperlinks). (2) **Ctrl+P is left to the browser** — the workbook has no print/export route of its own (only .xlsx/.csv export). (3) Insert/Delete on a block of cells offers **Entire row / Entire column only** — Excel's "shift cells right/down" is NOT built: this model has no cell-level shift that also rewrites references, and faking it would leave formulas pointing at the wrong cells. (4) Ctrl+Shift+; enters the time as text ("3:07 PM") — the engine has day-serial dates only. (5) Foreign (Excel-HTML) formulas paste as written — see B2455075. (6) Keys are matched on the character produced (`e.key`), never `e.code`, so a non-US layout cannot fire a chord by accident.
- **Cannot be proven in a headless Chromium (why this is Verify: live):** whether Chrome-on-Windows lets a page keep **Ctrl+1…9 (tab switch), Ctrl+PgUp/PgDn (tab switch), Ctrl+0 (zoom reset), Ctrl+S, Ctrl+R, Alt-alone (menu focus)** — the page calls `preventDefault` on all of them (and on the Alt *keyup* that starts a sequence), and the Playwright run proves the handlers fire, but a real Windows Chrome keyboard path is not available here. If any is swallowed by the browser it is reported on V1898576, not hidden.
