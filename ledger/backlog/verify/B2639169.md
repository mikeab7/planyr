- **What changed** (`public/sequence/index.html`, MasterView): the **Status** segmented control and its label are gone. The toolbar's right side is exactly **Filter · Group by · Show · Columns**, one matching `.btn` style (`ReportMenu`, a module-scope component), TASK REPORT and the count pill stay left.
  - **Filter** (funnel icon): a solid count badge = number of filter TYPES in use (Status + Project = 2) and the accent border while any is on. **STATUS** — a checkbox for every status in the approved order (Not Started, In Progress, Needs Attention, Paused, Complete, then any custom status from settings), each with its count; default In Progress + Needs Attention. **PROJECT** — a checkbox per schedule with its count, none checked = all. **Clear all** pinned at the bottom. Filters immediately (no Apply), the panel stays open while ticking, closes on an outside press / Esc / the button again; the four dropdowns share ONE open slot, so opening one closes any other in a single click. Nothing checked in a section narrows nothing, so Clear all shows every task. Status and Project combine (AND).
  - **Group by** is a dropdown button "Group by: None | Project ▾" with a single-choice list; behaviour unchanged. **Show** and **Columns**: contents and behaviour unchanged, only position and button style.
  - **Counts** are faceted and exact: each count equals the rows that box would show given what the OTHER section currently narrows to (and the Show setting). Pure `reportFacetCounts`.
  - **One classification:** the filter reads `_disp` (the displayed status that paints the pill and drives the Status sort) — no second copy; custom statuses are extra checkboxes (`reportStatusOptions`). **Header pill, group pills and rows** all derive from the one `filteredRows`; a group with no matching row never gets a header.
  - **Empty state** rewritten for the new control: "No tasks match the filter (Needs Attention · Delta Site …). Clear filter" (and a "Show all" way back when the Show setting is what empties the list). The old "No tasks are Needs Attention / Show all statuses" text is gone.
  - **Not clipped, reachable:** the panel is `position:fixed`, placed from the button's own box and clamped inside the iframe, scrolls INSIDE itself when the project list is long (40 projects measured), Clear all stays pinned and visible; at phone width the four buttons wrap onto a second row instead of crowding the title.
- **Migration (nobody loses their view):** the saved key `masterHealthFilter` is unchanged and still read — legacy `true` = In Progress + Needs Attention, legacy `false` = nothing checked, what #2800 saved (`["red"]`, `["yellow","red"]`, `[]`) = those boxes / nothing checked; unreadable → the default; a key for a deleted custom status is dropped.
