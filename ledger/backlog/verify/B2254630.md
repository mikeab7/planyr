- **Findings (asked first):** the three scale actions (Set scale / Trace a length / Match 2 points) exist ONLY in the Site tab's Overlays panel (`OverlaysPanel.jsx` `ScaleGroup`, for `sheetOverlays`). The Map/Comps overlay (`site_plan_overlays` — the lease-comp flyer, the thing the Adjust site plan panel edits) **never had any scale control**: its scale could only change by dragging a corner handle on the map, and the Adjust panel's "Move / resize" was the only route (disabled when locked). So nothing was removed by a recent change; the controls were never on this surface, and the owner's flyer sat there.
- **Built:** a **Scale** section in the Adjust panel for every placed plan (scaled or not, locked or not): three equal full-width buttons **Set scale · Trace a length · Match 2 points**. *Set scale* — preset list + custom "1 inch = N ft" (PDF pages only; px-per-inch is exact for an uncapped page and recovered from a standard sheet size for a capped one, refused with a reason otherwise). *Trace a length* — click both ends on the map, type the real length (ft/in/m), scales about the traced midpoint. *Match 2 points* — click a drawing point then its true map spot, 2+ pairs (3+ = best fit with the residual reported), moves + rotates + scales. Markers and a live prompt pill are drawn on the map; Escape cancels; every click while calibrating belongs to the calibration. All three commit through the same placement write as a corner drag (pinned comps follow) with `explicit:true`, so a locked plan takes them.
- Engine: `anchorImagePointGeo` + `alignOverlayGeo` in `shared/overlay/overlayPlacement.js` (geo half; `anchorVisibleCentreGeo` now delegates, golden-verified); rules in `shared/sitePlans/lib/overlayScaleGeo.js`; click state in the dependency-free `overlayCalibration.js` leaf (MapFinder imports only that, keeping the math off the Site route's boot path).
- **Proof:** `test/overlayScaleGeo.test.js` (round-trips: Set scale → 40 ft/in; Trace → exactly the typed length with midpoint fixed; Match → both points land within 0.05 ft, scale and rotation recovered; calibration click state); source guards in `test/cropEditorOwnerFixes.test.js`; live `V1681809`.
