### B2146545 — Review: Enter/Space on a focused button did nothing (window key handler cancelled the native click) `[Review]` (bug) #doc-review #keyboard  *(found by AUTH-SWEEP 2 driving V163 on build 1142833; seen on toolbar "Versions" and the Reviews-menu Delete/Cancel buttons)*

`[x]` **Root cause:** `DocReview.jsx` window keydown handler called `preventDefault()` on Enter and Space for any target that was not an input/select/textarea/contenteditable (Space = hold-to-pan, Enter = finish draft), which cancels a focused button's native click. The B531 comment that child buttons handle their own Enter/Space was false.
`[x]` **Fix:** after the modifier early-return, Enter/Space return untouched when the target is inside a `button, a[href], summary, [role=button], [role=menuitem]`. Canvas Enter/Space-to-pan behaviour is unchanged. Guard: `test/reviewsMenuPortal.test.js`.
