### B2161442 — A land comp's Save button said "Pick mo or yr to save" `[comps]` (bug) #comps #ui #mobile #site-planner  *(Owner block 2026-10-08 NEW-3, follow-up to B2138081. Minted from the reserved block. DEDUPE-FIRST: B2138081 (Done) introduced `saveState`. Net-new.)*

`[x]` **Root cause (found by instrument, not by reading the brief's guess):** `saveState` fell back to the lease-only copy for ANY unready row with a location — and the row was unready for a reason a land comp cannot act on: its cell flags still carried the lease `leaseRatePeriod` blocker raised when the row was a lease (a type switch never cleared flags). The same stale flag also disabled the desktop Save, counted in the desktop "N blocking" footer, and rendered a "Rate has no period" sentence under a land row.
`[x]` **Fix:** `rowBlocker(row)` names the real blocker from the row's own `validateComp(draftToComp(draft))` errors and its blocking flags — `Pick a comp type to save` · `Place it on the map to save` · `Pick monthly or yearly to save` (ONLY the lease period) · `Fix the flagged field to save`; `activeCellFlags(cellFlags, compType)` drops flags raised by a column that does not apply to the row's CURRENT type (an unclassifiable key is never hidden) and now feeds `saveState`, the desktop `rowIsReady` / blocking count / problems list, and the jump-sheet status text.
`[x]` **What land actually requires to save — confirmed intentional:** a type and a placed location, nothing else. `validateComp` asks for no size or price on land or building sale (`comps.sql`: `land_price`, `land_size_value`, `bldg_price`, `bldg_size_sf` are nullable; NEW-5 2026-09-02 made even the Executed date optional). So the brief's example copy `Add a size to save` would be false — no copy claims a requirement that does not exist; a placed land comp with size/price empty reads `Save 1 comp`.
`[x]` **Tests:** `test/compMobileSheetFollowups.test.js` — every comp type × blocker (unplaced, placed + empty size/price, lease no-period via error and via flag, stale lease flag on land, live non-period flag, no rows, saving) plus `activeCellFlags`. Headless: lease with no period → Land → placed → `Save 1 comp`.
