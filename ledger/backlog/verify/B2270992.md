### B2270992 — Admin coverage map: the wheel hijacked the page, so the map could not be scrolled past `[Platform / Admin]` (bug) #admin #ui  *(owner chat block 2026-10-15, NEW-1 of three; measured live on build 6638a91. Minted B2270992 from this branch's block, against fetched `origin/main`.)*
`[~]` **⏳ Verify — implemented and sandbox-proven; the deployed-build check is V1696128.**
- Verify: live (a real browser, the deployed bundle) → **V1696128**; the session signs in as the test account with `is_admin` mocked (same shape as `ui-audit/verify-admin-surfaces.mjs`), so no `Blocker:`.
- **Root cause (measured):** `ParcelCoverageSection` bound a non-passive `wheel` listener on the `<svg>` that called `preventDefault()` on EVERY wheel event, so a map that filled the viewport swallowed page scroll; wheel-up also zoomed in and pushed the top of the US out of the frame.
- **Fix:** a plain wheel / two-finger trackpad scroll is the page's (the handler returns before `preventDefault`); the map zooms only on Ctrl/Cmd+wheel (a trackpad pinch arrives as a ctrl-wheel), the +/−/reset buttons, or a touch pinch (`lib/coverageMapInteraction.js` `wheelIntent` / `wheelZoomFactor`). The first plain wheel over the map shows "Use Ctrl + scroll to zoom" once per page visit. The map's height is capped to what is left under the header + summary + legend (`mapHeightCap`, measured against the nearest scroller on resize and when content above reflows), kept in aspect (letterboxed, with all pointer maths going through the SVG's own screen matrix), floor of a usable height on a very short window. Reset restores the whole US with nothing clipped (asserted over every county's bbox). At whole-US zoom a one-finger touch drag on the map scrolls the page (`touch-action: pan-y`); it switches to `none` only while zoomed in, where a drag pans.
- **Sandbox proof:** `test/coverageMapInteraction.test.js` (wheel intent, bounded zoom step, cap maths, source guard that the scroll branch returns before the first `preventDefault`); `ui-audit/verify-admin-parcel-coverage.mjs` (real Chromium): at 1440x800 and 1600x1100 the WHOLE map sits inside the admin scroller with no scrolling; at 1280x450 a plain wheel DOWN over the map scrolls the page and a plain wheel UP scrolls it back; no plain wheel event is `defaultPrevented`, Ctrl+wheel is (and zooms); plain wheel never zooms, at whole-US or zoomed in; the hint shows once; Reset restores `translate(0 0) scale(1)`. Red against the pre-fix component (the card/hover checks fail first; the wheel arms were measured live on 6638a91).
