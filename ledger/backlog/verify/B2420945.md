- **What was wrong:** `TN_ID_SOURCES` held Davidson (11 digits) and Rutherford (dashed) only. Pasting the id a card shows for any other lot — the Comptroller's `001 073    17102 000 2026`, Williamson/Hickman/Chester's `104    01308 00005104`, Hamilton's `066  018`, Montgomery's `090 00203 000`, Shelby's `072124 A00048` — went to the geocoder. (The Sullivan lot's id read "Site search does not read … as a parcel id" in the sweep.)
- **Fix:** `lib/tnParcelId.js` — ONE parser for the assessor's fixed-width control-map link (map · map letters · group · 5-digit parcel) that reads every shown form, the dashed/dotted form an owner types, Hamilton's tax-map number, Metro's lettered condo numbers and Shelby's assessor number; per-source where-clauses (Comptroller `CMAP`/`PARCEL` + `COUNTY_ID`; the CAMA family's link column anchored at the map; Shelby's `PAID`). `lib/parcelIdSearch.js` asks every plausible source in parallel and never guesses between them (an id that reads two ways asks both), lands on the exact reading first, ranks a repeated control-map number by nearness to the map and names the others (`also in …`), accepts a county named first (`Anderson 073 171.02`), retries a silent source once, and says "any Tennessee county's parcel layer" instead of a nine-name list. `lib/parcelQuery.js lookupParcelsWhere` is the one where-clause lookup. The in-planner per-county ID box got `idNormalizer` `tn-link` / `tn-hamilton` / `tn-shelby` (Williamson, Montgomery, Hickman, Chester, Hamilton, Shelby).
- **Two bugs found by running it, not by reading it:** a middle-wildcard `LIKE '%128%01200'` matched dozens of lettered maps and the 20-row answer missed the lot (anchored at the map, letters in order, 50 rows); Rutherford's two-letter map letters (`091NB-C-…`) and Williamson's condo tail (`…C00109063J`) were not ids.
- **Red-proof:** `test/tnIdRoundTrip.test.js` 375 of 378 red on `origin/main`; the Node sweep passes C on 1 of 95 there, 95 of 95 here. Unit: `test/tnIdForms.test.js` (47), `test/tnParcelIdSearch.test.js` (50, updated: the plan now includes the other sources).
