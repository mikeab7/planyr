- **Symptom (measured on planyr.io build b94ffe1, signed out, two seeded projects; also on a build of 5fc90a1, BEFORE both perf rounds — so not caused by them):** project A → project B → back to A: the canvas shows A, the URL keeps `#/project/<B>/site` indefinitely. A reload or a shared link opens B; a module switch carries B.
- **Root cause:** `SitePlannerApp` effect (1) set the one-pass `routeChangedThisPassRef` (B881664's "defer to the route reconcile") for EVERY route change — including the hash round trip of effect (2)'s OWN write. Effect (2) does not re-run on that pass (its inputs did not change), so the flag survived and was consumed by the NEXT switch's write, which was skipped. Logged live: `[E2] {"effGroup":"live-bo","defer":true,"route":"live-ca"}`.
- **Fix:** `bootResume.routeChangeNeedsDefer(prev, projectId, ownEcho)` — an own echo (`projectId === pendingRouteWriteRef`) is not an external change and never sets the flag. B881664 / B1865936 behaviour for a genuine outside navigation unchanged.
