- **⛔ A CALLOUT STORES A TONE **NAME**, NEVER A COLOUR.** The node carries `info | tip | important | warning | danger` and nothing else. Three surfaces then draw that one name their own way — the screen from theme tokens, paper from print ink, Markdown from GitHub's own alert syntax. Storing a colour would have frozen the first of those three into the document forever, and would have printed a dark box on a light sheet the day the theme changed.
- **THE FIVE TONES ARE GITHUB'S FIVE, DELIBERATELY.** `> [!NOTE]` / `[!TIP]` / `[!IMPORTANT]` / `[!WARNING]` / `[!CAUTION]` is a real rendered construct in GFM, so the export is the same thing with a different spelling rather than an approximation — which is why a callout adds **nothing** to the lossiness report. A sixth tone would have no marker to map to; adding one means deciding its fallback first, and both files say so.
- **A TOGGLE IS THE BROWSER'S OWN `<details>`.** Folding is then something the browser does — no measuring, no animation frame, no height cache to go stale — and a printed sheet inherits the same element, so there is no second implementation on paper to drift (PDF-PARITY by construction). The fold is an ATTRIBUTE in the document, so it persists, syncs and survives a reload; a small plugin claims the marker press and writes the attribute rather than letting the browser flip a DOM property ProseMirror would immediately overwrite.
- **⛔ A COLLAPSED TOGGLE PRINTS AND EXPORTS EXPANDED, UNCONDITIONALLY.** `docToHtml` opens every `<details>` before it serialises — not behind an option a caller can forget, because this file has exactly two callers and both are the print path. Paper has no disclosure triangle, so a folded section written out folded is simply missing text, and nothing about the resulting sheet looks wrong. That is the whole reason it is not a flag.
- **ONE BUG THE HARNESS CAUGHT AND NO UNIT TEST COULD HAVE.** `setNoteToggle` read `state.selection`, but the slash menu runs it at the end of a chain that has already deleted the typed `/toggle` — so its positions were stale by exactly the length of the command the user typed, and the result was a toggle with an EMPTY title and the title's words in its body. A command that reported success and produced the wrong document. It reads `tr.selection` now.
