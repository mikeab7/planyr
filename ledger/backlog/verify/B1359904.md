**THREE MARKER WEIGHTS** (`lib/dashboardMapMarkers.js`, pure + unit-tested): status `"active"` → filled accent pin, soft halo, bold name beside it (loudest); status `"pursuit"`/`"onhold"` (still-open, not-yet-active — the same open-pipeline boundary `dashboardPipeline.js`'s `OPEN_STATUSES` already draws for the Pursuits/Going-quiet cards) → hollow accent ring, lighter label; comps → small quiet grey `circleMarker` dots, no label, `interactive:false`. `role:"tracked"` market records and settled (`complete`/`dead`) projects are excluded from the map entirely — not open pipeline, same boundary this dashboard already treats as "the pipeline" elsewhere. A legend under the map names Active/Pursuit; a `ToggleChip` (the app's own primitive) switches the comps layer on/off, defaulting on.

**FIT-ON-LOAD:** the Leaflet map is constructed and fit to `L.latLngBounds` of every plottable point exactly once, in the mount effect, and never re-fits afterward — toggling comps only filters what's drawn, it never moves the camera.

**MISSING LOCATIONS ARE COUNTED, NEVER SILENTLY DROPPED:** `missingLocationCount()` counts open-pipeline projects/pursuits with no usable `origin` (`data->origin` on `sites`, unchanged storage shape — `SetLocationDialog.jsx`'s existing field); a quiet line under the map (`"N projects' location(s) need fixing →"`) is clickable/keyboard-activatable and calls `onNavigate({module:"site-planner", projectId:null})` — the Site Planner's own project list (`MapFinder`), the same landing point "New project" and leaving a project already use, from which any of them is reachable to fix via the existing "Set location…" flow. Never a project ID guess — the line always opens the list, since it can point at several.

**EMPTY STATES, never an empty grey rectangle:** (a) nothing in the open pipeline and no comps at all → a short line, no map mounted; (b) something exists but nothing has a location yet → the map is still skipped (nothing to fit to), leading with the missing-location line instead; (c) at least one located point → the real map, legend and (if any) the missing line.
