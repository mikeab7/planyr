**What shipped.**
- **One default, changed — not a second one stacked.** `--canvas-parcel` and `--canvas-setback` are `#34E802` in BOTH themes, and the `--indigo` alias B1187 minted is deleted, so there is a single source of truth. - **Scope is the DEFAULT only.** Both render paths still resolve `pc.stroke ?? PAL.parcel` and `setbackLineStyle(pc, PAL.setback)`, so any user or site that explicitly set a parcel or setback colour keeps it — B1100's override behaviour is untouched and a default change cannot stomp a deliberate choice.
- **A casing, because #34E802 is very saturated and many of these sites are farmland.** New token `--canvas-line-casing` (translucent black, both themes) draws a dark under-stroke a touch wider than the line beneath BOTH the parcel boundary and the setback ring — on the ring it carries the same dash, so the halo dashes with it. That is what keeps a green property line from disappearing into green crop, and it does the same work on dark asphalt and on the USGS topo sheet. It is applied to every parcel line, not only the default-coloured one, so a user's own colour survives its worst background too; it is skipped while the line already carries a state colour of its own (remove-hover / multi-pick) and on an inactive parcel, which is deliberately faint context. **The colour itself is unchanged from what the owner picked** — the legibility work is entirely underneath it.
