- **THE MECHANISM.** Growth above the baseline but inside the band annotates and **writes nothing**. So `main` accumulates real, honest feature weight above its own recorded baseline, invisibly, one in-band merge at a time, until a later branch adds its first kilobyte and trips a ceiling that was already ~90% consumed before it existed. That branch is then told to "pay it back with an optimization" for bytes it did not add, and its only exit is to RAISE the baseline by everyone else's drift.
- **IT HAS ALREADY HAPPENED FIVE TIMES IN NINE DAYS**, every one honestly annotated and every one laundering drift: B1401 · B1405 · B1414 · B209502 · B255200, the largest reading *"main was already 73.6 KB above this stale baseline before this branch"*.
- **THE FIX USES A MEASUREMENT ALREADY BEING TAKEN.** `scripts/perf-base-stats.mjs` builds the base ref on every CI run for the NEW-3 attribution; it was only ever used to NAME movers, never to judge. Now `inherited = base − baseline` and `branch = value − base`, and **a branch is charged only its own bytes**: it fails when its own growth consumes the whole band, or when main was clean so the overage is entirely its own — and it does NOT fail for drift it cannot fix. `inherited` is printed on **every** run, breach or not, so accumulation can never again be invisible until it is 73.6 KB deep.
- **MAIN GETS NO RELIEF, and that asymmetry is the design.** Attribution applies to a pull request only (`GITHUB_BASE_REF`, with `--as-pr`/`--as-main` for testability). A push to main is judged on what main IS, so the drift surfaces on main — where a deliberate ratchet with a stated reason is the correct answer — instead of on a stranger's branch. Without that half this would be an unbounded loosening.
- **Proven end-to-end both ways** against a real build: as a pull request the inherited breach PASSES with a named line telling the reader **not** to raise the baseline; as a push to main the identical numbers FAIL. Plus 7 unit tests covering every branch of the split, including that `classify()` — main's absolute verdict — is untouched.
