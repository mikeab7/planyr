`[x]` **Route chosen: extend the existing piece-table reader — no library.** `src/shared/files/docStructure.js` reads CHPX/PAPX (via the PlcfBteChpx/PlcfBtePapx FKP pages), the style sheet (STSH), fonts (SttbfFfn), list definitions (PlfLst/PlfLfo), table grids (sprmTDefTable) and the `Data` stream, on top of `docText.js`'s container + piece-table reader (refactored to export `readWordFile`/`decodePieces`; the deed plotter still gets byte-identical text). **Why not a library:** no browser-capable one reads .doc formatting — `word-extractor` is Node-only and text-only, `mammoth` is .docx-only, SheetJS `cfb` is just the container, `officeparser` is text-only; a hand-written reader over the already-trusted container code costs **one new lazy chunk, `docStructure`: 16.05 kB raw / 7.26 kB gzip**, fetched only when a .doc is opened (nothing on the boot path; the DocEditor chunk itself is 77.13 kB / 26.19 kB gzip with all of NEW-1 and NEW-2) and keeps the format knowledge next to the code that already read it. A library would have been larger and still Node-only or text-only.
`[x]` **Now carried:** paragraphs; Heading 1–3 / Title; bold, italic, underline, strike, super/subscript, colour, size, font (only where it differs from the document's own default, which becomes the new .docx's default); alignment and indents; bullet and numbered lists incl. nested; tables incl. horizontal and vertical merges and column widths; hyperlinks; **JPEG and PNG pictures** (real images, with the media written into the .docx). Saving as .docx (new file, original kept — unchanged) writes all of it.
`[x]` **Not carried — said on the item, in the on-open note and in a visible placeholder, never silent:** EMF/WMF/PICT/TIFF/DIB pictures and drawn shapes (placeholder "[EMF picture not carried over from the .doc]" etc.), text boxes, headers/footers/footnotes/comments, nested tables (text flattened into the outer cell), tracked changes (shown as plain text, counted), cell borders/shading. If the structure reader throws, the text-only reader runs instead and the editor says so (never a quiet downgrade).
