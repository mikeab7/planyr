### B2084480 — Library doesn't show a file just saved in Review until a full reload `[library]` (bug) #library #persistence  *(Owner report 2026-10-04 build 4ca9ff1, dispatch block NEW-1. DEDUPE-FIRST: searched Open/Verify/Done for Library refresh / Unfiled / B1953796 (R8 focus refetch) — R8 covers focus only; no prior item for a same-session save. Not a recurrence.)*

`[x]` **Cause (AUDIT-FIRST):** Library Home loaded `doc_reviews` once per activation and FileBrowser only on activation/focus; Review's write (`upsertReview`, and the Recent `recordOpen`) lands AFTER that read, and nothing told the Library. A reload re-read it, which is why a cache-busted reload showed the file.
`[x]` **Fix — one signal, no new store:** `src/shared/library/libraryChanged.js` (`notifyLibraryChanged` / `subscribeLibraryChanged`: same-document listener set + `BroadcastChannel` for the browser's other tabs; carries no data, so listeners re-read the one source of truth). Emitted from `reviewStore.upsertReview` (the single funnel every save / save-as-new / refile / autosave passes through — after the facts mirror), `deleteReview`, `restoreReview`, and `recentDocs.recordOpen`. `LibraryHome` re-reads reviews + Recent, `FileBrowser` runs its token-guarded `refresh()`.
