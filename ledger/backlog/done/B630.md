### B630 — Don't force Stitch's Align gate onto sets that can't be stitched (schedule/legend / all-NOT-TO-SCALE) `[Doc Review / Stitch]` (feature — product call)  *(Cowork brief 2026-07-03 "NEW-1"; minted **B630** = highest real B# across both files (B627) + 1; branch `claude/stitch-not-aligned-overlay-s2wbdx`)*
`[x]` **Fixed + shipped this session.** Opening the JACINTOPORT mechanical set (14-page schedule/legend/code-summary set, resumes as `kind:"stitch"`) used to show **13/14 sheets flagged "⚠ Not aligned"** — a false demand, because the set has no match-line seams to stitch and is not to scale. Now such a set is classified a **reference set** and the align gate is dropped entirely.
- **Classifier:** `isReferenceSet(placed, ftPerUnit)` (`lib/stitchGeom.js`, pure + unit-tested) — true when **≥2 placed sheets, NO match-line seam on any sheet, no composite scale, AND ≥1 sheet positively `notToScale`** (a legend/notes/schedule/"NTS" sheet). The `some(notToScale)` requirement is the guard (added after the adversarial review) against a **real plan set aligned by a shared corner** — that case is also seam-less + uncalibrated but has ZERO not-to-scale sheets, so it's never misclassified and keeps the manual-Align affordance. `loadStitch` **back-fills `notToScale`** for pre-B631 saves via a background re-read of each source's page metadata (the same reader the drop path uses; best-effort, token-guarded, only ever upgrades a sheet to not-to-scale), so the owner's JACINTOPORT set (whose legend/notes sheets read not-to-scale) is still caught on resume. Fail open: any seam OR any calibration OR no not-to-scale sheet ⇒ a real plan, gate unchanged.
- **UI:** when `referenceSet`, the canvas overlay + sidebar "Align before measuring" nag are suppressed, and a **dismissible steer** — *"These look like reference sheets (not to scale) — there's nothing to stitch or measure here · [Open as single sheets]"* — offers a jump to single-sheet Review (`onReview`). `blockedOverUnaligned` gives a reference-set-specific message if the user still tries to measure.
