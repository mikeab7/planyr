- **FIX:** (1) `src/shared/ui/AnchoredMenu.jsx` — a `ResizeObserver` on the PANEL ITSELF re-runs placement whenever its size changes (fixes every `AnchoredMenu` consumer, not just this one — the panel's own size is an input to its placement); (2) `src/app/HelpReportControl.jsx` — the Report and Help views' action rows (Back / Send) are `position: sticky; bottom: 0` so in a window too short for the whole view the panel scrolls inside itself (it is already capped at 72% of the window) and Back stays reachable; Back buttons carry `data-testid` `help-back` / `report-back`.
