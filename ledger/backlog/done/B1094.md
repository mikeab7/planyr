- **Root cause (AUDIT-FIRST).** `elementSync.js` has no notion of `attachedTo`. A batch is *whatever happens to be dirty* at the instant `flush()` runs, and each op carries the payload **captured when the diff enqueued it**. So an assembly can straddle transactions in two independent ways: a member that reaches the dirty queue late goes out in its own later commit, and a member whose op was minted before the gesture ships the pre-gesture bytes. Neither is recoverable afterwards — `flush()` also returns early while any commit is `inflight`, which widens the window rather than closing it.
- **Fix — two guarantees, both in `flush()`, immediately before the batch is built.**
  - **(a) CLOSURE.** `closeAssemblies()` — if ANY member of an assembly is dirty, every member whose LIVE data disagrees with the shadow joins the same batch. The assembly root is the same `rootIdOf` rule `planClipboard` and the delete/nudge paths already use (`attachedTo` when bonded, else self), so there is one definition of "assembly" in the codebase. One gesture → one commit → N+1 ops.
  - **(b) FRESHNESS.** `freshen()` — every op's data is re-read from the live canvas at flush time through a new injected `liveCollections()` provider, so a payload captured before the gesture can no longer reach the wire, whatever queued it (a deferred cascade, a transport-failure requeue, the pending-edit journal). The z the diff ASSIGNED to a z-less new element is preserved across the refresh.
  - Both are **opt-in**: a caller that supplies no `liveCollections` (every existing test) gets the pre-fix engine byte for byte.
- **Tests.** `test/assemblyTear.test.js` — a host + 5 bonded children dragged 241 ft commits **exactly one batch of 6 ops, every one at post-gesture coordinates**; a member the differ never saw is CLOSED INTO the same commit rather than dribbled out later; a queued pre-gesture payload is re-read at flush time; an unbonded element pulls nothing extra in. `e2e/assembly-move-integrity.spec.js` drives the REAL canvas logged out — a building with a 5+-member assembly (dock stack, car-parking pair, bump-outs) translates every member by the same delta and Ctrl+Z returns them all, zero page errors.
