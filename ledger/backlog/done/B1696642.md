- **THE DEFECT.** `planar:merged` fires purely from a rev-number comparison on the cloud row (`key`/`value`/`__rev` — no session, device or tab identity anywhere in that table), so "from another tab" was always a guess dressed as a fact — the same merge fires identically whether the OTHER write came from a different tab, a different browser window, or an entirely different device, and the owner's own report ("I wasn't working in another tab") is exactly the case where the specific claim is provably wrong. Checked the mirror-image banner too, as the dispatch asked: "A newer version was saved on another device." is detected the same rev-only way (`checkRemote`/the `planar:stale` event) and has the identical problem in the opposite direction — it could equally have been another tab on the SAME device.
- **THE FIX.** Both banners now say only what's actually known: **"Merged in changes saved elsewhere"** and **"A newer version was saved elsewhere."** — never guessing which of tab/window/device it was. The merge toast additionally reports WHAT changed, since that IS knowable: new `countChangedTaskRows(before, after)` (pure, module-scope, mirrored) diffs this tab's own pre-merge document against the merged result — since the merged doc is the 3-way merge of the true ancestor, this tab's pre-save doc, and the newer cloud copy, a task row that differs between "before" and "after" is exactly what the foreign save contributed. Toast now reads e.g. **"Merged in changes saved elsewhere — 2 tasks updated."**
