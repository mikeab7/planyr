- **Root cause of "everything is square" (not just a missing margin): `Ribbon.jsx`'s `ribbonBtnStyle` referenced `RADIUS.control` — a token that does not exist on `src/shared/ui/radius.js`'s `RADIUS` (only `pill`/`sm`/`md`/`lg`).** It silently resolved to `undefined`, which React drops from the style object, so **every ribbon button — Undo/Redo, Paint, Eraser, every dropdown trigger, every colour swatch — rendered at a flat 0 border-radius**, confirmed via `getComputedStyle` before touching anything (`borderRadius: "0px"`). This alone accounts for most of the "square" read on the busiest row on screen. Fixed to `RADIUS.sm` — the token `radius.js`'s own scale defines for exactly this case ("a control nested inside another rounded surface").
- **The sheet's own contained-card treatment (Stage 2, `c5c0a50ff`) was already coded — margin, `RADIUS.lg`, a border — and MEASURABLY PRESENT (`getComputedStyle` confirmed `margin:8px`/`borderRadius:12px`/`border` all applied) but was genuinely imperceptible in a real screenshot at working zoom**, because `--surface-page` (#F3F5F8) and `--surface-raised` (#FFFFFF) are only ~4% apart in lightness — a flat 1px border in that range reads as nothing. The owner's "everything is square" complaint was correct in effect even though the code disagreed on paper — a rule nobody can see is no different from one that was never written. Fixed by adding a soft `boxShadow` (design-exempt, matching the zoom control's own pre-existing shadow language in the same file) to give the card real depth the flat border couldn't provide at this contrast.
- **The ribbon and formula bar joined into ONE contained toolbar card** (`ModelApp.jsx`) — panel radius (`RADIUS.lg`), the same margin/shadow language as the sheet card below it, `overflow:hidden` to clip the ribbon's own content to the card's rounded top corners (verified this doesn't clip the ribbon's own `AnchoredMenu` dropdowns — those portal to `document.body`, confirmed live: the narrow-width "…" overflow popover renders well outside the card's bounds). A single hairline divider (the ribbon's own pre-existing `borderBottom`) marks the seam between the ribbon row and the formula-bar row inside the one card, rather than each being its own anonymous full-bleed strip.
