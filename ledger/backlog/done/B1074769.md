`[x]` **Decision: keep the caret+menu structure; do NOT reintroduce a plain secondary button.** B922816 (`docs/archive/BACKLOG-DONE.md`) shipped this exact structure to FIX a reported problem with the other option: the owner's verbatim complaint (2026-08-29) was two buttons of equal visual weight — "I don't think we should have two areas where it says start blank... instead of start blank and start blank on the main mapper, it's select parcels, maybe a drop down where you can start blank instead" — and B922816's own diff notes the map toolbar previously had "'Select parcels' and 'Start blank' as two buttons of equal visual weight side by side... competing." Re-splitting "Start blank" back out into its own co-equal button beside "Select parcels" would silently resurrect that exact, already-fixed complaint. The original NEW-1 comment on this control also already reasons about future extensibility ("a MenuItem list rather than a bare popover so a future secondary option... has somewhere to go without another redesign") — discarding that now to save one click is a net loss with no offsetting problem solved.
`[x]` **Fix: size the panel to its content instead** — `width` 200 → **148** on the `startBlankMenuBtnRef` `AnchoredMenu` only (Comp mode's 3-item "Place comp" menu is explicitly untouched, per the brief). `MenuItem` is `width:"100%"`, so the panel width fully determines the item's own width (200px panel → 186px item, exactly the measured "heaviness"); 148 is not an invented number — it matches an existing compact-menu precedent already in the app (`model/components/Ribbon.jsx`'s `width={148}` tool menu), keeping this app's established convention of a deliberately-chosen FIXED width per menu (no menu anywhere in this codebase dynamically sizes to its text content — checked: widths range 148–300 across every `AnchoredMenu` call site) rather than inventing a first-ever content-measured menu. "Start blank" (11 characters, ~70–90px at the menu's 12px/500-650-weight type) fits comfortably inside the resulting ~114px of usable item width.
