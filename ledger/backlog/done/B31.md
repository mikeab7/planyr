### B31 — Two-point Split returns null when both crossings share an edge `[Site Planner]` (bug) — minor, low
`[x]` `if (lo.i === hi.i) return null` uses only the extreme-`t` hits, so a valid straight cut across a concave parcel (whose first/last crossings land on the same edge while valid interior crossings exist) silently no-ops. Fix: when `lo.i === hi.i`, pick the two crossings with distinct edge indices that yield two ≥3-vertex rings.
