### B68 — Opening a project with saved elements renders a blank screen (`cfgOf is not defined`) `[Site Planner]` (bug) — crash, high
`[x]` Opening a project that has saved layout elements (e.g. **"Schiel Road"**) blanked the whole page; the console showed `ReferenceError: cfgOf is not defined`, thrown inside the `els.map` during render — so empty/new projects (iterating over nothing) didn't crash, which is why only populated projects blanked. **Root cause:** `cfgOf` is a component-scoped helper (`SitePlanner.jsx:2449`, it closes over `settings`), but it was *also* called at `SitePlanner.jsx:5237` inside `renderElPx` — a **module-level** function that receives `settings` as a parameter — where the component-scoped `cfgOf` is not in scope. It shipped because it compiles fine; a build-only CI check can't see an unresolved identifier at runtime. This is exactly the "disjoint-but-interdependent concurrent merge" failure mode called out in **B63**: a parking `cfgOf` call site (added with B29/B59 in PR #22) landed in a scope where the helper isn't visible, and the clean merge + green build hid it.
