- **⛔ CORRECTED 2026-09-01 — filed here as `Verify: sandbox` was WRONG, and this item's own first live CI

  proxy — succeeded), re-ran `--check` against the OLD committed baselines with the now-correct browser, and
  it reproduced the CI failure byte-for-byte locally, confirming the cause before touching anything.
  Inspecting the diff-highlight artifacts showed the mismatch was **entirely text-glyph antialiasing** (nav
  labels, the logo, header text — two Chromium point releases hint/antialias text very slightly
  differently) — never layout, color fills, icons, or borders, so this was a real instrument defect, not a
  false alarm masking something worse. Fix: re-approved all 8 baselines with the matching browser, re-ran

  `visual-regression.mjs`'s own header — "never set `PW_CHROME` to a locally-convenient alternate browser

  behavior, the same class LIVE-VERIFY already names, not a one-off.**
