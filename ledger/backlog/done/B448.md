New pure `lib/sessionBytes.js` + 5 unit tests (1434 total); logged-out render-from-cache verified V131; the keyless-mid-upload signed-in confirm logged V131.** Owner repro: drop a PDF, then immediately switch files (or reload) before the Drive/Supabase upload resolves → the source is still **keyless** (no storageKey/driveKey), so the backdrop can't be re-fetched and you land on the re-drop banner / a blank canvas with orphaned markups.

Survives the lazy DocReview workspace unmounting/remounting (a tab switch mid-upload). Only when the bytes are truly absent does the precise B405 re-drop banner show.
