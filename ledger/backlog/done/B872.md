- **Entry points:** right-click a rect building → "✎ Edit footprint (reshape)"; same as the "✎ Edit footprint…" button in Selected · Building → Footprint. Converts `el.points = elCorners(el)` (world feet, rotation baked in) + pins the dock walls.
- **Dock-frame preservation (the core design):** the loaded walls are recorded as fixed world-feet LINES (`el.dockLines`), NOT by edge index (an index shifts the moment you insert a control point on an end wall). A dock corner SLIDES ALONG its wall (drag projects onto the line, no grid snap); an end/rear vertex moves freely. v1 guards keep dock walls straight: inserting a control point on a dock edge is blocked (LOUD); deleting a dock corner is refused (consumes the Delete key, never nukes the building). `dock:"none"` → fully free editing.
- **Derived dims + downstream:** after each vertex drop, `frameBBox` recomputes `w`/`h`/`cx`/`cy` as the dock-frame bounding box, so dockSidesFor / footprintDepth·Length / the column grid / KMZ / clear-height·slab keep reading correct bounding dims; the panel Length/Depth render read-only (labeled "bounding"); footprint SF is polygon-truth (`buildingSqft` → `polyArea`). Column grid clips to the polygon ring (`clipSegmentToRing`); the dock-door count/apron repoints to the TRUE dock-wall segment (`dockSegExtent`), recounting as the wall lengthens/shortens; the truck court + its outward stack pull in to that segment (reuses the B492 clear-span trim).
- **Panel routing (fixed during the headless drive):** a reshaped building (`footEdit`) now keeps the full building inspector (Footprint reshape controls + "↺ Reset to rectangle", dock zones, structure, column grid) instead of falling through to the generic polygon inspector — the `!selEl.points` gate now also admits `selEl.footEdit`. A hand-click-drawn irregular building still gets the generic inspector (no regression).
- **Guards:** self-intersecting / zero-area / <3-vtx drop reverts to the pre-drag ring (LOUD); conversion `pushHistory` so undo restores the pristine rect. Corner bump-outs anchor to square corners → conversion is BLOCKED while any are attached (visible message, never a silent drop); the bump-out + end-wall-parking adders are disabled on a reshaped building.
- **Move/copy parity:** single-move, group-move, duplicate, and paste all carry the dock-frame box + pinned walls with the shifted ring (`shiftPointsEl` / snapshot translate) so a reshaped building never strands its dock frame at the source. Element-level sync + blob save round-trip `points`/`footEdit`/`dockLines` verbatim (no schema bump — the persistence layer stores each element as an opaque blob; agent-audited).
- **Parity:** hand-click-drawn irregular buildings (creation-time `points`, no dock frame) are untouched — prior fill-only render + fully-free editing (no regression). Only `footEdit` buildings get the constrained treatment + grid/doors.
