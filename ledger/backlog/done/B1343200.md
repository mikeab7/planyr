`[x]` **IMPLEMENTED AND VERIFIED THIS SESSION.** Every interactive element in both header strips now carries a MINIMUM ~44x44 CSS px tap area, without growing the visible chip — the brief's own constraint ("extend the target with padding and a transparent extended target rather than inflating the design into something chunky").
- **Mechanism** (`src/index.css`'s new `.tap-target` class): a generated `::after` box, centered on the control via `top/left:50% + translate(-50%,-50%)`, sized `max(44px, 100%)` on each axis — this floors the hit area at 44px without ever shrinking it below the control's own visible size, and costs zero extra DOM nodes (a press on generated content still fires its click on the host element).
- **Applied at the PRIMITIVE level, not per-instance**, so the next control built from these inherits the floor automatically (the item's own ask): `Tab`, `IconButton` and `MenuTrigger` (`src/shared/ui/controls.jsx`) all carry the class unconditionally now — this covers every module tab, the fullscreen/settings icon buttons, and the account pill / cloud-off trigger / sign-in pill app-wide, not just in the header. The header's own bespoke chips (not built from a shared primitive) got the class individually: the wordmark button, the cloud-sync badge, the Dashboard and project breadcrumb crumbs, and the Site Planner's plan crumb (`.dbtn`).
- **Type scale is untouched** — this item is about hit AREA, never font size; the brief's "below the floor the answer is fewer items visible, never smaller text" is honored by construction (nothing here shrinks any text).
- **Scope note, stated rather than silently narrowed:** this covers the breadcrumb row's own crumbs and the header's shared chrome primitives (which the module tab strip is built from) — it does NOT reach into every workspace's own `toolbarContent` icon buttons (SitePlanner's undo/redo/snap/select row, Scheduler's toolbar, etc.), which are a separate, much larger surface built from many one-off components rather than the shared `Tab`/`IconButton`/`MenuTrigger` primitives.
