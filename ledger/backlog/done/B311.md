### B311 — "Select parcels" mode toggle (non-hijacking default) `[Site Planner]` (feature) — layered on B310  *(arrived as "NEW-2" 2026-06-20; first filed B301, renumbered **B311**)*
`[x]` **Done 2026-06-20 (branch `claude/blissful-mccarthy-dkozi0`).** A **Row-2 toolbar toggle** ("Select parcels", next to Snap, shown only when the plan has parcels) as a hard-off fallback for pure browse/measure workflows where zero accidental selection is wanted. **Non-hijacking default = ON:** click a lot to select it, dragging always pans (normal selection works out of the box thanks to B310, so the toggle isn't the primary gate). **OFF:** a press on a parcel is click-through — `startMoveParcel` returns *without* `stopPropagation`, so the event falls through to the background pan exactly as if it landed on empty canvas; a click never selects. Turning it OFF also drops any current parcel selection so browse mode is clean.
- **Persistence:** stored as `settings.parcelSelect` (default `true` in `DEFAULT_SETTINGS`), so it rides the existing per-project Site Model `settings` save/restore path — saved per project, restored on reopen. No new store, no localStorage key.
- **Verified — same harness (`ui-audit/verify-b310-b311.mjs`):** default reads **ON** (`aria-pressed=true`); flipping it **OFF** → a click no longer selects (parcel stays unselected); flipping it back **ON** → a click selects again; **OFF persists across a full page reload** (per-project). lint 0 · 712 tests · build green.
