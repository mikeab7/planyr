- **THE FIX — middle truncation, applied everywhere a sheet or file name is truncated in Review, per the owner's instruction.** `shared/files/middleTruncate.js` (pure `splitLabel` → `{head, tail}`, `head + tail === text` always) + `shared/ui/MiddleTruncate.jsx`, which pins the tail with flexbox rather than measuring — so it stays right at ANY width, through a rail drag, a font swap or a browser zoom, with no measure/re-render loop. The tail is cut at a real token boundary when one fits (" - p17", not "7"), taking the EARLIEST boundary within budget so it keeps as much of the distinguishing end as it can afford, and an explicit delimiter beats a bare word break. With no usable boundary it still keeps the last characters — a blunt cut preserves identity, losing the tail does not. Every one carries the full name as a `title` tooltip.
- **Applied at:** the Stitch tray (both the grouped and the raw per-page branch — the per-page one is the owner's exact case), the Stitch placed-sheets list, and the Review sheet rail (code pinned and never truncated, title middle-truncated beside it — on a real set "OVERALL ROOF PLAN" and "OVERALL FLOOR PLAN" repeat across disciplines).
