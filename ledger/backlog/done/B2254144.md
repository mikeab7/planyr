- **What it is:** `components/ParcelStylePanel.jsx` in the parcel page's Style section (the old outline/setback colour+width+line rows are replaced by it; Fill and the three opacities stay beneath it). A scope selector at the top — "All parcels (workspace default)" | "This parcel only" (disabled with nothing selected; never applies to nothing) — then Boundary / Setback line (native full colour picker, weight slider 1–6, dashed switch) and Dimension labels (show, colour, size slider 8–16 pt, "Auto" = the existing zoom-scaled size until touched). The canvas repaints on every input event.
- **Resolution (render time):** parcel override → workspace default → built-in (`resolveParcelLook`). The workspace default is ONE blob `{boundary:{color,weightPx,dashed}, setback:{…}, labels:{show,color,sizePt}}` in `profiles.prefs.parcelLook` (own-row RLS, private by default; `userPrefsStore.setParcelLookPref` is the only writer; hex + numeric ranges validated on write — a bad value is refused out loud, never repaired). Weight/colour/dash on a parcel that already had stamped values still resolve exactly as before.
- **Weight = screen pixels, constant across zoom (owner-locked):** the boundary and the setback ring no longer pass through `strokeZoom`/`dashZoom` (the B617 "scale with the drawing" rule is deliberately gone for these two strokes); guarded by source assertions and measured live (stroke-width identical after zooming in 4 notches and out 8). The old B880 / B567 guards in `bugHuntGuards.test.js` were updated to the new rule.
- **Failure handling (crash severity):** optimistic — the on-device mirror is written on every input event; the account write is a trailing debounce (`lib/trailingWrite.js`, flushed on page-hide/unmount so the FINAL value always lands, writes never overlap or reorder). A real failure REVERTS the covered fields to their pre-burst values and shows "⚠ Couldn't save your style — it was put back (…)"; signed out it keeps the value and says "saved on this computer only" (`lib/parcelLookPersist.js`, failure paths unit-tested). **Caught live, not by reading:** the first build threw `Illegal invocation` from the debouncer (it called `setTimeout` as a method) so the account write never fired while every unit test passed — fixed and pinned by a test that fails on that shape.
- **A defaulted setback ring** (drawn only because no setback value was ever set) keeps its lighter opacity cue, but now honours a dash someone chose (the old rule forced a dotted pattern over any choice).
- **Out, as specced:** no presets, no no-build band, no buildable-envelope styling, no swatch palette, no dash-pattern picker (dashed is one pattern on/off — a legacy "dotted" parcel keeps its pattern and reads as dashed-on), no per-side label toggle (→ B2254145).
