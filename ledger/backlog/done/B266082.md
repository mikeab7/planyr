- **THE GAP.** `e2e.yml` tested exactly ONE configuration: signed in, against production planyr.io. `npm run e2e` with no `BASE_URL` tests a completely different one — logged out, against a local build — and **nothing in this repository had ever run it.** That is how B1179's `click-behavior` and `inspector-close` ended up with no watcher anywhere, and how their later fix by unrelated work went unnoticed for nine days. A second `e2e-local` job now runs that lane on the same schedule, in its own ledger lane.
- **THE SECOND HALF — a false-green assertion.** Playwright's `toBeVisible()` means "non-empty box, not `visibility:hidden`". It says nothing about WHERE the box is. In real fullscreen the header slides to `y = −44`: every module tab is still "visible", unreachable by any user, and unclickable by Playwright itself. `module-keepalive`'s "the chrome came back" assertion therefore **PASSED against a page whose chrome had not come back**, and the case died one line later on a click — which is why its real subject was never reached. New `expectOnScreen` / `expectOffScreen` helpers in `e2e/helpers.js` assert viewport position; both POLL, because the header slides (measured: bottom edge at 4.5 on the first frame, −1 once settled) — a wait, not a relaxation.
- **Deliberately NOT part of the required `build` check**, with the reason on the record: a full suite plus a build would put ~15 minutes on every pull request, and a gate people route around is worse than one that runs nightly and is read.
