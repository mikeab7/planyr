### B628 — Dedicated canvas right-click menu (never the browser's), with Delete on a deed / parcel `[Site Planner]` (feature)  *(owner-reported 2026-07-03 — "I should be able to right-click a parcel from a metes-and-bounds and delete it… it should be a dedicated menu for something on the map. `[x]` **Shipped this session.** A right-click **anywhere on the planner canvas now opens OUR menu, never the browser's** — the svg root's `onContextMenu` always `preventDefault`s (was: only cancelled an in-progress road draw, so every other right-click leaked the Chrome menu). What the menu offers depends on the target:
- **A markup — deed/encumbrance, easement, utility route, traced line, or a neutral line/rect/ellipse/polygon** (wired via `onMarkupContext` on each markup `<g>` + the shared `common` props): **Lock/Unlock** + **Delete**. For a plotted **deed** it also offers **Align to county parcel** (falls back to "Rotate to grid north" with no parcel — the B625 action) and Delete reads **"Delete deed + exceptions"**, removing the whole `deedGroup` (boundary + its save-and-except holes) as one unit.
- **A parcel** (existing `parcelMenu`): gained a **Delete parcel** item alongside Merge/Clear (`onParcelContext` now carries the id).
- **Empty canvas**: a **Map** menu — **Zoom to fit** + **Paste** (enabled when a shape/overlay is on the clipboard).
- Overlays/elements keep their own menus (each stops propagation before the root handler; the B230 right-click-to-add/delete-vertex capture handler still wins on a selected editable path's edge/corner).
- **Every delete tombstones** (`tombstone(...)` → `deletedIds`) so a cloud/cross-tab union-merge can't resurrect it (B556/B612).
- **Tests:** lint 0 · **2226 tests green** · build green · headless `ui-audit/verify-b627-context-menu.mjs` **5/5** (right-click a deed opens our Align+Delete menu not the browser's; Delete removes the deed AND its save-and-except hole AND tombstones both; right-click empty canvas opens the Map menu; a canvas `contextmenu` is default-prevented). Added a `data-testid="parcel-outline"` hook (mirrors the B625 `deed-boundary` hook) for the harness.
