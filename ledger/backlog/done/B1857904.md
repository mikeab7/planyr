`[x]` **THE BUG, reproduced two independent ways.** (1) An isolated `@playwright/test@1.61.1` capture (three cases: plain pass, `test.skip()`, fail-then-retry-pass) showed the real skip shape is `ok: true, tests[0].status: "skipped", results: [{status:"skipped"}]` — ONE result, never an empty array. (2) The REAL fixture already committed in this repo, `test/fixtures/playwright-report.sample.json`, already carries a genuine skip — `auth.setup.js`'s "authenticate once" step, skipped whenever `E2E_EMAIL`/`E2E_PASSWORD` are absent (this sandbox's own condition) — and nothing in `test/e2eDriftGate.test.js` had ever asserted on its status. `collectCases()` (pre-fix) reported it as `"passed"` in both cases: the function branched only on `spec.ok` (true for a skip, since Playwright never counts a skip as a failure) and on `some(status==="flaky")`, never on `tests[].status === "skipped"`.
`[x]` **WHY IT IS NOT COSMETIC.** `nextLedger()`'s `--update` path drops a ledger row the instant its case reads `"passed"`. Pre-fix, a required known-red case that merely FAILED TO RUN (a missing secret, a filtered project) — never one that genuinely passed — could have silently discharged a real ledger row with the underlying defect never re-checked even once.
`[x]` **THE FIX (`scripts/lib/e2eDrift.mjs`).** `collectCases()` now checks whether every `tests[]` entry reads `"skipped"` FIRST, before the `spec.ok`/flaky branch. Narrow and additive: a real failure, a real pass, and a real flaky-retry all classify exactly as before; only the genuinely-skipped case changes, from `"passed"` to `"skipped"`. A mixed multi-project result (skipped on one project, run on another) deliberately falls through to the old logic unchanged — this collector does not track project identity, and that is out of scope for this fix.
`[x]` **A completeness signal, added narrowly per the dispatch's "distinguish required release runs from filtered diagnostics" instruction.** New pure function `assessCompleteness(report)` reports whether a Playwright JSON report reflects a FULL run, using `report.config.shard` (structured `{current,total}` when `--shard` narrowed the run) and `report.config.argv` (the literal command line, so `--grep`/`--project` show up verbatim). **`config.grep`/`config.grepInvert` do NOT work for this** — measured directly, both with and without `--grep`, Playwright serializes the parsed RegExp to `{}` in the JSON report either way. Wired into `scripts/e2e-drift-gate.mjs` as an always-printed status line plus an **opt-in** `--require-complete` flag (unused by today's `ci`/`local` lanes — deliberately NOT wired into `.github/workflows/e2e.yml` in this PR, left for whichever session builds the R2 critical-interaction lane that will actually consume it, per "narrowest safe" scope for this stage). `compare()`'s return grew a `skipped` count for visibility (a skip is reported, never silently invisible) — a skipped ledgered case now correctly lands in `absent` (reported, not fatal, not treated as a fix), not falsely `stale`.
`[x]` **PROVEN, mutation-checked.** Reverted `collectCases()` to the pre-fix branching and re-ran the suite: exactly the 3 targeted regression tests failed (`expected 'passed' to be 'skipped'` ×2, `expected 'passed' not to be 'passed'`), all 39 others stayed green. Restored the fix: all 42 green again.
