`[x]` **FIXED + verified this session (build green · 4776 unit tests · real logged-out canvas e2e).** A callout / text box whose text is wide — long all-caps lines like the owner's "COULD ADD VOLUME TO ADJACENT MASON BASIN" — drew its text straight past the right/left edge of its box. - Origin: filed 2026-07-21 from chat.
- **Root cause (AUDIT-FIRST):** B913's `calloutLayout` (`src/workspaces/site-planner/lib/calloutLayout.js`) sized the AUTO-width box from a flat `line.length * charW` estimate with `charW = fontPx * 0.56` — a monospace guess. The committed `<text>` renders in proportional **Inter**, where wide glyphs (all-caps M/W/A) run well past 0.56·fontPx, so the estimate under-sized the box and the real glyphs spilled out. This is the SAME class of bug B909 fixed for the Doc Review shared engine — but the Site Planner callout path never adopted the real-measurement module. (B918's "already fixed by B913" claim was therefore wrong; corrected there.)
- **Fix:** `calloutLayout` now measures REAL glyph widths via the shared `src/shared/markup/textWrap.js` `bestMeasurer` (a real `<canvas>` `measureText` in the browser, matching the app's Inter face to sub-pixel precision; the per-char heuristic in Node so the module stays pure/Node-testable) — bold/italic fed through so heavier glyphs size wider. AUTO width hugs the widest REAL line; EXPLICIT (dragged) width now wraps via `wrapText` (width-based, mirroring the editor's soft-wrap) instead of the old char-count `wrapLines`. The flat `charW` remains only as the coarse floor inside `minCalloutWidthFt`.
- **DEDUPE-FIRST:** recurrence of the Site Planner half of the callout-overflow class (B918 punted it as "fixed by B913"; B913 introduced the flat estimate). Not the Doc Review half (B918, separate `MarkupRenderer`/`textWrap` path — unaffected).
- **Verified (sandbox/headless):** unit — `test/calloutLayout.test.js` updated to real measurement + a new invariant test (the AUTO box encloses every line at ppf 0.2/0.35/0.9) + a proof the box is now wider than the old flat estimate; full suite green (4776). e2e — new `e2e/dim-callout-edit.spec.js` "B929" places the exact all-caps string on the logged-out canvas and asserts the committed `<text>` fits inside the box `<rect>`. Build green; MAP/doc-pointers clean.
