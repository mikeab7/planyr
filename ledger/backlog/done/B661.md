- **Fix:** `scripts/build-parcel-snapshot.mjs` is now **source-resilient** — each county carries an ORDERED candidate list tried until one clears its min-count (keep-last-good if none). Chambers/Waller PRIMARY is now the **public AGO-hosted "StratMap25" FeatureServer** (`services1.arcgis.com/1mtXwieMId59thmg/.../2019_Texas_Parcels_StratMap/FeatureServer/0`, TPWD-owned, 2025 vintage, `capabilities:Query`, on an independent host immune to the TxGIO outage). It has **no county field**, so a new `county-poly` provider kind fetches the county boundary polygon (TxDOT `Texas_County_Boundaries`, field `CNTY_NM`) and **POST-spatial-queries** the parcels layer scoped to it. TxGIO `/query` is kept as a documented preferred-when-healthy fallback; Fort Bend stays on FBCAD (a plain query). The builder stamps `county` on each feature (the AGO layer lacks it) so the "Cached copy · <County>" badge works.
