- **Measured on main (red-proof):** a column letter's click selected the column but the Name Box still read `C1`; a **row number click did nothing** (selection and Name Box unchanged); drag across headers and Shift+click did nothing useful; the top-left corner box was inert (the click timed out — nothing there); header right-click menus lacked Clear contents / Hide / Unhide.
- **Built (all in `lib/selection.js`, used by SheetView, FormulaBar, ModelApp and the keyboard):** a whole column/row is ONE RANGE `{r1,r2,c1,c2}` (`wholeColumns/wholeRows/wholeSheet`), never a walk over cells. Click a letter/number → whole line, active cell = its first cell, Name Box reads `C:C` / `5:5` (`A:C`, `2:7` for runs, `A:Z` for everything); drag across headers extends; Shift+click grows from the anchor; the corner box selects the whole sheet; typing `C:C` / `5:5` into the Name Box selects it too. Bold, fill, font colour, number format, alignment, Delete/clear, Ctrl+Shift+= / Ctrl+- all act on the range. Right-click a header: Insert / Delete / Clear contents / Hide / Unhide / Column width… or Row height… / Autofit / Freeze (a right-click inside the current whole-line selection keeps it and acts on every selected line). The 6-px resize strip on a header border still wins the press: dragging it resizes, double-click on it autofits, the middle of the header selects (harness H6).
- **Ctrl+click on a header ADDS that whole row/column as another range** (after merging main's multi-range model, `lib/selectionModel.js`, B2530689). Shift+click/drag extend only the newest range; commands that need one rectangle (copy, paste, insert/delete, hide, autofit, merge) show Excel's "This action won’t work on multiple selections." (harness H4 asserts the two-range Name Box/outline and the notice).
- **Cost to know:** formatting a whole column/row/sheet writes a style entry for each EXISTING cell of the sheet's current rows (≈1,000 for a column; ≈26,000 for the whole sheet) because this model has per-cell styles only — there is no column-level style. Cells added later (typing past the end) do not inherit it. Copy of a whole line takes only its USED part.
