- **THE REAL BUG IN THE APPROVED DESIGN — FOUND AND FIXED, NOT COPIED.** Every link in the owner-chat design pointed at bare `https://planyr.io`. `index.html`'s front-door redirect sends any visitor with no `planarfit:`/`sb-*-auth-token` key in `localStorage` and no `?app` in the query string straight to `/landing/` — so "Open Planyr," as drawn, would have bounced a brand-new visitor right back to this same page. Fixed: "Open Planyr" → `/?app` (the existing bypass); "Create an account" → `/?app&auth=signup`; "Sign in" → `/?app&auth=signin`. The `auth=signin|signup` deep link is new, small, and load-bearing — without it the two auth links would have booted the app to a bare screen with no visible next step, which is not "correct" even though it wouldn't loop. `src/app/Shell.jsx` gained a one-time mount effect that reads `?auth=`, opens the existing `AuthPanel` on the right tab, and strips the param via a plain string splice (not `URLSearchParams.delete()+toString()`, which would have re-serialized a bare `?app` flag as the uglier `?app=` — caught and fixed during verification, not left in); `AuthPanel.jsx` gained one new `initialMode` prop feeding its existing `mode` state (default unchanged — every other caller is untouched).
