`[x]` **Shipped this session.** Typing a Finish date pins it as a **hard finish constraint** and shows a **padlock toggle** on the Finish field — the exact icon + interaction as the existing Start lock (which I inspected first: the amber padlock SVG on the Start cell, driven by `pinnedStart`; see B615's recorded findings). The two locks are now visually and behaviorally identical.
- **Semantics:** a locked finish is an absolute date the schedule is measured against — the `pinnedEnd` task's `end` is a **fixed point** in `cascadeDates` (successors cascade from it; it never moves when the predecessor chain slips). The start back-calcs from the locked end to preserve the working-day duration (`startForEnd`, the working-day inverse of `calcEnd`). **Precedence:** the locked finish is the constraint; the duration/predecessor-derived finish is **checked against it** — if the chain forces a start too late to fit the duration before the locked finish, the task is flagged `finishConflict` **loudly** (a red banner listing the tasks + a red ⚠ on the row) and the end is **never** silently overwritten or exceeded — the user resolves it (move the finish, shorten the duration, or change the dependency).
- **Implementation:** `pinnedEnd` mirrors `pinnedStart` — set when a Finish is typed (`updateTask`/`previewProject`), cleared by the padlock click (which re-flows the finish from start+duration). The Finish cell renders the same padlock SVG + tooltip; a conflict adds the ⚠ + danger color. The holiday-recompute + all load paths preserve a locked finish (never re-derive its end). Confirmed the interaction with `cascadeDates` so the locked finish participates as a fixed point, not a floating output.
- **Tests:** covered by the B615 batch — `startForEnd` inverse, pinnedEnd no-preds (end held, start back-calc, no conflict), a conflicting predecessor (conflict flagged, lock held), a non-conflicting predecessor (no flag), and a successor cascading from the locked finish; + anti-drift guards for the lock icon, unlock path, and banner. lint 0 · 2201 green · build green.
