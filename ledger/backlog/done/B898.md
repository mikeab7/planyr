- **⛔ INCLUSIVE BY DESIGN, never AHJ-exclusive (owner correction mid-session, chat NEW-2):** every merge-group member toggles TOGETHER and renders whatever its own source returns for the current view — nothing filters by the parcel's jurisdiction. A site near a boundary or in an ETJ can be served by a neighboring provider (CCN extension, wholesale supply, a nearby main), so hiding a provider based on "which AHJ contains the parcel" would hide a real option. The existing coverage/Relevance system (`coverage.js`, buffered ~2.5 mi default, defaults to "Dim" not "Hide") is the only dimming mechanism — it was already inclusive-by-default, not changed. The merged row's ⓘ lists every contributing provider by name (`mergeGroupInfoSections`) so a user can tell whose main/territory each feature is.
