`[x]` `docs/DESIGN.md`'s radius section gained "The shape rule" — `pill` reserved for CONTAINERS only (never a standalone control's resting shape), `md` for standalone controls, `lg` for containing surfaces, `sm` for anything nested (resolved via `nestedIn()`, never picked by eye) — plus the binding clause: a nested control must carry the SPECIFIC family `nestedIn()` derives for its own container, not merely "some legal number." A worked example (`MapFinder.jsx`'s `SiteCompSwitch`) documents the one escape: when a container is already `sm` (the smallest non-square step), a directly-nested control snaps to the CONTAINER's own radius rather than mint an off-scale derived value (`nestedIn(sm, 2)` floors at 4, a fifth number no step names) — matching the container exactly beats a perfectly-concentric-but-invented number. Documented exception 4 covers Leaflet's own map controls (zoom stack, locate button, scale bar) as third-party chrome brought onto the scale where a curve is genuinely visible, with the scale bar named as the deliberate non-fix (a ruler with no fill has no box for a radius to make visible).
`[x]` **Mechanical guard, `ui-audit/ui-inventory.mjs`'s new `nestingMismatches()`:** for every crawled surface, walks the real rendered DOM, finds each rounded control's nearest rounded visually-containing ancestor (bounded to a few DOM hops, requiring a real inset and corner-proximity so a control floating in the middle of a big panel doesn't false-positive), and asserts the child's radius equals `nestedIn(ancestorRadius, measuredGap)` (or the container's own radius, per the small-outer-radius fallback above). This is a check `design-drift-audit.mjs` cannot make — that guard is a pure text scan with no DOM and no geometry, so it can confirm every number is somewhere on the scale without ever seeing that two adjacent on-scale curves disagree. Findings print in `docs/UI-INVENTORY.md`'s new "Nesting mismatches" section. Tolerances (1.5px on the derived-vs-actual comparison, corner-proximity requirement, minimum 3px inset, minimum 1.5px gap) were tuned against this session's own real findings — see B942178 for what it caught and how each was resolved, including the two identified as measurement-convention noise (box-model border inclusion) rather than real drift.
