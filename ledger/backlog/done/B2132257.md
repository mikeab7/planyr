- **Owner's answer, verbatim (2026-10-05):** "If the window goes really small, then I'm okay with the predecessor and successor text being one line. At my normal ultrawide that I have at work, I want it to be two lines, but if we get small enough, then yeah, of course we can adjust." This RESOLVES the conflict the original entry flagged: B655552's two-line spec stands at every normal width; the one-line form is allowed only when the column is too narrow.
- **What shipped (`DepCell`, `public/sequence/index.html`):** a ResizeObserver on the cell's OWN box (`offsetWidth`, never the window) picks the mode — so Grid, Split's grid pane and a user-resized column all behave the same. **Threshold: one line below 110 wide, back to two lines only at 126 or wider** (`DEPCELL_ONE_LINE_BELOW` / `DEPCELL_TWO_LINE_AT`, pure `depCellNarrowNext`); inside 110–126 the cell holds whichever mode it was in (hysteresis, no flicker when a drag parks on the boundary). **Why 110:** the two-line form needs the label's hanging indent (up to ~38 for a "20FS+360d" label) plus a readable run of name on the continuation line; under ~110 that run is a word or two and "24 · Find and send Wire…" on one line reads better. The default column is 148, so the default look and the wide look are untouched. One-line form: label (never truncated) + name with ellipsis + "+N" for several links, vertically centred; the full-text tooltip and the "+N" hover list are unchanged; the editor still edits the full value. Row height never changes.
- **Not reproduced, stays retracted:** the earlier "text spills past its row" claim — 0 spills at every point, before and after. The defensive clip from PR #2055 stays.
- **Measured honestly:** window width does NOT change a column's width (columns are fixed-width and the grid scrolls sideways), so "narrow window" only produces one line when the column itself is narrow. The sweep therefore drives it with three column configs: `dflt` (148, the default), `owner` (260, resized wider) and `narrow` (96, resized narrower) at 800–2560 × 450/900, Grid and Split.
