`[x]` **SHIPPED THIS SESSION — root-caused to a path the owner correctly suspected but couldn't name.** `comps.js`'s `emptyDraft(anchor)` hardcoded `compType: "land"` unconditionally, for every caller, regardless of whether `anchor` carried anything at all. `CompsPanel.jsx`'s `pendingAnchor` effect calls exactly this — `emptyDraft(pendingAnchor)` — the moment a location is picked (the map toolbar's "Place comp" button, a parcel select, or a site-plan pin) with NOTHING already armed and NOTHING already open waiting to receive it: a fresh map click with the Comps sheet closed, or with the sheet open but every existing row already located.
