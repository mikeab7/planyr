So like, you know, my road names are on, so they should show up in the exhibit."
- Cause: on screen the street names are the vector road layer (MapLibre GL in Leaflet, `vectorLabelLayer.js`), a WebGL canvas the export's SVG clone never captured; the export path had no street-name step at all (the aerial stitcher only fetches imagery).
- Fix: `exportSheet.exportRoadNamesForFrame` renders an off-screen MapLibre map with the SAME "site" style (`shared/basemaps/roadNamesSnapshot.js`) on the sheet's extent at the sheet's label scale (`sheetLabelPpfFor`), pixel ratio 2-4, placed from the map's own bounds, right above the aerial and under GIS bands + the plan. Gated by the Layers panel's Road Names row (incl. its opacity) and the aerial being shown; no print-only switch. Raster Esri road names when the vector source is down; both down -> printed without them + a warning (LOUD-FAILURE). A frame too wide for the Site Plan map to draw roads prints none (`SITE_ROADS_FROM`).
