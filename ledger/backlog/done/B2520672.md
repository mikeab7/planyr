`[x]` **Done — shipped 2026-10-29.** `extractUnlabeledLine` (`src/shared/comps/lib/compParse.js`) took the FIRST date on a line matching `COMMENCEMENT_LINE_RE` as the commencement date and then blanked the WHOLE line before rate/size/escalation/title/execution date were read. Proven on main d0c93cd: `"150,000 SF lease at $0.55/SF/mo NNN, 5.25% bumps, commencing 12/1/2026"` kept only type + commencement; `"Acme Logistics, 120,000 SF, $0.58/SF/mo NNN, RCD 3/1/2027"` dropped title/size/rate; `"Lease executed 9/15/2026, commencing 1/1/2027"` stored the execution date as the commencement date.
**Fix:** Claims only the commencement keyword + the date NEAREST AFTER it (else the nearest date before it), blanks just that span, and every other detector reads the rest of the line; the execution-date detector now runs on the remainder, so a second date on the line is the executed date. A commencement line whose date wasn't claimed still skips the execution-date detector (unchanged).
