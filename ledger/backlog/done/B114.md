### B114 — Snapping always on; can't be suppressed during a drag `[Site Planner]` (bug)  *(arrived as "NEW-1")*
`[x]` Done 2026-06-16 (branch `claude/epic-dirac-3ljl49`). Dragging an element (e.g. a road) near a neighbour flush-snapped it to that neighbour's edge with no per-move escape, so you couldn't drop it at a deliberate offset (a 15-ft buffer behind trailer parking). Root cause: the existing "Alt-drop to place free" only skipped the *bond* at drop (`onUp`'s `!e.altKey` guard); the element had already been moved to the flush-snapped position during `onMove`, so Alt never placed it freely — and there was no keyboard toggle. Fix:
- **Hold-to-suppress (the standard CAD pattern):** a new `altSnapOffRef`, re-armed from `e.altKey` on every `onBgDown`/`onMove`, makes the live snap = `settings.snap && !altSnapOffRef.current`. `snap()`/`snapPt()` read it (so grid snap, draw, vertex, and placement all honour Alt), and a per-frame `snapOn` gates the inline paths the core helper doesn't cover — the ambient neighbour flush-snap (`edgeSnapCenter`), resize/edge-resize-to-grid, and rotate-to-15°. Holding Alt bypasses ALL of them for that one move and re-enables on release. Shift-drag (deliberate align+bond) is unaffected.
- **Toggle + shortcut + default OFF:** the toolbar button stays, plus a new **S** shortcut and the Site-defaults checkbox toggle snap; "off" fully disables every snap path above. Per owner request snap now **defaults OFF (free movement)** and is a **global drafting preference** (a tool mode), not a per-site attribute: it lives in `localStorage` (`planarfit:snap`, default off) via `loadSnapPref`/`saveSnapPref`/`setSnap`, seeded at the settings `useState` and preserved across JSON import, so the per-site saved `snap` is ignored on load (every existing site started free, regardless of its baked-in `snap:true`). Turning it on persists across sites/reloads until turned off. (`settings.snap` is still the field every read site uses — it just mirrors the pref now.)
- **Visible state:** the toolbar pill now reads `Snap 10′` ↔ `Snap off` (green/grey dot, `aria-pressed`), the Site-defaults checkbox is relabeled "Snap to grid & neighbours (S)", the Select-tool hint says "hold Alt to bypass snap & place freely • toggle snap with S", and the shortcuts panel gains `S → Toggle snap` and `Alt drag → Bypass snap`. Build green; lazy-chunk split intact. **Browser-verify** logged in VERIFICATION.md.
