### B490 — PDF viewer: optional-content (OCG) layer toggle `[Doc Review / Markup]` (feature) — ✅ DONE 2026-07-03 (batch `claude/backlog-review-batch-vfz167`)
A "▤ Layers" control in the Review toolbar shows/hides a PDF's optional-content groups (e.g. turn off Electrical to see just the site plan). New pure `lib/ocg.js` (`ocgLayerList` + `deriveLayerVisibility`) iterates pdf.js's OptionalContentConfig — v6 has **no `getGroups()`**, so it uses the `[id, group]` iterator; `renderInto` threads the retained config via `optionalContentConfigPromise`; `DocReview` extracts the config on load (`readOcg`, guarded on `pdfRef` against a superseded load), lists the groups in a **portaled `AnchoredMenu`** popover (escapes the toolbar row's `overflow:hidden` clip — a hand-rolled popover was clipped), and re-rasters both layers on toggle. Visibility is **in-memory** (a view filter, never the immutable markups). **Required a pdf.js polyfill:** the modern ESM build calls `Map.prototype.getOrInsertComputed` (a TC39 proposal) but — unlike the legacy build — doesn't bundle it, so `getOptionalContentConfig()` threw; added a guarded polyfill in `lib/pdf.js`.
Verified: new `test/ocg.test.js` + full suite **2225** green · lint 0 · build green + DocReview lazy chunk intact · headless `ui-audit/verify-ocg.mjs` (**8 checks**, hand-authored 2-layer OCG fixture `e2e/fixtures/sample-ocg.pdf` via `ui-audit/make-sample-ocg-pdf.mjs`): the Layers button appears, the popover lists Electrical+Plumbing and is genuinely **visible (not clipped)**, unchecking Electrical re-rasters red→0 while blue persists, re-checking restores it, no page errors.
