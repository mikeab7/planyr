**Measurement blockers, recorded so a later harness doesn't rediscover them:** (a) `performance.measureUserAgentSpecificMemory()` is unavailable on planyr.io (no cross-origin isolation), so full-tab memory is NOT directly measurable from that surface — the non-JS share is inferred, not observed; (b) cross-origin tile responses carry no `Timing-Allow-Origin`, so `transferSize` is 0 and every byte figure comes from re-fetching sampled tile URLs rather than resource timing; (c) the default resource-timing buffer is **250 entries and it filled during load**, silently pinning tile counts — any harness built for NEW-8 must call `performance.setResourceTimingBufferSize()` before measuring or it will under-report; (d) no DevTools heap snapshots from that surface — the sampled-counter series is the substitute.
