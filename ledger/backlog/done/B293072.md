- **UNJUSTIFIED DRIFT — closed:** (a) the element menu could not reach its own inspector or copy, while every other family could; (b) the element menu said **Pin/Unpin** for the identical `locked` field every other family calls **Lock/Unlock** — one concept, two words; (c) markup, callout and measurement had **Copy but no Duplicate**, while elements and references had both; (d) the measurement menu rendered **two of the four** Arrange modes though all four chords were already wired; (e) a callout honoured `c.locked` throughout the render and every gesture handler, with **no control anywhere in the app** to set or clear it — so an annotation could not be locked, and a legacy locked one could never be freed. Duplicate is now ONE `duplicateRef` built on the clipboard pair the app already had, not a fourth bespoke cloner.
- **JUSTIFIED — left different, with the reason written down** on each cell of the table: a line/polyline has no fill (no enclosed area); a vertex path has no single rotation axis; a road is sized by its centreline, not a W×H box; an easement's corridor is derived from its centreline so a free rotation would desync it; a measurement has no independent fill or dash (its line style is what makes it READ as a measurement) and no rotation (it would change the number it reports); annotation text stays horizontal; a parcel has no typed size or rotation (it is georeferenced — typing a width would falsify the boundary).
- **JUDGEMENT CALL FOR THE OWNER — deliberately NOT decided:** should a site ELEMENT be allowed to cross the type-layer rule (paving drawn OVER a building)? Today that rule is absolute (road → paving → pond → parking → building) and Arrange only reorders within a band, while markups, measurements and references each have an explicit cross-the-plan escape hatch. It is a drawing-convention decision, so it is parked as an `{ open: … }` cell on every element row rather than closed by a session.
- **THE DURABLE FIX (this is the part that stops it drifting again):** `e2e/elementCapabilities.table.js` declares, for EVERY selectable type and EVERY capability in a shared vocabulary, one of `"yes"` / `{ na: "<why this type lacks the concept>" }` / `{ open: "<question for the owner>" }`.
