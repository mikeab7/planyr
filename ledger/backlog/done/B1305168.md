- **What differs from the pasted source, all deliberate:**
  - **Dimmed for a working surface.** The pasted renderer strokes contour lines at full opacity (it's the landing page's main event); here they draw at `DIM_ALPHA = 0.32` so they read as quiet texture in the gutters between cards and never compete with a card's own text. Tuned by screenshotting the real dashboard (both themes) and looking at it, not guessed.
  - **Theme-aware colors, not the source's literal hex.** Contour line colors come from `usePalette()` (`shared/theme/ThemeProvider.jsx`) — `borderStrong`/`textTertiary`, the same JS-mirror-of-CSS-tokens mechanism the drafting canvas already uses, because the landing page is permanently dark and the dashboard is not. The cursor's coral highlight comes from `BRAND.coral.top`/`BRAND.coral.mid` (`src/shared/brand/tokens.js`) — real brand hex, converted to rgba — replacing the pasted source's approximated coral literals (`rgba(249,136,114,…)`/`rgba(240,112,90,…)`).
  - **Kills the loop during a react-grid-layout drag or resize.** `Dashboard.jsx` wires `onDragStart`/`onDragStop`/`onResizeStart`/`onResizeStop` to a `gridInteracting` flag passed into the background as `paused` — the component cancels its `requestAnimationFrame` loop for the gesture's duration and resumes the instant it ends, so a full-viewport repaint every frame never fights a drag. Verified live (headless): the canvas's own pixels are provably frozen (byte-identical `toDataURL()`) for the whole time a drag or a resize is held, and resume drifting within the next animation tick after release.
  - **Fixed behind everything, `pointer-events: none`.** The canvas is `position: fixed; inset: 0; z-index: 0`; `Dashboard.jsx`'s scrollable content wrapper (the one holding the grid) gets its own `position: relative; z-index: 1` stacking context so the cards (plain `position: static`) paint above it regardless of DOM order — the same `main`(0)/workspace-wrapper(1) stacking pattern `Shell.jsx` already uses. `AppHeader` needs no change; its own row already carries `position: relative; z-index: 60`.
  - **Cards were already opaque.** Checked `DashboardCard.jsx` and every card renderer in `components/*.jsx` for a translucent own-background before assuming a fix was needed — `DashboardCard`'s shell uses `var(--surface-raised)` (`#FFFFFF` light / `#1D2027` dark, no alpha) and no card component sets its own competing background.
