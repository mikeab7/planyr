- **⛔ THE SECOND ATTEMPT'S NAMED HOLDER IS REFUTED, and the reason generalises.** `holderOf` stops at the first retainer that is not FLAGGED detached — sound only if "not flagged" implies "alive", and it does not: **V8 sets `detachedness` on DOM WRAPPERS ONLY.** A closure that is itself garbage, reachable only from inside the dead island, satisfies the stopping rule perfectly. The `native_bind` holding the overlay file `<input>` as its third bound argument is exactly that: **React DOM builds that shape for every non-delegated listener** (`listenerWrapper.bind(null, domEventName, eventSystemFlags, targetContainer)`, three arguments, third is the element) and an `<input>` gets one for `invalid`. It points at the input because it was MADE for the input, and the pair is a cycle inside the island. **This is the THIRD correction in the family** — the shortest path is the wrong question → a native node is not a holder → a JS object reachable only from inside the island is not a holder either.
- **THE COMPLEMENTARY QUESTION, which cannot fail that way.** Walk FORWARD from the GC roots refusing to pass through any detached node; everything reached is provably alive; the leak is the edges crossing into the island. Two load-bearing rules: the handle tables are **not traversed through** (every DOM wrapper is in one, so a walk through them names the table — the same always-true, never-useful answer), and a detached node is recorded and never expanded, so the result is the island's BOUNDARY.
- **THE RESULT: 6 crossings out of 357,982 live nodes, every one of them Leaflet, every one WEAK.** Each is a `CSSStyleDeclaration` pointing at `leaflet-tile-container leaflet-zoom-animated` (×2), `leaflet-layer`, `leaflet-container leaflet-touch` and two plain `<div>`s — and each of those bottoms out at `(Traced handles)` through a **`weak:` edge**, which does not retain. **Not one SVG node, not one panel, not one rail button.** So (a) nothing in live JS strongly references the island, which with §5's clean listener census and clean cleanup sweep puts the reference on the **Blink side**; and (b) **§4's ruling-out of Leaflet should be treated as re-opened** — its evidence was that container and tile COUNTS return, and a returning count means a new container replaced the old one, not that the old one was released.
