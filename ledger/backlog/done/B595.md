`[x]` **Fixed this session — membership-anchored read-back + a cross-tab merge tripwire. *Moves to BACKLOG-DONE on merge.***
- Part of: **B648** (Persistence & Sync epic).
- **Why the notice lagged (found in the same audit):** the immediate B458 mirror verifies the on-device write by **count** (`drawnCount got < want`). A same-count swap — one item dropped while another lands, exactly the B594 tombstone/id-collision fold — leaves `got==want`, so the count check is **blind** to it; the loss only surfaced later when the thinned cloud push tripped a CAS conflict / the user noticed. So the indicator was a lagging symptom, not an edge-of-loss alarm.
- **Fix:**
  - **Read-back now verifies by MEMBERSHIP, not just count:** `writeMirror` collects the ids it just wrote and confirms each one read back; a missing id flips the loud `localSaveFailed` banner **within the ~50ms mirror** (edit-anchored, not push-anchored) + records `save-verify-failed{ missingId }`. No cry-wolf — it only fires when an id we literally just wrote is absent.
  - **Cross-tab merge tripwire:** the `storage` handler now asserts the union never drops a live id without a tombstone explaining it; if it ever does (a future regression of the B594 class), it goes LOUD to telemetry (`merge-dropped-live`) instead of silently shrinking the canvas. Reuses the B468 telemetry pattern.
  - **Cross-tab convergence signature is now id-membership, not collection counts** (`SitePlanner.jsx` `onStore`): a same-count remote swap (other tab deleted one item + added another) used to be skipped by the count-only `sig()`, leaving two tabs permanently divergent — now they converge (and a pure remote delete re-hydrates).
- **Verified:** covered by the B594 gate (lint 0 · 2072 tests green · build green). The live signed-in confirmation that a genuinely non-landing save now flips the badge promptly is folded into **V185**.
- **Dedup:** folds into **B125** (loud-failure scope) + **B134 #4** (silent save error) rather than minting a parallel mechanism; the net-new ask — detection must cover the **silent same-count no-op**, not only writes that throw — is what this adds.
