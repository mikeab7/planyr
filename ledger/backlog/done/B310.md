### B310 — Accidental parcel selection while panning the planner canvas `[Site Planner]` (bug)  *(arrived as "NEW-1" 2026-06-20; first filed B300, renumbered **B310** — concurrent `main` consumed B300–B309)*
`[x]` **Done 2026-06-20 (branch `claude/blissful-mccarthy-dkozi0`).** With parcels rendered, grabbing the planner canvas to pan kept registering as a parcel select — `startMoveParcel` (`SitePlanner.jsx`) fired `setSel` on pointer-**down** and `e.stopPropagation()` blocked the background pan, so a press anywhere on a lot selected it whether the gesture was a click or the start of a drag. Navigating across lots felt like constantly clicking into them.
- **Fix — click-vs-drag discrimination on the parcel layer.** A press on a **locked** parcel (the default every county-pulled / drawn lot carries — created `locked:true` in all six creation paths) now starts a **PAN** (`drag.current.mode:"pan"`) tagged with the parcel id + the press origin (`tapParcel`, `downX/downY/downT`), instead of selecting. On pointer-**up** (`onUp`) it counts as a deliberate **click → select** only if travel ≤ `PARCEL_CLICK_SLOP_PX` (**5px**, measured in SCREEN px so it's zoom-independent) **and** the press was < `PARCEL_CLICK_MS` (**400ms**); any larger/longer movement panned and leaves the selection untouched. Uses Pointer Events + `setPointerCapture` (already the canvas's model) so the up fires even if the pointer left the polygon, and the gesture joins the existing `abortGesture` recovery (`capturePidRef`) so an interrupted parcel-pan can't strand the grab cursor (B271-class).
- **Preserved:** a deliberately **unlocked** parcel still grabs-to-move on press (you unlocked it to reshape/move it — matches elements); the full-polygon hit area is unchanged (we gate on gesture *intent*, never shrink the target); Shift-click-to-merge and align-edge picking still work. Space / the Pan tool remain the always-on pan escape hatches.
- **Verified — lint 0 · 712 tests · build green; `SitePlannerApp` lazy chunk intact.** Headless on the built app (`ui-audit/verify-b310-b311.mjs`, logged-out, seeded one locked parcel): a deselected→**click selects** (stroke→#c2410c / width 3); a **drag of 95px pans and does NOT select** (stroke stays #5b6650 / width 2, the parcel's on-screen box shifted +95px), **0 page JS errors**. Logged as **VERIFICATION V78**.
