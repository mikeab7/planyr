Origin: filed 2026-09-03 from chat. Minted from the reserved block via `npm run next-id -- --against-main`.)*
`[x]` **SHIPPED.** `src/shared/ui/radius.js` exports `RADIUS` (keys `pill`/`sm`/`md`/`lg`); `src/shared/ui/controls.jsx` exported a DIFFERENT object also called `RADIUS` (keys `control`/`pill`/`panel`). Which keys were valid depended entirely on which module a file imported from, and a miss evaluated to `undefined` — React silently drops it from a style object, shipping a flat 0-radius corner. This is exactly how every ribbon button in the Model module shipped square (B1087904, PR #1371: `Ribbon.jsx` asked `RADIUS.control` while importing `radius.js`'s scale, fixed by switching to `RADIUS.sm`). A fresh AST-style sweep of every file importing `RADIUS` from either module (see the item's own diagnosis) found no other live instance of the miss — this item is prevention, not cleanup.
- (a) Resolved the name collision by RENAMING `controls.jsx`'s export from `RADIUS` to `CONTROL_RADIUS` — `radius.js`'s `RADIUS` (the general-purpose scale, documented as the single source of truth) keeps its name; `controls.jsx`'s partial three-key scale, which predates it and is deliberately kept as a literal digit duplicate (not an import) for `test/notesModule.test.js`'s Notes-workspace mirror contract, gets the new name. Every importer updated in the same commit: `controls.jsx` itself (8 call sites), `src/workspaces/scheduler/components/AgendaView.jsx`, `src/workspaces/design-gallery/DesignGallery.jsx` (which now shows BOTH scales side by side in the `/design` gallery's token tables — it previously imported `radius.js`'s `RADIUS` under an alias to dodge the very collision this item removes). `test/notesModule.test.js`'s regex, which reads controls.jsx's literal digits, updated to match the new export name.
- (b) Added a dev-mode-only Proxy guard (`src/shared/ui/strictScale.js`, `strictScale(name, scale)`) that THROWS on an unknown key access — naming the bad key and listing the valid ones — instead of silently returning `undefined`. Wired onto the four scales the item named: `RADIUS` (radius.js), `SPACE`/`FONT_SIZE`/`CONTROL_H` (designTokens.js). Gated on `import.meta.env.DEV`, matching `controls.jsx`'s existing `warnLockedOverride` pattern — zero cost in production, and every valid key (including an inherited one like `toString`) still passes straight through. `controls.jsx`'s own `CONTROL_RADIUS`/`PAD`/`FONT`/`SIZE` are deliberately left unwrapped — wrapping would break the literal-digit-regex contract `test/notesModule.test.js` depends on, and the task named the four scales above specifically.
