### B1557013 — MasterView's double-click-to-edit silently lost focus to a stale refocus timer `[Scheduler]` (bug) #scheduler #ui  *(self-discovered while live-verifying B1557008's Owner cell in MasterView — a double-click opened the picker, but no keystroke reached it. Reproduced identically on the Name column, confirming it was never owner-specific. Minted **B1557013** from the same reserved block. DEDUPE-FIRST — searched Open/⏳Verify/Done for "cellFocusTimer", "MasterView focus", "double-click loses focus": no prior item; net-new — and per STANDING RULE #1, fixed rather than merely filed, since it directly blocked verifying the item this session was dispatched to ship.)*

`[x]` **FIXED THIS SESSION** — proven live (`document.activeElement` was the `<input>`, not the table wrapper, immediately after a real Playwright `dblclick`; typing then landed in the field and committed correctly) and pinned structurally in a new test, `test/masterViewFocusSteal.test.js`.

**MECHANISM, measured, not reasoned about.** `onCellClick` (MasterView) schedules `setTimeout(() => tableWrapRef.current.focus(), 0)` on every click, cancelling only the PREVIOUS such timer. A real double-click fires two `click` events before the `dblclick` that opens the editor — so the SECOND click's timer was still pending when the editor mounted and focused its own input, and that timer (a macrotask, strictly after the editor's mount effect) fired moments later and silently stole focus straight back to the table wrapper. Every column with a double-click editor (name, duration, health, % complete, and now owner) carried this, not just Owner — confirmed by reproducing it on the Name column before touching any code.

**FIX.** `openEdit(payload)` — `clearTimeout(cellFocusTimer.current); setLocalEdit(payload);` — replaces every `onDoubleClick={() => setLocalEdit(...)}` call site (5 of them). The keyboard-driven edit-open paths (`handleTableKey`'s Enter/F2 and type-to-edit branches) were left calling `setLocalEdit` directly — they open only from a SELECTED, non-clicking state, so no stray click timer is ever pending for them.

Files: `public/sequence/index.html`, `test/masterViewFocusSteal.test.js` (new).
