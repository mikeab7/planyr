`rowCarryPlugin` (`lib/notesTableRowStyle.js`) finds the rows/cells a transaction INSERTED from its own step maps, so every route is covered by one rule: **Row ↓** (copies the row it was added from), **Row ↑** (copies the row it was added FROM — the one below the new row; a new top row uses the row below it), **Tab out of the last cell** (the same `addRowAfter`), **Col ←/Col →** (each new cell takes its neighbour in the SAME row — the same small change, so it is done). **Formatting only: size, and the row's height (B2671186); no cell text is carried.** Skipped on undo/redo (one Ctrl+Z removes the row and its size together), on paste/drop (a pasted row brings its own words), and for any inserted row that is not entirely plain-empty. Typing into the new cell keeps the size (B2671184's adopt step). **There is no "add-row control at the table edge" in this app** (only the toolbar Row ↑/↓ and Tab); the rule is keyed on the document insertion, so any control added later is covered with no change.
