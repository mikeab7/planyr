The one real defect in this area, a MID-LOAD race where `counts` reads empty for a second before `site_elements` rows land, was already fixed as **B683568** via the `elementsReady` flag — a different, transient bug, correctly distinguished from this hypothesis by the task itself ("PR #1123 fixed a loading race, NOT this" — no PR #1123 exists in this repo's history; the matching fix is B683568).
