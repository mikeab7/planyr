### B152 — Offset-from-parcel-edge easement mode `[Site Planner]` (feature)  *(arrived as "NEW-3"; minted B152)*
`[x]` Third input mode: select one or more contiguous edges of an active parcel and enter a width → one-sided strip parallel to and inset from the boundary (the "10′ utility easement adjacent to the property line" pattern), with corner mitering where the run turns. Depends on B150; shares the offset engine. Designed so the same machinery is reusable for a future setback/building-line tool (no setbacks built now).
> ✅ **Done.** `buildParcelEdgeStrip` (easements.js) orders the chosen edges into one contiguous run (rejects non-contiguous / whole-boundary selections), auto-picks the **inward** side (offset toward the parcel interior), and miters turns via the shared `offsetPolyline`. Clickable edge hit-targets render over each active parcel in this mode; a floating **"Create easement ⏎"** bar (mirrors the merge-parcels bar) confirms. The stored easement keeps the edge-run as its editable centerline + `offsetSide`, so width edits and vertex drags re-derive correctly. Self-verified headless (the edge hit-target is the topmost element at the click; strip created).
