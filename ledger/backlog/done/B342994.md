### B342994 — Ctrl+zoom in Notes `[Notes]` (feature) #notes #ui  *(owner chat block, 2026-08-10)*
`[x]` Ctrl+wheel and Ctrl+= / Ctrl+- / Ctrl+0 scale the document.
- Verify: sandbox
- Origin: filed 2026-08-10 from chat (NEW-3).
- Scales the **document**, never the app chrome or the rail — the browser already scales everything together; what it cannot do is "make the writing bigger and leave my navigation where it is". The browser's own zoom is **suppressed** for these gestures (non-passive wheel listener + `preventDefault`), so the two cannot fight.
- CSS `zoom`, not a transform: the text must RE-WRAP at the new size and the caret must stay the browser's own — and it is what lets the anchored blocks of B342993 recover the live scale by measuring rather than by being told.
- Level persists **per scope** and deliberately does NOT sync (a comfortable size belongs to the screen you are sitting at). Ctrl+0 returns to 100%. The level is shown only when it is not 100%, and clicking it resets. **VIEWPORT-STABLE**: the scroll anchor is measured before the step and restored in a layout effect, before paint.
- Guards: repo-root `test/` suite **notesAnchorZoom** (23 rows: the ladder, the clamp, every key spelling, the wheel curve incl. line/page delta modes, and the scroll arithmetic) + `verify-notes-anchor-zoom` §7.
