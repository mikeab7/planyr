### B2566048 — The new (Univer) grid is unreadable in Planyr's dark theme: invisible tool icons, a white pill for the tab strip, headers the colour of their strip `[Spreadsheet]` (bug) #ui #testing  *(owner report 2026-10-30 ~10:55 AM Central, his own account, Grand Port, planyr.io build `eee96cc`, File ▾ → Try the new grid, dark theme. Follow-up to B2557488 — same module, NOT a recurrence of anything earlier; deduped against Open / Verify / Done.)*
`[x]` **✅ DONE — merged (PR #2733, build `9a37bf0`); V2014704 ✅ PASSED live 2026-10-30. Disposition (owner-reported symptom): REPRODUCED AND FIXED — reproduced on the sandbox host, root-caused by measurement, fixed, and re-measured on planyr.io in both themes; if the owner still sees it unreadable, re-open THIS item (×2).** Owner's words: the Univer toolbar strip rendered near-black with every tool icon invisible (only undo/redo and two colour swatches showed); the Start / Formulas / Data / View strip was a bright white rounded pill floating on the dark header; column letters and row numbers were nearly the colour of their strip; the formula bar and name box were empty black boxes with no visible border or text; grid cells and the bottom sheet tab read fine. Expected: Planyr's dark palette throughout, light theme still correct, the tab strip flat and full width (no pill, no rounded corners, no shadow).
- **Root cause (MEASURED, not inferred — the report's guess was "Univer's light theme applied while the app is dark"; it was close but the real mechanism is different).** B2557488's `buildUniverTheme` wrote Planyr's token values straight into Univer's gray scale — surface into `gray.0`, text into `gray.900` — which is right ONLY in the light theme. Univer's scale never flips direction (0 lightest … 900 darkest): its dark mode swaps to `dark:` classes that pick the OTHER end of the same scale (text = `gray.0`, background = `gray.800`, hover/selected = `gray.600/700`), and it paints its CANVAS (grid lines, header strips) through a colour inversion (`out_i = in_i − 0.667·(r+g+b) + 1`, core `invertColorByMatrix`). So in dark, `gray.0` was Planyr's DARK surface — every dark label and icon became dark-on-dark (measured: tool icons 1.02:1 against their strip, formula-bar text 1.17:1, column letters 1.10:1, name box 1.02:1), the canvas grid lines were white (13.5:1), and the strip was `gray.900` = Planyr's light text, i.e. the bright pill. A second defect: the theme was built ONCE at mount and a light/dark flip only called `toggleDarkMode`, so flipping dark→light while the grid was open left the sheet tab at 2.2:1.
- **The fix.** `lib/univerTheme.js` `buildUniverTheme(base, tokens, { dark })`: light = surface `gray.0`, hairline `gray.200`, text `gray.900` (unchanged); dark = text in `gray.0`, surface in `gray.800/900`, `gray.700/600` stepped from the surface toward the text, and the canvas-facing hairline (`gray.200`) and header tint (`gray.50`) written as the exact PRE-IMAGE of Univer's canvas inversion so what lands on screen is the token. `UniverSheet.jsx` rebuilds the theme from the LIVE tokens on every `data-theme` change and on an OS colour-scheme change (System mode), then toggles dark mode. `univerSheet.css` makes the tab strip one flat full-width band (radius 0, no shadow, surface background, a hairline underneath).
- **Which Univer UI parts were kept / hidden / restyled.** KEPT as Univer draws them: the toolbar (icons, dropdowns, tooltips), the formula bar and name box, the column / row headers, the grid, the bottom sheet-tab bar and zoom control. RESTYLED (colour only, from Planyr's tokens): all of the above through the theme; the Start / Formulas / Data / View strip flattened by CSS. HIDDEN: nothing.
- **Measured before → after (sandbox host, pixels, WCAG contrast of the furthest ink against the region's own background; both numbers are from `ui-audit/verify-univer-theme-contrast.mjs`, which FAILS on the pre-fix code — 19 failures — and passes after):** dark — tool icons 1.02:1 → 11.5:1 (worst of 13); column letters 1.10 → 8.8:1; row numbers 1.09 → 8.0:1; name box 1.02 → 13.6:1; formula bar 1.17 → 11.9:1; grid lines 13.5:1 (white) → 1.37:1 (quiet hairline); formula-bar hairline 13.5 → 1.45:1; typed cell text 1.20 → 16.3:1; tab strip surface `rgb(232,235,240)` (pill) → `rgb(29,32,39)` = the toolbar's. Light — the same checks passed before except the flat-strip one (5 rounded / shadowed parts → 0); after: icons 13.2:1, headers 13.8:1, grid lines 1.55:1. Both flips while open pass.
