### B2540739 — Library folder rail: one project's Google Drive sync status showed under another project `[Library]` (bug) #library #drive #sync  *(owner chat block NEW-5, found by reading code on main d0c93cd, 2026-10-29. Minted **B2540739** from this branch's reserved block. DEDUPE-FIRST — B701 (honest Drive-sync footer) built the status line; this is a project-switch race in it, not a duplicate. Net-new.)*
`[x]` **SHIPPED (Verify: sandbox → Done — reason below).** **ROOT CAUSE (AUDIT-FIRST):** `FolderTree` stays mounted across a project switch (`Library.jsx` renders it with no `key`). `scheduleSync` (debounced timer + `syncFoldersToDrive` with a progress callback) wrote the single `drive` status line from closures of the project it was started for, and the reset on a project change (`setDrive(idle)`) ran before A's still-running sync wrote over it — so B showed "Mirroring to Google Drive… 3 of 12", then "Synced · just now" or a red error, all about A. A pending (not yet fired) timer for A also fired after the switch. `reload()` could likewise land A's folder rows after the switch.
- **Fix:** `lib/driveSyncRun.js` `runDriveSync` — a run is tagged with its project id and its progress / verdict reach the screen only while `isShown(projectId)`; the confirmed-sync timestamp is still remembered for A (true of A whatever B shows); a throwing sync is a red status, never a stuck "Mirroring…". `FolderTree` keeps `shownProjectRef` (current every render), clears the pending timer on a project change, and `reload()` drops a result for a project no longer shown.
- **Tests:** `test/libraryDriveSyncSwitch.test.js` — a fake sync that reports progress / success / error / skipped after the switch (nothing reaches the screen, A's confirmation remembered), the shown-project path, the throw path, source guards.
- **Why sandbox only:** a live run would mirror folders into the real Google Drive from the test account (the exact orphan-folder hazard of B1162192/B1162193); the reports are driven by an injected fake sync instead.
- Files: `library/lib/driveSyncRun.js`, `library/components/FolderTree.jsx`, `test/libraryDriveSyncSwitch.test.js`.
