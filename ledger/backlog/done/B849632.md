Found by force-disabling `narrow` and rebuilding for the B849635 harness's mutation-proof (see that item), NOT by re-reading the JSX — the phone-only E2E harness never exercises the desktop code path, so this shipped invisible to every check that only runs at 390px. Fixed: `showList`/`showDetail` are two independent conditions, each computed once, both asserted by a live desktop-viewport check (268px rail, no Back control, no `data-narrow`) before this was called done.
- **TITLE CLIPPING + TAP TARGETS + SAFE AREA.** The title's own clipping was mostly a symptom of the squeezed 40%-width pane (fixed by the drill-in going full-width); the title font size also drops 27px → 21px on phone for more room.
