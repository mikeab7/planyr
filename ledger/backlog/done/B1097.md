- **Root cause (AUDIT-FIRST, confirmed in the code).** `normalizeBondedRotations` / `normalizeDogEarPositions` / `normalizeWallKids` run only inside `createSiteModel` — the site-record BLOB path. `rowsToModel`, the path that actually builds the model from `site_elements` on a signed-in plan, ran only `migrateRoads`. So a drifted or torn child was never repaired on load. Exactly the B1012 shape: one fix, two read paths, only one of them wired.
- **Fix.** One shared `normalizeBondedChildren(els, onHeal)` in `siteModel.js`, called by BOTH `createSiteModel` and `rowsToModel` — so the two paths can never disagree again. It runs the three existing normalizers plus a new one.
- **New pass — `normalizeStrandedZones`.** The three existing normalizers re-derive a child that has DRIFTED; none can see a child that is simply somewhere else. This one detects an offset that is **impossible for the child's kind** and re-fits it. Impossible is MEASURED, never guessed: a dock-stack member sits flush outward from its host's wall, so its centre can never exceed `host half-diagonal + the whole chain's depth + its own half-diagonal + slack`; a wall kid can never exceed `host half-diagonal + its own half-diagonal + slack` (`strandedFromHost`, exported and unit-tested). Only members PAST the reach are re-fitted, through the same pure `layoutZoneByKind` the canvas lays the stack out with, using each member's own stored depth (translation-invariant, so a resized court keeps its depth) and the chain head's along-wall span when the head is still where it belongs. Everything inside the reach is returned **by identity** — the idempotency contract B499 asked for, and why this is safe to run on every load and every refetch. A side-parking row's along-wall slide is user intent and is still never normalised (the B1039 owner rule) — **unless** the row is stranded, in which case that number is wreckage and the re-fit re-centres it.
- **LOUD-FAILURE.** `onHeal` reports every re-fit; `refetchReplace` forwards it to `reportClientEvent("bonded-children-healed", …)` with the count and the first 20 records. A silent repair is a repair nobody can audit.
