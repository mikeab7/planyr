### B158 — Replace inline ✕ delete button with right-click context menu on site list rows `[Site Planner / UI]` (feature)  *(arrived as "NEW-1"; minted B158)*
`[x]` **DONE + verified. lint 0 errors · 1613 tests · build green · NEW headless `ui-audit/verify-b158-site-row-context-menu.mjs` 9/9 (real Chromium, logged-out).** Most of the target state had **already shipped under B168** — the inline single-click ✕ on a site row was removed (only the non-destructive ⊕ locate icon remains on hover) and the right-click menu (`statusMenu` in `MapFinder.jsx`, opened from a card row OR a map marker) already carries both **Rename…** (→ inline-edit rename flow) and **Delete project…** (→ the existing confirmation modal), positioned at the cursor and clamped to the viewport, dismissing on click-outside.
