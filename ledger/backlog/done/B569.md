- **`arcChordPoints(p0, p1, meta)`** (new export in `lib/metesAndBounds.js`): from the curve's stated radius / central angle / turn (already parsed into `curveMeta`), rebuilds the circle and walks the minor arc from start to chord-end, tessellating ~1 point per 4° (8–48 pts). Derives R from chord+Δ when radius is absent; falls back to the straight chord when there's no usable radius/angle or the geometry is degenerate (chord > 2R). Frame-correct: +x east, +y south; `turn:"R"` puts the centre on the traveller's right.
- **`callsToPath` emits the arc points** for a curve course (ending exactly at the chord endpoint, so the next course continues unchanged) — so `buildEncumbranceMarkup`, the easement strip, the modal preview, and the plotted polygon ALL follow the true curve. Closure/misclosure are unaffected (endpoints unchanged). Fixed a latent bug: the save-and-except tie POB was read by `callsToPath(tie)[tie.length]`, which breaks once a call emits many points — now takes the last path point.
- **Honest UI:** the modal warning changed from "plotted as straight chords" to "reconstructed as true arcs" (and flags any curve with no stated radius/angle that still falls back to a chord); the call list marks each curve "⤾ (arc)" vs "⤿ (chord)".
