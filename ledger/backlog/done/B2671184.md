`[x]` **✅ Done — V2115856 PASSED live 2026-11-05 on build 44486b2 (the merge commit of #2867), signed in as the test account (`ui-audit/verify-notes-table-size-live.mjs`, 18/18).**

**Reproduced first, then the adjacent cases recorded** (`ui-audit/verify-notes-table-size.mjs`, real mouse, rendered size + stored doc, then a reload; **43 passed / 55 FAILED on unmodified main**, every failure a reported behaviour). **Cause, measured:** a size lives on RUNS OF TEXT (`textStyle.fontSize`); an empty cell has no run, so a row selection sized the filled cells and skipped every empty one — and a row of only empty cells took nothing at all ("nothing happens"). On top of that, even a block-level size is DERIVED from the runs (`deriveBlockSizes`), so the first character typed into a sized empty cell reset it.
- **Fix** (`lib/notesTableRowStyle.js`, wired in `lib/notesExtensions.js` + `NoteToolbar.jsx`): `sizeEmptyBlocks` gives every EMPTY paragraph in the selection's ranges the size on the BLOCK (works for any selection — drag, shift-click, rows, a column, the whole table, one cell, Ctrl+click sets); `adoptEmptyBlockSize` runs BEFORE the derivation and writes the size onto text typed into a block that was empty before the transaction (keyed on "was empty", so a size cleared on purpose is never resurrected). The toolbar runs `sizeEmptyBlocks` before the mark command (a document change clears stored marks).
- **The class, same fix:** bold / italic / underline / strike / text colour / highlight / font on a row selection had the same hole (a filled cell took it, an empty one did not). A short `seed` list on the empty block (`seedMark`, run after the ordinary mark command) hands those marks to the first text typed there. A caret keeps ordinary stored marks.
- **Matrix, all green after:** drag row · shift-click row · a whole EMPTY row · row with an empty cell at the end · several rows · a whole column · the whole table (Select table) · one empty cell · sizes 8/9/10/14/18/24 · part of the text in one cell (only that part) · typing into a cell that started empty (row selection AND caret) · bold and colour on a row (filled + empty) · reload after each.
