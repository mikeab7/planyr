### B266086 — The drift gate's own parser was written against an invented fixture and matched NOTHING `[Infra / CI]` (bug) #infra #testing  *(minted from this branch's reserved block B266080–B266095, next free after B266085. DEDUPE-FIRST — searched Open / ⏳ Verify / Done for `collectCases`, `e2e-drift-gate`, `known-red`, `rootDir`, `reporter`: **B266080** shipped the gate hours earlier and is Done; this is a defect IN it, found by running the check its own `V63088` said was owed. Net-new.)*
`[ ]` **✅ Done 2026-08-08 — found, fixed and re-proven in the same session that shipped the defect.**
- Verify: sandbox
- **HOW IT WAS FOUND — by running the check the V-item named, instead of parking it.** `V63088(b)` flagged one specific quiet failure mode: *"if the JSON reporter's `file` field is absolute rather than repo-relative, every row reports as `absent`… that is the one failure mode here that is quiet, so it is the first thing to check."* Driving a real `--reporter=json` run locally showed **it was real, and there were TWO of them, not one.**
- **THE TWO SHAPE FACTS THE PARSER HAD WRONG.** (1) `spec.file` is relative to `config.rootDir` — the testDir — so it reads `pond-outlet-clear.spec.js`, while every id in this repo is repo-relative. (2) The **top-level suite of each file IS the file** (`title === file`), so including it in the title chain printed the filename twice: `pond-outlet-clear.spec.js:63 › pond-outlet-clear.spec.js › Pond outlet fields …`.
- **THE CONSEQUENCE, measured rather than guessed.** **Zero of the 61 seeded ledger rows would have matched.** The first real run would have reported all 61 as "did not run" and all 33 failures as brand-new regressions. It fails **loud rather than false-green** — the `novel` path is fatal, the `absent` path is not — which is the one mercy, and it is exactly why the gate is built to fail on a shape it does not recognise. It would still have been useless noise.
- **THE ROOT CAUSE IS THE FIXTURE, AND THAT IS THE LESSON WORTH KEEPING.** `collectCases()` was written against a **hand-written** report helper in its own test file, and 16 tests passed against it. **A fixture you invented can only ever confirm what you already believed.** This is the same shape as the three harnesses this repo has already caught being silently blind — the undisposed `ElementHandle`, the seeder that made B749's cost path unreachable, the growth harness whose plan B was plan A truncated. *When the instrument and reality disagree, the instrument is the thing on trial.*
- **THE FIX + THE GUARD.** `collectCases(report, { root })` re-prefixes `spec.file` from `config.rootDir` and skips any suite that names its own file. `test/fixtures/playwright-report.sample.json` is **captured from a real `npx playwright test --reporter=json` run** (only the bulky per-result payloads dropped) and five new tests pin both facts — including the end-to-end one that would have caught this: the instrument's own output is matched against the committed ledger with nothing hand-written in between.
- **RE-PROVEN, all three mutations, on the corrected parser and in the real reporter shape:** true failure set → **exit 0, `29 ran · 29 failed · 29 on the ledger`** (before the fix that last number was **0**) · one fabricated new failure → **exit 1**, named · one ledgered case flipped to passing → **exit 1**, named.
