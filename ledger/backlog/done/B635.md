`[x]` **Filed AND fixed + headless-verified + shipped the SAME session per STANDING RULE #1 (branch `claude/gantt-dep-arrow-anchors-0pwz6f`).** At low (~33%) zoom on the Pappadoupolos Gantt, labels overprinted bars — a milestone name crowding an adjacent bar, a leaf name running into the row below, and a **summary caption sitting on its own bracket** ("Utilities"). Root cause: labels were placed per-row with no band confinement, so at compressed horizontal zoom (narrow bars → more labels flip to "above"/beside) a label's box bled ~2px into the neighbouring row; and the summary caption's fixed font was taller than the headroom above its bracket once the row compressed.
- **Own-row band confinement (the structural fix).** `placeGanttLabel` gained an optional `rowH` → `confineY()` clamps every label's vertical box into its OWN row band `[rowTop, rowTop+rowH]`. Because rows are disjoint vertical bands, a confined label **cannot geometrically overlap another row's bar or label** — the whole class of cross-row collisions is designed out rather than resolved case-by-case. A pure no-op when `rowH` isn't passed, so nothing else changes. Both render paths pass it.
- **Summary caption auto-fit.** New `fitCaptionFs(baseFs, headroom)` shrinks a summary caption's font to the room above its bracket (floored at 6.5px for legibility), so "Utilities"/"Wastewater"/"Water" always clear their own span even at the minimum row height. Applied on-screen and in the print `buildGanttSVG`.
- **Testability.** Bar/bracket/diamond glyphs now carry `data-gantt-bar` (+ `data-gantt-kind="summary"`) so overlaps can be measured against real DOM boxes.
- **Mirrored in the print path** (`buildGanttSVG`) — same `rowH` confinement + caption fit; its existing B402 label de-collision stays as a defensive second layer.
