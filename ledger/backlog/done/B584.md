- **HIGH — correctness / data-loss / crash / freeze:**
  - **#1 `parseFlexDate` ISO fast-path accepted impossible dates** (`2026-02-30`, `2026-13-01`) → persisted a date the app silently rolled (→ Mar 2) or NaN'd, disagreeing with every displayed/cascaded value; slash-form already rejected them. Now the ISO path round-trips the same calendar check. (engine + mirror + runtime test)
  - **#2 stale tab could overwrite newer cloud data** — the concurrency guard bailed when `knownRev[k]` was undefined (the seed / offline-fallback load path never sets it), so a seed-derived board could clobber the real cloud row. Now treats an unknown base rev as 0 (matches `checkRemote`).
  - **#5 redo restored the WRONG snapshot** — the keydown effect omits `data` from its deps, so undo/redo pushed a STALE closure `data` onto the history/future stacks, losing the redone edit. Now pushes the live `dataRef.current`.
  - **#6 cut+paste a task silently severed every OTHER task's dependency on it** — the moved subtree got new ids but external successors kept pointing at the old id, which `renumberTasks` then dropped. Now rewires remaining tasks' predecessors onto the new ids.
  - **#7 editing a name/predecessors/notes cell under a row/range selection silently discarded the edit** — `commit()`'s fill loop skipped those columns and returned without ever committing the focused cell. Now commits the focused cell for non-fillable columns.
  - **#9 one far-future date froze the on-screen Gantt** — the month/year axis loops + container width were unbounded (a year-4000 typo → ~24k month divs / 16M-px width). Now the span is capped at ~100 years (the SVG export already bounded its loop).
  - **#12 PDF export crashed to a blank page when a selected project had zero visible rows** — empty Gantt → null `svgEl` → `cloneNode` threw before the staged DOM was restored. Now the split-Gantt slices are guarded on a non-null `svgEl`.
  - **#17 the owner ContactPicker committed the prefix "ghost" over an exact match** — typing "Sam" with "Samuel Jones" on file assigned Samuel. Enter now only ghost-accepts when the typed text isn't already an exact contact.
  - **#20 the nav-request handshake reply stripped `linkedSiteId`** — a late reply could desync the shell into falsely showing "no schedule linked" over a linked project (and minting a duplicate on Create). The reply now carries the link fields like the primary emit.
- **MEDIUM — correctness / data:**
  - **#4 a phone/narrow-window session overwrote the saved desktop view** — the mobile `d.view="grid"` override was baked into persisted data and autosaved cross-device. Now the grid layout is gated at RENDER time only; the saved `view` is never mutated.
  - **#13 Tabloid PDF printed on the wrong paper** — `@page{size:11in 17in landscape}` is invalid CSS (lengths + keyword) and never swapped for landscape. Now `@page` uses the explicit, orientation-swapped `pgW/pgR` dims for every size.
  - **#16 approving a suggestion with a blank note appended an empty note row** — inflated the task's notes badge/count. Now guarded like `createTask` (note only when typed).
  - **#18 the grid applied conditional-format rules to EXPANDED parents using stale data** — so expanding a summary could flip its color, disagreeing with the Gantt/dashboard. Parents now always use rolled child health (collapsed or expanded), like `GanttView`/`MasterView`.
- **LOW — rendering / polish:**
  - **#3** persisted grid zoom was ignored on load (always reset to 100%) — now adopted from data after the async load.
  - **#8** `autoSizeCol` measured an empty Start/Finish as the literal `"NaN/NaN/"`, inflating the auto-fit width — now measures nothing.
  - **#10** dependency arrows to a duration-0 SUMMARY anchored to a phantom diamond center instead of the bracket — both y-helpers now test the summary case before the milestone case (matches the bar renderer).
  - **#11** on-screen dependency connectors lacked the export's `isNaN` guard, emitting phantom NaN-coordinate arrows for an unparseable date — now mirrored.
  - **#14** a fully-filtered MasterView showed a blank table with no message (the empty-state row was unreachable) — now keyed on the displayed-row count.
  - **#15** grouped-by-project arrow-key nav landed the selection on the hidden Project column (outline vanished) — selection is now keyed to the rendered `displayCols`.
  - **#19** floating (nth-weekday) holidays were computed one calendar day early in any timezone east of UTC (`fd()`'s UTC slice of a local-midnight date) — now serialized with `fdLocal` like every other "today" comparison. (engine + mirror + anti-drift)
