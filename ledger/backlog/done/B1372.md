- Verify: sandbox

- **What shipped:** the table button opens a small grid. Sweeping the pointer across it previews the size, the running count is written out underneath ("5 × 4 table") so nobody counts squares, and releasing inserts. Reaching the grid's edge GROWS it, up to a cap — so a large table is reachable by dragging further, with **no dialog box** (the house rule, not a preference).
- **It is keyboard-reachable:** arrows resize the preview, Enter inserts, Escape closes. A gesture-only control is one a keyboard user simply cannot use.
- Guard: `verify-notes.mjs` §5 was rewritten around it — it sweeps the grid, asserts the running size follows the pointer, asserts the grid grows at its edge, picks a size, and then asserts the **stored document** holds a table of exactly that size rather than a 3×3.
