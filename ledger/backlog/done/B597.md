- **How (host, `public/sequence/index.html`):** `computeFormulaValues` + `previewFormula` now store an errored cell as `PF.errVal(res.error)` (was `PF.BLANK`) in the shared row map, so a downstream column that aggregates it propagates. - **Scoped boundaries (deliberate, documented + tested):** (1) `XLOOKUP`/`INDEX` propagate the SPECIFIC matched/indexed error cell (and `XLOOKUP` an error scanned *before* a match) — but `MATCH`'s family-filtered compare-safe scan SKIPS an error cell (use `XLOOKUP` if you need lookup-array error propagation); (2) `SUMIF`/`AVERAGEIF` propagate an error in a *matching* sum cell but not in a *non-matching* row's sum cell (only consumed cells raise); (3) a normal BLANK cell is still skipped — only a real error value propagates.
