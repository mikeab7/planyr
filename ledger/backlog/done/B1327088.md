  1. **Removed the volatile stamp.** `scripts/build-map.mjs` no longer writes a `Generated <date> @ <hash>` line into `MAP.md`'s header — that line changed on every regen even with zero real content change (a PR was once observed whose entire diff was "Refresh MAP.md's generated-at stamp"). `--check` never compared the header anyway (only the file/export inventory), so this changes nothing it enforces. `BACKLOG_OPEN.md`'s generator was already deterministic (no stamp); the "best-effort match counter" the dispatch also named turned out to already be fixed in a prior PR (#1458) — `ui-audit/ui-inventory.mjs` already reports "(+more matches elsewhere, best-effort)" with no number.
  2. **A branch may no longer touch any of the three files, enforced by a new required gate.** `scripts/generated-doc-touch-guard.mjs` fails a PR outright — before `npm ci`, in well under a second — if its diff (against the merge base with `origin/main`, the same technique `scripts/check-mint.mjs` already relies on) includes `MAP.md`, `BACKLOG_OPEN.md`, or `docs/UI-INVENTORY.md`. Exempts a push to `main` itself and the scheduled regen job's own branch (only when that branch's diff touches nothing else).
