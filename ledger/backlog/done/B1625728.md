**ROOT CAUSE (AUDIT-FIRST).** "Split rows/aisles" (`splitParkingRows`) replaces one `parking` field element with a STACK of independent pieces — stall row | drive aisle | stall row — each its own element (`lib/parking.js` `explodeParkingBands`). The wall-edge "+" ladder's append function, `addSideParkPieceBeyond`, appends a new piece beyond the OUTERMOST piece of that stack, and its original comment said the aisle "already exists" — true only when the outermost piece genuinely IS an aisle, which `explodeParkingBands` produces only for an ODD row count (a reserved, not-yet-paired aisle). The far more common case — an EVEN row count, e.g. the default 2-row field, or any field grown to a second row before splitting — explodes to a stack that ends on a ROW, with nothing beyond it. `addSideParkPieceBeyond` appended a bare stall row there unconditionally, every time, which is exactly "only adding parking but no aisles." The same root cause reached `growParking` (the per-field canvas "+"/"−" nodes and the Properties panel's "＋ Row"/"－ Row" buttons): resizing ONE piece of a bonded stack in place doesn't move its siblings, so it would silently overlap them instead of extending the field — checked and confirmed via `relayoutWallKids`'s call sites (`growParking` was never among them).

**THE FIX, `SitePlanner.jsx`, two call sites:**
- `addSideParkPieceBeyond` now checks the outermost piece's `type`: if it's already `"paving"` (the odd/reserved-aisle case), append just a row exactly as before; if it's `"parking"` (the common case), append an aisle THEN a row — two new elements in one `addBuildingEls` call, so Ctrl+Z undoes both as one step.
- `growParking` now checks whether the element it's asked to grow/shrink is a wall-bonded piece with siblings (`el.attachedTo && el.sideParkSide`, `sideParkPadsOn(...).length > 1`); if so it delegates to `growEmployeeSide` (the same outermost-append/outermost-remove ladder) instead of resizing that one piece in place — so every entry point onto a split stack behaves one way, regardless of which piece happens to be selected.
