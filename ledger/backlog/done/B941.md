`[x]` **SHIPPED + verified this session (build green · 4795 unit tests · real logged-out canvas e2e).** When a measurement (or a markup line/polyline) STARTS on a parcel boundary — the first click snaps onto the property line — holding **Shift** now locks the drawn direction to the nearest 45° **relative to that edge**: parallel (along the line), perpendicular (the setback case), or the 45° diagonals. Bluebeam's Shift snaps to page-absolute 90°/45°; this snaps in the edge's frame so "perpendicular to the property line" is one press. Off a boundary, Shift falls back to the page-absolute 45° lock (which the measure tool also gains, matching the line tools).
