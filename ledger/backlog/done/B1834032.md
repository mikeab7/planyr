`[x]` **AUDIT-FIRST — what the code actually did before.** `↗ Arrow` already existed but was DISABLED unless a box was already selected, and pressing it only armed a `pendingFrom` for the next box press — no source highlight, no line following the pointer, no crosshair, and Escape only reached the canvas's own keydown (so it did nothing unless a box had focus). So the click route technically existed as a keyboard fallback, but was unreachable from a clean state and gave no feedback.
`[x]` **Implemented** in `lib/notesSketchEditor.js` — `pendingFrom` replaced by one `connecting` state (`null` · `{from:null}` waiting for the source · `{from:id}` waiting for the target) and ONE state machine, `pickForConnect`. `↗ Arrow` is enabled whenever the sketch holds ≥2 boxes (no selection needed) and toggles the mode; a box that is already selected is taken as the source (the old select-then-Arrow route still works, one click fewer). While the mode is on, a press on a box or its dot is a PICK — no drag, no pointer capture, no box creation, no editor — and outranks every other reading of the press (including the B1683296 relocate branch and the NEW-1 idle double-tap detector, which is reset). Picking the same box twice says so and stays in the mode; `onDoubleClick` is suppressed during and just after a pick so a real double-click on a box never opens its editor mid-connect. A press on bare canvas, Escape (listened for on `window` only while the mode is on, since a pick takes no focus), or ↗ Arrow again cancels, out loud. The arrow itself goes through the existing `connect` → `addLink`, so duplicates/self-links are still refused with a stated reason (LOUD-FAILURE) and it is one undo step. The source box is dropped from the mode if another window/undo deletes it (`refresh`).
`[x]` **Visual feedback** (`NoteEditor.jsx` sketch CSS, tokens only): crosshair over the canvas, pointer over boxes, hover outline on candidate targets, the source box drawn with a dashed accent outline (`is-link-source`), and a dashed accent line (`data-testid="sketch-connect-line"`, the existing `planyr-sketch-pending` class) from the source's centre that follows the pointer, painted behind the boxes. Re-applied after every redraw (`markConnect`), since a redraw replaces the SVG. Screen-only chrome — no content, nothing reaches `renderHTML`/print (PDF-PARITY unaffected). Hint line REPLACES its drag instruction with the click one (PANEL-BREVITY: same one line, no sentence added).
`[x]` **Keyboard:** with the mode on, focus a box + Enter (or Space) picks it — twice makes the arrow.
