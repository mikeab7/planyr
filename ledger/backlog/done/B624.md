`[x]` **Shipped this session.** The grid Start/Finish cells accepted any parsed date, so a task could sit on a Saturday/Sunday — wrong for a working-day schedule. A working-day entry is unchanged (no toast). Composes with the locks: a rolled Finish still pins as the B622 hard-finish (on a working day); a rolled Start still pins (B615/pinnedStart). The finish-before-start guard runs on the rolled date. The Gantt has no date-editing drag path (bars render from start/end; only columns drag), so the typed cell is the only date input — fully covered.
