Fixed by adding "are"/"were" to the accepted connector set, and by having the same pattern consume a trailing "/SF"/"psf" unit marker (mirroring the existing value-then-label pattern's own optional suffix group) so the unit doesn't leak into Notes as orphaned text either. (2) **`ESCAL_WORD`**'s "annual" alternative had no `(?:ly)?` — so "annually" only ever matched its first six letters, leaving a stray "ly" behind for the leftover-text collector to append as its own orphaned fragment ("increasing 3% annually" → blank "3% annual" → leftover "increasing" + "ly" → whitespace-collapsed into the reported "increasing ly"). Fixed with `annual(?:ly)?`, so the whole word is consumed or none of it is.
