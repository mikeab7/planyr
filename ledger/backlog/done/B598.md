`[x]` **DONE + headless-verified the SAME session per STANDING RULE #1. lint 0 errors · 2109 unit tests green · build green · lazy split intact · `ui-audit/verify-b598-parcel-tool.mjs` 11/11 (real Chromium, logged-out) + existing `verify-merge-banner.mjs` 6/6 (merge flow intact).** The Parcel ("add parcels") tool had two usability gaps the owner hit: (1) once in it, every canvas click drops a boundary point, so there was no obvious way OUT — the only exits were Esc (undiscoverable) or clicking another tool, and finishing one lot silently auto-switched to Select; (2) no way to delete a parcel from the tool at all (removal was buried at the bottom of a selected parcel's props panel).
- **Exit (fix 1):** the Parcel tool now shows a persistent on-canvas **banner** (mirrors the existing merge/easement banner pattern + z-index/stopPropagation guard) with an explicit **Done** button → back to Select. The tool also **stays active after a lot is closed** (removed `closePoly`'s `setTool("select")`), so several adjacent lots draw in a row (a developer assembling a site from multiple parcels) — and "how do I get out?" now has one obvious answer: Done (Esc still works too). Adaptive hint shows point count + how to close; a **Finish ⏎** + **Undo point** appear once a draft has points.
- **Remove (fix 2):** the banner has a **Draw / Remove** mode switch. In **Remove** mode, clicking a parcel (interior OR boundary — both bubble to the canvas handler since `startMoveParcel` early-returns without `stopPropagation` outside Select) deletes it; the lot under the cursor is **highlighted in the danger hue** so it's clear what a click will remove (topmost-wins hit-test via `pointInRing`). Stays in Remove mode to delete several. Also added a per-row **✕** to each parcel in the Parcels panel — the most discoverable spot — sharing the same delete path.
- **Shared delete (`removeParcelById`)** mirrors `deleteSel`'s parcel branch exactly: `pushHistory` (undo-able) + filter out + **tombstone** (so a removal sticks across reload / cross-tab / cross-device merge and never trips the thin-clobber guard — B556/B596), and drops the id from the current selection / merge pick. `parcelMode` resets to "add" on every `selectTool`/Esc so the tool never re-opens in a stale Remove.
