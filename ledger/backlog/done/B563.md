### B563 — Version restore was a partial restore: it never re-applied `parcelDrawings` `[Site Planner / version history]` (bug — restore correctness)  *(self-found 2026-06-29 by the improve loop's lap-4 hunt; minted **B563** = highest real B# across both files (B562) + 1)*
`[x]` **DONE + verified the same session. lint 0 · tests green · build green.** `restoreVersion` explicitly re-applied 8 collections (parcels, els, measures, callouts, markups, underlay, sheetOverlays, deletedIds) but **silently skipped `parcelDrawings`** — the per-parcel attached drawings (PDF/image markups).
- **Why it bites:** `parcelDrawings` rides its OWN persistence path (`persistDrawings` → a `saveSite` merge), deliberately kept off the main autosave snapshot. The stored version DOES capture it (`sigOf` + `snapshotVersion` save the full `createSiteModel`), so a restore should bring it back — but the restore only touched the main-path setters. Result: after restoring an older version, every other collection reverted while `parcelDrawings` stayed at the CURRENT value — a **mixed-version canvas**. Worse, the very next line `noteLocalContent(siteId, v)` recorded the restored version `v`'s drawings as the conflict baseline, so **live state ≠ recorded baseline**, which could mis-fire the cross-session "newer version elsewhere" guard on the next push.
- **Distinct from undo/redo:** the undo/redo snapshot intentionally excludes `parcelDrawings` (geometry-only undo). A full version RESTORE is a different operation — the user expects the entire saved state back.
- **Fix:** restore + durably persist the version's drawings via `persistDrawings(v.parcelDrawings || [])` (sets state AND saves AND debounces the cloud push — a bare `setParcelDrawings` would update the display but not persist, reverting on reload). Anti-drift guard in `test/bugHuntGuards.test.js` (B563).
- **Files:** `src/workspaces/site-planner/SitePlanner.jsx`, `test/bugHuntGuards.test.js`. The live signed-in confirmation (attach a drawing → save a version → change drawings → Restore the earlier version → the old drawing set returns and survives reload; cloud version history is unreachable headless) is **VERIFICATION.md V173**.
