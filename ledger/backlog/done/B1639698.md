**Which extraction path was used, as asked: `/identify` over recursively-subdivided ENVELOPE tiles — not a bulk export.** No bulk-export operation exists on this MapServer (`capabilities: "Query,Map"` only — no `Data`/`Extract`/`createReplica`); `/identify` does, however, accept an envelope (a rectangle), not just a single click point, and the operation honors it as a real spatial filter — which is what turns it into a substitute for the disabled `/query`. `identifyTileCounty` (new, in `scripts/build-parcel-snapshot.mjs`) starts from the county's own bounding box (via the existing `fetchCountyPolygon`/TxDOT boundary source) and recursively quarters a tile whenever ITS OWN response reaches the layer's declared `maxRecordCount` (read live from the layer's `?f=json` metadata — 2000 on this service, confirmed) — so completeness is judged per-request, never from a total feature count for the county, which `returnCountOnly` cannot supply (confirmed still disabled, same as `/query`) and which the fix therefore never asks for, per the dispatch's own instruction. A tile at the ceiling is discarded whole (its contents may be an arbitrary subset) and only its four children are trusted. Results are deduped across adjacent tiles by `PROP_ID` (falling back to `OBJECTID`) and filtered to the target county via the identify response's own `COUNTY` attribute (a corner tile can genuinely reach a neighboring county). Field names are read case-insensitively both ways (`attrValue`) — the layer's metadata lists them lowercase, `/identify` capitalizes them — exactly the trap the dispatch named. `esriRingsToGeoJsonGeometry` (new, in the pure `src/shared/gis/parcelSnapshotBuild.js`) converts `/identify`'s Esri-JSON rings into the same GeoJSON `buildSnapshotFC` already consumes from `/query`'s `f=geojson` output (outer/hole nesting by shoelace-area sign + point-in-ring containment, re-wound to GeoJSON's convention), so the two extraction paths feed one unchanged downstream pipeline. `SOURCES.chambers`/`SOURCES.waller` now try a plain `/query` first (self-heals for free if TxGIO's is ever re-enabled — one fast-failing request costs nothing in a nightly job) then `identify-tile`; the dead `AGO_STRATMAP` mirror and its URL are gone from the file entirely.
