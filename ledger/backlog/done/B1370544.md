`[x]` **FIXED THIS SESSION — the whole body drags, and the grip stays a real target on top of that.**
- **THE SAME GESTURE IS NOW WIRED TO TWO SURFACES, WHICH IS NOT REDUNDANCY.** The BODY drags only while the caret is elsewhere, because once you are typing in a box a press-and-travel inside it is somebody selecting a phrase — his own rule, verbatim: *"text selection taking over only once the note has focus."* The GRIP drags unconditionally, because a box you have just typed into still has to be movable without pressing Escape first. Dropping the grip to decoration was tried first and immediately produced that trap.
- **WHAT DECIDES BETWEEN THEM IS THE CARET, READ LIVE OFF THE EDITOR'S OWN STATE** (`anchorPosAtSelection`), not the selection ring and not a React attribute — which makes it immune to whether React has repainted `data-selected`/`data-editing` yet, a race a DOM attribute would lose on the first move of a gesture.
- **THE BODY'S PRESS IS PASSED THROUGH, NOT SWALLOWED.** It is already spoken for by the two-stage select/enter model, so the drag is deferred to a 4px movement threshold instead of `preventDefault`ing the press — otherwise dragging a box would have cost the ability to select one.
- **⛔ AND ONE MEASURED DETAIL THAT IS THE DIFFERENCE BETWEEN THIS WORKING AND DOING NOTHING: the pointer is captured at the PRESS, not at the threshold.** Without it, a drag that left the box's own 180px frame stopped receiving `pointermove` on that element, the gesture never reached its threshold, and the box never moved — indistinguishable from the defect being fixed, and it read exactly like it in the harness on the first attempt.
- **THE GRIP: 12×20px, visible on HOVER as well as on selection**, with `cursor: grab` over the whole box and `cursor: text` on the one box the caret is in. It sits inside the box's own 16px left padding, so it covers no text.
- Verify: sandbox — driven with a REAL mouse in headless Chromium and read back out of storage (`ui-audit/verify-notes-free-placement.mjs` §7): a body drag of (150, 90) on a box at (200, 200) stores (350, 290); cursor `grab`; grip 12×20 with `pointer-events` live and `cursor: grab`; opacity 0 at rest, 1 on hover. Source-shape guard in `test/notesModule.test.js` pins both wirings so neither can be quietly dropped.
