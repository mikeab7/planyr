- **MEASURED:** Notes and the Site Planner now render the badge at the **identical position** (top 10, right 23 in a 1500-wide window), with identical wording.
- **THE OTHER MODULES, since he asked.** Site Planner, Scheduler and Doc Review already fed the shared badge and were correct. **Library feeds nothing, and that is right** — it is a file browser with no document of its own to save, so a save indicator there would be claiming a fact that does not exist.
