### B355 — Default new-site-plan name to lettered concepts (Concept A, B, … AA) `[Site Planner]` (feature)  *(arrived as coworker-chat "NEW-1" + "NEW-2" 2026-06-21 — two near-identical drops of the same request; deduped into ONE item, minted **B355** = next free after B354; implemented + verified same session)*
`[x]` **Fixed + verified (2026-06-21), on branch `claude/hopeful-galileo-0xbh0q`.** New site plans now default to **Concept A, Concept B, …** instead of "Plan 1, Plan 2". **Dedup note:** NEW-1 and NEW-2 are the same feature; NEW-1's "scope: per-site, resets per site" and NEW-2's "within project scope" resolve to the **same thing in this codebase** — a "project" *is* a Site Planner site group, and a plan's letter sequence runs within that group (exactly where the old `Plan N` numbering lived). No conflict, so they fold into one. **Design (all points honored):** (a) **per-site** — every site's first concept is "Concept A"; the sequence resets per site group; (b) **continues past the highest existing letter, never reuses a gap** — if "Concept B" exists but "A" was deleted, the next is "Concept C" (so a name a teammate remembers is never silently re-pointed); (c) **past-Z is spreadsheet-style** — Concept Z → AA → AB → … (bijective base-26, never crashes at the 27th); (d) **stays user-editable** — this only sets the default; (e) **no retroactive rename** — existing "Plan N" names are left untouched (they don't parse as concepts, so a site that already has "Plan 1" simply gets "Concept A" as its *next* new plan; the legacy-group migration in `storage.js` still writes "Plan 1" for old un-grouped records). **Implementation:** pure, unit-tested `src/workspaces/site-planner/lib/conceptName.js` (`numberToConcept`/`conceptLettersToNumber`/`parseConceptIndex`/`nextConceptName`), wired into the three creation paths in `SitePlannerApp.jsx` (`newSiteFromMap` → "Concept A"; `newPlanSameParcel` → `nextConceptForGroup`) + the blank-site first-save default in `SitePlanner.jsx` + the `createSiteModel` fallback in `siteModel.js`. **Verified:** new `test/conceptName.test.js` 14/14 (A–Z, AA/AB roll-over, round-trip, gap-not-reused, legacy "Plan N" ignored); full suite 1055/1055; lint 0; build green.
