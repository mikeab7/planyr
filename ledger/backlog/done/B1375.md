- **The defect, in one line:** `splitParkingRows` built each piece with only `cfg` and `attachedTo` copied off the source field, so a 60 ft double-loaded module became `parking 18 / paving 24 / parking 18` with **`sideParkSide` and every other `HOST_ROLE_TAG` dropped**. The pieces stayed bonded to the building and kept rendering; they simply stopped meaning anything.
- **What that cost:** every lookup and every heal keyed on the role tag went blind — `empSidePark`, `sideParkingOn`, `empSideAddTitle`, `normalizeWallKids` / `hostOf` (which admit a child only when it is a wall-strip type **or** carries `sideParkSide`), and the side-parking heal in `normalizeHostRuns`. The untagged pieces therefore never re-flushed when their host moved or resized — a live suspect for the recurring *"the parking is entirely separated from the building"* reports — and the aisle lane was written as bare `paving` bonded to a building with no role at all: a bonded child with no identity. The destructive consequence is **B1376**.
- **The fix:** `lib/bondRemap.js` gains `carryHostRoleTags(src, clone)` — the ONE tag-carry helper for any path that replaces an element with fresh-uid children — and both Explode branches (stall rows AND aisle lanes) spread ONE `bond` object built from it, so no future edit can give the rows an identity the aisles do not get. `sideParkFit` and the new `sideParkPiece` joined `HOST_ROLE_TAGS`: both are measured against the host, so both must travel with it or not at all.
- **The set is now modelled, not just tagged.** `lib/dogEar.js` `sideParkStack` is the one derivation of a wall's outward parking stack — pads ordered inner→outer (by `sideParkPiece`, falling back to their own perpendicular offsets for every plan already on disk) each with the cumulative gap it must clear. `relayoutWallKids`, `normalizeWallKids` and `normalizeHostRuns` all read it, so an exploded set lays out as ONE wall kid. It is byte-identical for a single un-exploded field.
- **Fleet impact at time of fix (live DB, non-deleted sites):** 12 host buildings across 9 plans and 6 sites carried untagged exploded pieces — Goose Creek ×4 plans, Silvestri, Sylvestri, Katz, Hoffmeister, RICHEY. Those are repaired by **B1377**.
