- **THE MECHANISM.** `renderView` gained the scale term: the group transform is `translate(tx ty) scale(k)`, `k = view.ppf / anchor.ppf`, `tx = view.offX − k·anchor.offX`. **It reduces to B1440's pure translate at k = 1, so the pan path is unchanged BY CONSTRUCTION** — `anchorTransformAttr` emits the byte-identical bare `translate` there, and that is a unit test, not a hope.
