New pure `lib/roadClasses.js`. Each class seeds a **default centerline radius** (the Arc default for new vertices) and a **min-radius warning threshold** — **all editable; the seeds are starting points to verify against current AASHTO / local fire code, none authoritative or hardcoded.**
- **Seed classes:** Truck route (default ~120′, warn < 50′), Auto drive aisle (default ~25′, warn < 24′ — the drawn-road default), **Public / collector** (speed-based: threshold from `R = V²/[15(e+f)]`, ≈185′ at 25 mph, editable design speed), Fire lane (default ~50′, warn < 28′ inside per IFC App. D), Custom (no threshold).
- **Civil check (non-blocking):** scans the **tessellated centerline for the minimum radius of curvature anywhere** (circumradius of each three consecutive points) and compares to the class threshold. Below → **`flashWarn` on commit/edit** AND a **persistent ⚠ indicator in the road's Element panel** ("⚠ 35′ radius — below 50′ min for Truck route"). **Never blocks or auto-corrects** — surfaces it loudly, the user decides. Works uniformly for arc vertices and traced/smooth runs (it measures the resulting alignment, not how it was drawn).
