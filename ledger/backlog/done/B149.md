`[x]` At a zoomed-out site-overview level, fine infrastructure dimensions — sidewalk widths, road/drive-aisle widths, short edge dimensions — no longer render; they reveal progressively as the user zooms in. Only the high-level labels (building name + SF, and the site-summary chip from **B148**) stay visible at overview zoom.
- **Original ask / recommended mechanism:** tag each annotation with a **tier** — *overview* (building names/SF, site totals) / *site* (building-footprint dims, parking-module dims) / *detail* (sidewalk, drive-aisle/road widths, sub-aisle dims) — and gate visibility by current map scale, made **self-tuning** by a **minimum on-screen length**: a width callout only draws when the feature it measures projects to at least ~40 px on screen (resolution-independent; no hand-tuned zoom-step breakpoints).
- **2026-06-23 owner amendment (folded in):** at site-overview zoom the **"5′ Sidewalk"** centred label and the fine width/edge dimension callouts (e.g. the "30′/40′" drive/aisle ticks bracketing the sidewalk run) **still painted** — illegible clutter. Locked decision: **drop the label + width dimension only; KEEP the thin strip geometry** (a 5′ strip is ~1 px at that scale; pop-in/out of the geometry on zoom would flicker — geometry-hiding is a separate scope, not silently added). Edge case respected: this must NOT also suppress the building name/SF or the B148 site-summary chip (overview tier — always visible).
