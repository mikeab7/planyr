- **Layer 2 — found ONLY by chasing an unexpected result from the layer-1 fix, and retracted rather than filed as a bug.** With layer 1 fixed, `verify-help-report-control.mjs`'s corner-clearance check for "plan" mode reported the help control sitting 50px from the true corner instead of the expected ~14px — a plausible-looking new finding. Fixed by routing "plan" mode (and `verify-capture-pipe.mjs`'s BASE navigation) to `#/project/<the seeded groupId>/site`, which opens the plan itself; "map" mode deliberately keeps the project-less `#/site` (the picker/Leaflet screen IS the map screen that mode means to test). **This is the validate-a-selector-against-a-known-good-case discipline applied to a screen rather than a DOM query: a plausible number from a harness that had never proven it reached the thing it claimed to measure.**
