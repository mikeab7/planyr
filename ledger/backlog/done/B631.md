### B631 — Suppress the "Align before measuring" gate + overlay on NOT-TO-SCALE placed sheets `[Doc Review / Stitch]` (bug — false gate)  *(Cowork brief 2026-07-03 "NEW-2"; minted **B631**)*
`[x]` **Fixed + shipped this session.** A sheet with no plan scale can never be measured, so its "Align before measuring" gate was a false demand. New pure predicate `isNotToScale(meta)` (`lib/sheetRead.js`) = an explicit title-block "NOT TO SCALE" (`scale.explicit==="nts"`) **or** a text-dense non-drawing sheet (`textDense` — notes/specs/legend/schedule, B379); it's deliberately FALSE for a merely-unlabeled plan sheet (that keeps Calibrate+Align). The flag now rides on the placed object — set in `addSheet`/`addGroup` from the read meta, persisted in `buildSnapshot`, read back in `loadStitch` — and a NOT-TO-SCALE sheet renders **no align overlay + no sidebar nag** (the existing measure-block still applies). Scaled sheets are unchanged; local-scale measuring on unaligned-but-scaled sheets stays out of scope. Unit-tested (explicit-NTS / text-dense true; unlabeled-plan false).
