### V189 — B603: the "Elevation / hillshade (USGS 3DEP)" map overlay actually paints (tinted hillshade) ✅ PASS live 2026-07-03
- **Added** 2026-07-01 · **Verified** 2026-07-03 (Cowork, signed in on planyr.io) · earlier: lint 0 · **2148 tests green** · build green.
- **Root cause / fix (B603):** the overlay sent `renderingRule={"rasterFunction":"Elevation Tinted Hillshade"}` — the USGS press-release PROSE wording. ArcGIS ImageServer `exportImage` errors on any name that isn't an exact `rasterFunctionInfos[].name`, so it returned an error tile and the overlay painted **blank/failed**. The real 3DEP template name is **`Hillshade Elevation Tinted`**. One-line fix in `lib/layers.js`; guarded by `test/bugHuntGuards.test.js` (B603) + `test/layerRequest.test.js`.
- **✅ Live result (Cowork, 2026-07-03):** the toggle lives under the utility-evidence group (not "Map layers" as the original note assumed), labeled **"Elevation / hillshade (USGS 3DEP)."** Toggling it on painted a **green elevation-tinted hillshade** across the view (uniform green is correct for the flat 8 South coastal-plain site — low relief), NOT a blank/gray error tile, and the layer's status dot was **blue/loaded**. Network: `elevation.nationalmap.gov/arcgis/rest/services/3DEPElevation/ImageServer` → **200** (the host the sandbox got 403 on). Opacity slider present. Confirms the corrected `rasterFunction` name renders a real image.
